# 제목
[Python 기초] 정규 표현식 (Regular Expression)

# 본문

## 1. 한 줄 요약

정규표현식은 문자열 안에서 특정한 규칙을 가진 패턴을 찾거나 바꾸기 위한 표현 방법이다.

정규표현식을 이해하면 이메일, 전화번호, 숫자, 특정 단어처럼 규칙이 있는 문자열을 효율적으로 처리할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

문자열에서 원하는 부분만 찾아야 하는 상황은 자주 있다.

예를 들어 다음 문장에서 전화번호만 찾고 싶다고 해보자.

```text
문의는 010-1234-5678 또는 010-9999-1111로 주세요.
```

단순히 글자를 하나씩 확인해서 전화번호를 찾을 수도 있다.

하지만 전화번호, 이메일, 날짜처럼 규칙이 있는 문자열을 매번 직접 검사하면 코드가 복잡해진다.

정규표현식을 사용하면 "이런 모양의 문자열을 찾아줘"라고 패턴으로 표현할 수 있다.

```python
r"\d{3}-\d{4}-\d{4}"
```

이 패턴은 다음과 같은 의미다.

```text
숫자 3개 - 숫자 4개 - 숫자 4개
```

정규표현식은 문자열 검색을 위한 강력한 필터라고 볼 수 있다.

---

## 3. 핵심 아이디어

정규표현식은 보물찾기 지도와 비슷하다.

보물의 정확한 이름을 몰라도 특징을 알면 찾을 수 있다.

```text
찾고 싶은 것
- 숫자로 이루어짐
- 중간에 -가 있음
- 010으로 시작함
```

정규표현식은 이런 특징을 기호로 적는다.

```text
\d      → 숫자 한 개
\d{3}   → 숫자 세 개
.       → 아무 문자 한 개
+       → 하나 이상 반복
*       → 0개 이상 반복
```

예를 들어 전화번호 패턴은 다음처럼 볼 수 있다.

```text
010-1234-5678

010     -   1234    -   5678
\d{3}   -   \d{4}   -   \d{4}
```

파이썬에서는 `re` 모듈을 사용해 정규표현식을 다룬다.

```python
import re
```

---

## 4. 동작 과정 살펴보기

아래 예제를 보자.

```python
import re

text = "전화번호는 010-1234-5678 입니다."
pattern = r"\d{3}-\d{4}-\d{4}"

result = re.search(pattern, text)
```

### Step 1. 검색 대상 문자열이 준비된다

```text
전화번호는 010-1234-5678 입니다.
```

### Step 2. 찾을 패턴을 준비한다

```text
패턴: \d{3}-\d{4}-\d{4}

의미:
숫자 3개
-
숫자 4개
-
숫자 4개
```

### Step 3. 문자열을 왼쪽부터 검사한다

```text
전화번호는 010-1234-5678 입니다.
         └─────────────┘
          패턴과 일치
```

파이썬은 문자열을 앞에서부터 확인하면서 패턴과 맞는 부분을 찾는다.

### Step 4. 찾은 결과를 꺼낸다

```python
result.group()
```

```text
결과

010-1234-5678
```

패턴과 일치하는 부분이 있으면 그 문자열을 가져올 수 있다.

## 5. 구현 코드 및 상세 설명

```python
import re

text = "이메일: test@example.com, 전화번호: 010-1234-5678"

# 전화번호 찾기
phone_pattern = r"\d{3}-\d{4}-\d{4}"
phone = re.search(phone_pattern, text)

if phone:
    print("전화번호:", phone.group())


# 이메일 찾기
email_pattern = r"\w+@\w+\.\w+"
email = re.search(email_pattern, text)

if email:
    print("이메일:", email.group())


# 숫자 모두 찾기
numbers = re.findall(r"\d+", text)
print("숫자 목록:", numbers)


# 특정 패턴 바꾸기
masked_text = re.sub(r"\d", "*", text)
print(masked_text)
```

### 코드 설명

```python
import re
```

정규표현식을 사용하기 위해 `re` 모듈을 불러온다.

```python
phone_pattern = r"\d{3}-\d{4}-\d{4}"
```

전화번호 패턴을 만든다.

`r`은 raw string을 의미하며, 정규표현식에서 역슬래시를 더 편하게 쓰기 위해 자주 사용한다.

```text
\d{3} → 숫자 3개
-     → 하이픈 문자
\d{4} → 숫자 4개
```

```python
re.search(phone_pattern, text)
```

문자열에서 패턴과 일치하는 첫 번째 부분을 찾는다.

```python
re.findall(r"\d+", text)
```

문자열에서 숫자가 하나 이상 이어진 부분을 모두 찾는다.

```text
010
1234
5678
```

```python
re.sub(r"\d", "*", text)
```

문자열 안의 숫자를 모두 `*`로 바꾼다.

개인정보 마스킹 같은 작업에 사용할 수 있다.

## 6. 마지막 정리

정규표현식은 문자열에서 특정 패턴을 찾기 위한 도구다.

파이썬에서는 `re` 모듈을 사용한다.

`\d`는 숫자, `\w`는 문자나 숫자, `+`는 하나 이상 반복을 의미한다.

`re.search()`는 첫 번째 일치 결과를 찾는다.

`re.findall()`은 일치하는 모든 결과를 리스트로 반환한다.
