# 본문

## 1. 한 줄 요약

튜플은 **쉼표로 구분되는 불변(immutable) 시퀀스 자료형**으로, 이질적인 요소들의 묶음을 표현하는 데 사용된다. 생성 후 개별 항목의 변경이 불가능하다는 점에서 리스트와 본질적으로 구별된다.

---

## 2. 시퀀스 자료형으로서의 위치

리스트와 문자열은 인덱싱, 슬라이싱 등 다수의 연산을 공유하는 *시퀀스(sequence)* 자료형이다. 튜플은 이와 동일한 시퀀스 자료형의 범주에 속하는 또 다른 표준 형(type)이다.

```
시퀀스 자료형 계층:

시퀀스 (Sequence)
  ├─ list   → 가변(mutable),   등질적 요소, 이터레이션 중심
  ├─ tuple  → 불변(immutable), 이질적 요소, 언패킹·인덱싱 중심
  └─ str    → 불변(immutable), 문자(character) 시퀀스
```

공식 문서의 구분에 따르면:

> 튜플은 불변이고, 보통 이질적인 요소들의 시퀀스를 포함합니다. 리스트는 가변이고, 요소들은 보통 등질적이고 리스트에 대한 이터레이션으로 액세스됩니다.

즉, **리스트**는 같은 종류의 데이터를 반복 처리할 때, **튜플**은 성격이 다른 데이터를 하나의 단위로 묶을 때 적합하다.

---

## 3. 핵심 아이디어

### 불변성(Immutability)이 핵심이다

튜플의 가장 중요한 특성은 **생성 이후 개별 항목에 대한 대입이 불가능하다**는 것이다. 이는 실수로 인한 데이터 변경을 원천 차단하며, 함수의 반환값이나 딕셔너리의 키처럼 **변경되어서는 안 되는 데이터**를 표현하는 데 적합하다.

단, 튜플 자체가 불변이더라도 **튜플이 담고 있는 가변 객체(예: 리스트)의 내용은 변경 가능**하다. 불변성은 튜플의 구조(어떤 객체를 참조하는지)에 적용되며, 참조 대상 객체의 내부 상태에는 적용되지 않는다.

```
불변성의 적용 범위:

v = ([1, 2, 3], [3, 2, 1])

v[0] = [9, 9, 9]   → ❌ 튜플 자체의 항목 변경 불가
v[0].append(4)     → ✅ 튜플이 참조하는 리스트 내용 변경은 가능
```

## 4. 동작 과정 살펴보기

### 4-1. 튜플 생성 — 괄호가 아닌 쉼표가 핵심

튜플은 **쉼표(comma)** 로 구성된다. 괄호는 가독성을 위한 보조 수단이며, 구문상 필수가 아닌 경우가 많다.

```python
>>> t = 12345, 54321, 'hello!'   # 괄호 없이 쉼표만으로 생성
>>> t
(12345, 54321, 'hello!')         # 출력 시에는 항상 괄호로 표시됨
>>> t[0]
12345
```

중첩 튜플도 가능하다.

```python
>>> u = t, (1, 2, 3, 4, 5)
>>> u
((12345, 54321, 'hello!'), (1, 2, 3, 4, 5))
```

```
생성 방식 비교:

표현식                결과 타입   비고
─────────────────────────────────────────────
1, 2, 3              tuple      괄호 없이 쉼표만으로 생성
(1, 2, 3)            tuple      괄호 포함 (일반적 표현)
(1,)                 tuple      요소 1개 — 반드시 후행 쉼표 필요
(1)                  int        쉼표 없음 — 그냥 정수 1
()                   tuple      빈 튜플
```

### 4-2. 특수 케이스 — 빈 튜플과 단일 요소 튜플

공식 문서가 명시적으로 짚는 문법 예외 사항이다.

```python
>>> empty = ()           # 빈 튜플: 빈 괄호 쌍
>>> len(empty)
0

>>> singleton = 'hello', # 단일 요소 튜플: 값 뒤에 쉼표 필수
>>> len(singleton)
1
>>> singleton
('hello',)
```

**값 하나를 괄호로만 감싸는 것은 튜플을 생성하지 않는다.** 후행 쉼표(trailing comma)가 단일 요소 튜플을 결정짓는 요소다.

### 4-3. 불변성 확인

```python
>>> t = 12345, 54321, 'hello!'
>>> t[0] = 88888
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'tuple' object does not support item assignment
```

```python
>>> v = ([1, 2, 3], [3, 2, 1])   # 가변 객체를 포함한 튜플
>>> v[0].append(4)                # ← 참조 대상 리스트는 변경 가능
>>> v
([1, 2, 3, 4], [3, 2, 1])
```

```
불변성 동작 시각화:

v = ( [1, 2, 3] , [3, 2, 1] )
       ↑               ↑
    참조(ref)         참조(ref)
       │
    v[0].append(4)   ← 리스트 내부 변경 → 허용
    v[0] = [9, 9, 9] ← 튜플의 참조 변경 → 불허
```

## 5. 구현 코드 및 상세 설명

### 5-1. 튜플 패킹과 언패킹

공식 문서에서 정의하는 두 가지 핵심 연산이다.

**튜플 패킹(Tuple Packing)**: 여러 값을 하나의 튜플로 묶는 것

```python
t = 12345, 54321, 'hello!'   # 세 값을 하나의 튜플로 패킹
```

**시퀀스 언패킹(Sequence Unpacking)**: 시퀀스를 여러 변수로 분리하는 것

```python
x, y, z = t   # 튜플의 세 요소를 각 변수에 순서대로 할당
print(x)      # 12345
print(y)      # 54321
print(z)      # 'hello!'
```

공식 문서에 따르면, 시퀀스 언패킹은 **오른쪽에 어떤 시퀀스라도 올 수 있으며**, 좌변의 변수 개수와 우변 시퀀스의 요소 개수가 일치해야 한다.

```
패킹·언패킹 흐름:

패킹:
  12345, 54321, 'hello!'  →  t = (12345, 54321, 'hello!')

언패킹:
  t = (12345, 54321, 'hello!')
       ↓        ↓        ↓
       x        y        z
```

### 5-2. 인덱싱과 슬라이싱

튜플은 시퀀스이므로 리스트와 동일한 인덱싱·슬라이싱 문법을 지원한다.

```python
t = (10, 20, 30, 40, 50)
#     0   1   2   3   4   ← 양수 인덱스
#    -5  -4  -3  -2  -1   ← 음수 인덱스

print(t[0])      # 10   — 첫 번째 요소
print(t[-1])     # 50   — 마지막 요소
print(t[1:3])    # (20, 30) — 1 이상 3 미만
print(t[::-1])   # (50, 40, 30, 20, 10) — 역순
```

### 5-3. 내장 함수와의 연동

튜플은 `len()`, `max()`, `min()`, `sum()`, `sorted()` 등 시퀀스를 처리하는 내장 함수에 그대로 활용된다. 단, `sorted()`는 튜플이 아닌 **리스트**를 반환한다는 점에 주의한다.

```python
t = (3, 1, 4, 1, 5, 9, 2)

print(len(t))       # 7
print(max(t))       # 9
print(min(t))       # 1
print(sum(t))       # 25
print(sorted(t))    # [1, 1, 2, 3, 4, 5, 9]  ← list 반환
print(type(sorted(t)))  # <class 'list'>
```

### 5-4. 함수의 다중 반환값

파이썬에서 함수가 여러 값을 반환할 때 내부적으로 튜플이 사용된다. `return a, b`는 `return (a, b)`와 동등하다.

```python
def min_max(numbers):
    return min(numbers), max(numbers)   # 튜플로 패킹되어 반환

result = min_max([3, 1, 4, 1, 5, 9])
print(result)           # (1, 9)

low, high = min_max([3, 1, 4, 1, 5, 9])   # 언패킹으로 수신
print(low, high)        # 1 9
```

### 5-5. 딕셔너리 키로의 활용

불변 객체는 해시 가능(hashable)하므로, 튜플은 딕셔너리의 키 또는 집합(set)의 원소로 사용할 수 있다. 리스트는 가변이므로 이 용도에 사용할 수 없다.

```python
# 2D 좌표를 키로 사용하는 딕셔너리
grid = {(0, 0): '원점', (1, 0): '오른쪽', (0, 1): '위쪽'}
print(grid[(0, 0)])    # 원점
print(grid[(1, 0)])    # 오른쪽

# 리스트는 키로 사용 불가
# grid[[0, 0]] = '원점'  → TypeError: unhashable type: 'list'
```

## 6. 핵심 요약 및 주의점

**핵심 요약**

- 튜플은 **쉼표**로 생성된다. 괄호는 가독성 또는 구문 명확성을 위한 보조 수단이다.
- **불변성**: 생성 후 개별 항목의 변경·추가·삭제가 불가능하다. 단, 튜플이 참조하는 가변 객체의 내부 상태는 변경될 수 있다.
- **단일 요소 튜플**은 `(value,)` 형태로, 후행 쉼표가 필수다. `(value)`는 단순 괄호 표현식으로 해석된다.
- **패킹·언패킹**: `a, b = t` 형태의 언패킹은 좌변 변수 수와 우변 시퀀스 길이가 일치해야 한다.
- 튜플은 불변이므로 **해시 가능**하여 딕셔너리 키 또는 집합 원소로 사용 가능하다.

**리스트 vs 튜플 비교**

```
항목               list              tuple
──────────────────────────────────────────────────
가변성             가변(mutable)     불변(immutable)
생성 기호          [ ]               ( ) 또는 쉼표
요소 성격          등질적(homogeneous) 이질적(heterogeneous)
주요 접근 방식     이터레이션        인덱싱·언패킹
딕셔너리 키        불가              가능
메모리 효율        상대적으로 낮음   상대적으로 높음
```

**주의점**

- `sorted(tuple)`은 `list`를 반환한다. 정렬된 결과를 튜플로 유지하려면 `tuple(sorted(t))`를 사용해야 한다.
- 튜플의 불변성은 튜플 객체 자체의 구조에 한정된다. 내부에 리스트를 담고 있다면 그 리스트는 여전히 변경 가능하다.
- `(1)` 은 `int`, `(1,)` 은 `tuple` 이다. 단일 요소 튜플 생성 시 후행 쉼표를 반드시 명시해야 한다.
