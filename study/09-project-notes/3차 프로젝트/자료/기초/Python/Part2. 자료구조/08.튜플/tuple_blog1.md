## 1. 한 줄 요약

튜플은 **한 번 만들면 내용을 바꿀 수 없는 리스트**다. 리스트와 거의 똑같지만 `[ ]` 대신 `( )`를 쓰고, 값을 추가·수정·삭제할 수 없다.

---

## 2. 왜 튜플이 필요할까?

리스트가 있는데 튜플이 따로 왜 있을까? 처음엔 "그냥 리스트 쓰면 되는 거 아닌가?" 라고 생각하기 쉽다.

핵심은 **"절대 바뀌면 안 되는 데이터"** 를 다룰 때다.

예를 들어 서울의 위도·경도는 바뀌지 않는다. 프로그램에서 이 값을 리스트로 저장하면, 실수로 코드 어딘가에서 값을 바꿔버려도 에러가 나지 않는다. 나중에 이상한 위치가 나와서야 "아, 어디서 건드렸구나" 하고 찾아다녀야 한다.

튜플로 저장하면 수정 시도 자체가 에러로 막힌다. **"이 값은 바뀌면 안 된다"는 의도를 코드로 보여주는 것**이다.

```python
# 리스트로 저장 — 실수로 바꿔도 아무 경고 없음
seoul = [37.5, 127.0]
seoul[0] = 0.0    # 조용히 바뀜... 나중에 버그가 됨

# 튜플로 저장 — 변경 시도 즉시 에러로 막아줌
seoul = (37.5, 127.0)
seoul[0] = 0.0    # ❌ 즉시 TypeError 발생!
```

거기다 튜플은 리스트보다 **메모리를 적게 쓰고 속도도 빠르다.** 변경 기능을 없앤 대신 그만큼 가벼워진 것이다.

---

## 3. 핵심 아이디어 — 튜플은 "인쇄된 명함"이다

리스트와 튜플의 차이를 한 문장으로 표현하면 이렇다.

> 리스트는 **화이트보드**, 튜플은 **인쇄된 명함**이다.

화이트보드는 언제든 쓰고 지우고 추가할 수 있다. 하지만 인쇄된 명함은 한 번 찍으면 내용을 바꿀 수 없다. 보고 읽는 것만 가능하다.

```
리스트 (화이트보드):
  [10, 20, 30]
   ↕   ↕   ↕
  추가·수정·삭제 모두 자유롭게 가능

튜플 (인쇄된 명함):
  (10, 20, 30)
   🔒  🔒  🔒
  읽기(인덱싱·슬라이싱)만 가능!
  추가·수정·삭제는 완전히 막혀 있음
```

중요한 점은, **읽는 방법은 리스트와 완전히 똑같다**는 것이다. 인덱스로 꺼내거나, 슬라이싱으로 범위를 잘라내는 것 모두 리스트와 동일하게 동작한다. 다른 점은 딱 하나, **값을 바꿀 수 없다**는 것뿐이다.

---

## 4. 동작 과정 살펴보기

### 4-1. 튜플 만들기

튜플은 소괄호 `( )`로 감싸고 콤마로 값을 구분해서 만든다.

```python
# 가장 기본적인 형태
fruits = ("사과", "바나나", "딸기")
coords = (37.5, 127.0)
mixed  = (1, "hello", True)   # 리스트처럼 타입을 섞어도 됨
```

괄호 없이 콤마만 써도 파이썬은 튜플로 인식한다. 하지만 다른 사람이 읽을 때 헷갈릴 수 있으니, 가독성을 위해 괄호를 쓰는 것이 좋은 습관이다.

```python
point = 3, 5
print(type(point))   # <class 'tuple'>  — 괄호 없어도 튜플!
```

---

**⚠️ 함정: 요소가 하나인 튜플**

여기서 처음 배우는 사람이 가장 많이 실수하는 부분이 있다. 요소가 하나뿐인 튜플을 만들 때는 반드시 **콤마를 붙여야 한다.**

```python
single    = (42,)    # ✅ 튜플 — 콤마가 있어야 튜플!
not_tuple = (42)     # ❌ 그냥 정수 42 — 단순히 괄호로 감싼 것뿐
```

왜냐하면 파이썬은 `(42)`를 "42를 괄호로 묶은 수식"으로 해석하기 때문이다. `(3 + 5)`가 8이 되듯, `(42)`도 그냥 42다. **"이게 값이 아니라 묶음(튜플)이에요"라고 알려주는 신호가 바로 콤마**다.

```
(42,) → 요소가 하나인 튜플   ← 콤마가 "이건 튜플이야"를 선언함
(42)  → 정수 42             ← 그냥 괄호로 감싼 숫자
```

---

### 4-2. 인덱싱과 슬라이싱 — 리스트와 완전히 같다

튜플의 각 요소에는 **번호(인덱스)**가 붙어 있다. 0번부터 시작하고, 뒤에서부터 셀 때는 -1이 마지막이다. 이 방식은 리스트와 100% 동일하다.

```python
nums = (10, 20, 30, 40, 50)
```

```
번호(인덱스) 시각화:

( 10  |  20  |  30  |  40  |  50 )
   0      1      2      3      4    ← 앞에서부터 셀 때
  -5     -4     -3     -2     -1    ← 뒤에서부터 셀 때
```

```python
print(nums[0])     # 10   — 0번 서랍 (첫 번째)
print(nums[2])     # 30   — 2번 서랍 (세 번째)
print(nums[-1])    # 50   — 마지막 서랍
print(nums[-2])    # 40   — 뒤에서 두 번째 서랍
```

슬라이싱은 `[시작:끝]` 형태로 여러 요소를 한꺼번에 꺼낸다. **끝 인덱스는 포함되지 않는다**는 점에 주의하자.

```python
print(nums[1:3])   # (20, 30)      — 1번 이상 3번 미만
print(nums[:3])    # (10, 20, 30)  — 처음부터 3번 미만
print(nums[2:])    # (30, 40, 50)  — 2번부터 끝까지
print(nums[::2])   # (10, 30, 50)  — 2칸씩 건너뛰며
```

---

### 4-3. 수정하려 하면 즉시 에러가 난다

튜플의 불변성은 매우 철저하다. 값을 바꾸거나, 추가하거나, 삭제하려는 시도를 모두 차단한다.

```python
fruits = ("사과", "바나나", "딸기")

fruits[0] = "포도"     # ❌ 값 수정 시도
fruits.append("포도")  # ❌ 추가 시도
del fruits[0]          # ❌ 삭제 시도
```

각각 실행하면 다음과 같은 에러가 나온다.

```
fruits[0] = "포도"
    → TypeError: 'tuple' object does not support item assignment
      (튜플은 항목 대입(수정)을 지원하지 않는다)

fruits.append("포도")
    → AttributeError: 'tuple' object has no attribute 'append'
      (튜플에는 append 기능 자체가 없다)

del fruits[0]
    → TypeError: 'tuple' object doesn't support item deletion
      (튜플은 항목 삭제를 지원하지 않는다)
```

에러 메시지를 보면 알 수 있듯, 튜플은 애초에 수정·추가·삭제 기능 자체를 가지고 있지 않다. 이것이 의도된 설계다.

## 5. 구현 코드 및 상세 설명

### 5-1. 튜플 언패킹 — 값을 여러 변수에 한 번에 꺼내기

튜플의 가장 강력하고 자주 쓰이는 기능이다. 튜플 안의 값들을 여러 변수에 동시에 담을 수 있다.

비유하자면 택배 상자(튜플) 안에 물건이 두 개 들어 있을 때, 상자를 열어서 첫 번째 물건은 왼손에, 두 번째 물건은 오른손에 쥐는 것과 같다.

```python
coords = (37.5, 127.0)
lat, lng = coords       # 튜플의 값을 두 변수에 동시에 담음

print(lat)   # 37.5
print(lng)   # 127.0
```

```
언패킹 동작 시각화:

  (37.5  ,  127.0)
     ↓          ↓
    lat         lng

결과: lat = 37.5, lng = 127.0
```

언패킹할 때 주의할 점은, **왼쪽 변수의 개수와 튜플의 요소 개수가 정확히 일치해야 한다**는 것이다. 개수가 다르면 에러가 난다.

```python
a, b = (1, 2, 3)     # ❌ 변수 2개인데 값이 3개 — 개수가 안 맞음
a, b, c, d = (1, 2)  # ❌ 변수 4개인데 값이 2개 — 개수가 안 맞음
```

만약 앞 몇 개만 받고 나머지는 한꺼번에 받고 싶다면 `*`(별표)를 활용한다. `*rest`는 "나머지 모두를 리스트로 받겠다"는 뜻이다.

```python
first, *rest = (1, 2, 3, 4, 5)
print(first)   # 1
print(rest)    # [2, 3, 4, 5]   ← 나머지가 리스트로 담김

a, b, *others = ("사과", "바나나", "딸기", "포도")
print(a)       # 사과
print(b)       # 바나나
print(others)  # ['딸기', '포도']
```

---

### 5-2. 함수에서 여러 값 반환하기 — 튜플이 가장 빛나는 순간

파이썬 함수는 기본적으로 값을 하나만 반환할 수 있다. 그런데 실제 코딩을 하다 보면 결과를 두 개 이상 돌려줘야 할 때가 자주 생긴다. 이럴 때 튜플이 자연스럽게 사용된다.

`return a, b`처럼 쉼표로 여러 값을 나열하면, 파이썬이 자동으로 그것들을 튜플로 묶어서 반환한다.

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)   # (최솟값, 최댓값) 튜플로 반환
```

```
실행 흐름:

get_min_max([3, 1, 4, 1, 5, 9]) 호출
    ↓
min([3,1,4,1,5,9]) = 1
max([3,1,4,1,5,9]) = 9
    ↓
return 1, 9  →  실제로는 return (1, 9) 와 같음
    ↓
(1, 9) 튜플이 반환됨
```

반환된 튜플은 그대로 변수에 받을 수도 있고, 언패킹으로 바로 분리해서 받을 수도 있다.

```python
# 방법 1: 튜플째로 받기
result = get_min_max([3, 1, 4, 1, 5, 9])
print(result)       # (1, 9)
print(result[0])    # 1  — 튜플에서 개별로 꺼낼 수도 있음

# 방법 2: 언패킹으로 바로 분리해서 받기 (더 자주 쓰임)
low, high = get_min_max([3, 1, 4, 1, 5, 9])
print(low)    # 1
print(high)   # 9
```

> 💡 파이썬에서 `return a, b`는 `return (a, b)`와 완전히 같다. 쉼표가 튜플을 만드는 것이지, 괄호가 튜플을 만드는 게 아니다. 파이썬 곳곳에서 튜플이 이렇게 조용히 쓰이고 있다.

---

### 5-3. 자주 쓰는 내장 함수들

튜플은 수정만 안 될 뿐, **읽고 분석하는 기능은 리스트와 동일**하게 쓸 수 있다. 아래 함수들은 리스트에서 쓰던 것과 사용법이 동일하다.

```python
t = (3, 1, 4, 1, 5, 9, 2, 6)

print(len(t))     # 8   — 요소가 몇 개인지
print(max(t))     # 9   — 가장 큰 값
print(min(t))     # 1   — 가장 작은 값
print(sum(t))     # 31  — 모든 값의 합
```

튜플 자체에 붙어있는 메서드(기능)는 딱 두 개뿐이다. 수정과 무관한 "세기"와 "찾기"만 허용된다.

```python
t2 = (1, 2, 2, 3, 2)

print(t2.count(2))   # 3 — 2라는 값이 몇 개 있는지 셈
print(t2.index(3))   # 3 — 3이라는 값이 몇 번 위치에 있는지 찾음
```

정렬은 `sorted()`를 쓸 수 있다. 단, **결과가 튜플이 아니라 리스트로 반환된다**. 튜플은 불변이기 때문에 정렬된 튜플을 새로 만들지 않고, 리스트로 돌려주는 것이다.

```python
t = (3, 1, 4, 1, 5)
result = sorted(t)
print(result)         # [1, 1, 3, 4, 5]  ← 리스트로 반환됨
print(type(result))   # <class 'list'>

# 튜플로 받고 싶다면 tuple()로 감싸면 됨
result_tuple = tuple(sorted(t))
print(result_tuple)   # (1, 1, 3, 4, 5)
```

### 5-4. 튜플 ↔ 리스트 변환

튜플은 불변이라 값을 추가하거나 삭제할 수 없다. 하지만 꼭 필요한 상황이 생기면, 잠깐 리스트로 바꿔서 작업한 뒤 다시 튜플로 되돌리는 방법을 쓸 수 있다.

`list()`는 튜플을 리스트로, `tuple()`은 리스트를 튜플로 변환해준다.

```python
t = (1, 2, 3)

# 1단계: 튜플 → 리스트로 변환 (이제 수정 가능!)
lst = list(t)
print(lst)         # [1, 2, 3]

# 2단계: 리스트에서 값 추가·수정·삭제
lst.append(4)
lst.remove(1)
print(lst)         # [2, 3, 4]

# 3단계: 다시 리스트 → 튜플로 변환 (다시 잠금)
t2 = tuple(lst)
print(t2)          # (2, 3, 4)
```

```
흐름 시각화:

(1, 2, 3)  ─── list() ───▶  [1, 2, 3]
                                  │
                            수정·추가·삭제
                                  │
(2, 3, 4)  ◀── tuple() ───  [2, 3, 4]
```

이 방법은 "튜플을 수정한다"기보다는, 잠깐 변환해서 작업한 뒤 다시 튜플로 포장하는 것이다. 자주 쓰이는 패턴이니 기억해두자.

## 6. 리스트 vs 튜플 — 언제 뭘 쓸까?

둘을 비교해서 선택 기준을 잡아보자.

```
항목               리스트 [ ]        튜플 ( )
─────────────────────────────────────────────────
수정·추가·삭제      ✅ 가능           ❌ 불가
인덱싱·슬라이싱     ✅ 가능           ✅ 가능
메모리 효율         보통              더 적게 사용
처리 속도           보통              더 빠름
딕셔너리 키로 사용  ❌ 불가           ✅ 가능 (불변이라 가능)
```

판단 기준은 간단하다. **"이 데이터가 나중에 바뀔 가능성이 있는가?"**

값이 바뀔 수 있다면 → **리스트**
- 장바구니 목록 (물건 추가·제거)
- 반 학생 출석부 (학생 추가·삭제)
- 게임 점수 목록 (점수 갱신)

값이 절대 바뀌면 안 된다면 → **튜플**
- 위도·경도 좌표 (서울은 항상 서울)
- 요일 이름 ("월화수목금토일")
- RGB 색상 코드 (빨강은 항상 (255, 0, 0))
- 함수의 다중 반환값

---

## 7. 마지막 정리

- 튜플은 `(값1, 값2, ...)`로 만들며, **한 번 생성하면 수정·추가·삭제가 불가능**하다.
- 요소가 하나일 때는 **`(값,)` 처럼 반드시 콤마**를 붙여야 한다. `(값)`은 그냥 괄호다.
- 인덱싱과 슬라이싱은 **리스트와 완전히 동일**하게 쓸 수 있다.
- **언패킹**으로 `lat, lng = (37.5, 127.0)` 처럼 값을 변수에 동시에 담을 수 있다.
- 함수에서 `return a, b`는 실제로 **튜플을 반환**하는 것이고, 언패킹으로 받는 게 일반적이다.
- `list()`로 리스트로 바꾸면 수정이 가능하고, `tuple()`로 다시 튜플로 되돌릴 수 있다.
