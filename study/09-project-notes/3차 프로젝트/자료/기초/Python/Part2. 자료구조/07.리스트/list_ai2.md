# 본문

## 1. 한 줄 요약

리스트는 여러 값을 순서대로 담을 수 있는 파이썬의 기본 자료구조이다.

리스트를 이해하면 여러 개의 점수, 이름, 숫자, 결과값을 하나의 변수로 관리할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

학생 5명의 점수를 저장한다고 해보자.

리스트를 모르면 변수를 여러 개 만들어야 한다.

```python
score1 = 80
score2 = 90
score3 = 70
score4 = 100
score5 = 85
```

학생 수가 많아질수록 변수 이름이 계속 늘어난다.

평균을 구하거나 전체 점수를 출력하기도 불편하다.

리스트를 사용하면 여러 값을 하나의 이름으로 묶을 수 있다.

```python
scores = [80, 90, 70, 100, 85]
```

이제 `scores`라는 변수 하나로 모든 점수를 관리할 수 있다.

리스트는 **같은 성격의 여러 값을 한 줄로 정리하는 상자**라고 볼 수 있다.

---

## 3. 핵심 아이디어

리스트는 번호가 붙은 사물함과 비슷하다.

```text
scores = [80, 90, 70]

사물함 번호:   0    1    2
              ┌────┬────┬────┐
값:           │ 80 │ 90 │ 70 │
              └────┴────┴────┘
```

각 값은 순서를 가진다.

파이썬에서는 첫 번째 위치를 0번이라고 부른다.

이 위치 번호를 인덱스라고 한다.

```python
scores[0]
```

위 코드는 리스트의 0번 칸에 있는 값을 꺼낸다.

```text
scores[0] → 80
scores[1] → 90
scores[2] → 70
```

리스트는 값을 꺼낼 수도 있고, 추가할 수도 있고, 수정할 수도 있다.

즉, 리스트는 여러 값을 담아두고 필요할 때 관리하기 위한 도구이다.

---

## 4. 동작 과정 살펴보기

아래 리스트를 사용해 보자.

```python
fruits = ["사과", "바나나", "포도"]
```

### Step 1. 리스트가 만들어진다

```text
fruits

0번       1번        2번
┌──────┬────────┬──────┐
│ 사과 │ 바나나 │ 포도 │
└──────┴────────┴──────┘
```

리스트 안의 값들은 순서대로 저장된다.

### Step 2. 인덱스로 값 꺼내기

```python
fruits[0]
```

```text
0번       1번        2번
┌──────┬────────┬──────┐
│ 사과 │ 바나나 │ 포도 │
└──────┴────────┴──────┘
  ↑
0번 칸
```

결과는 `"사과"`이다.

### Step 3. 값 수정하기

```python
fruits[1] = "딸기"
```

```text
수정 전

["사과", "바나나", "포도"]

수정 후

["사과", "딸기", "포도"]
```

1번 칸의 값이 `"바나나"`에서 `"딸기"`로 바뀐다.

### Step 4. 값 추가하기

```python
fruits.append("수박")
```

```text
추가 전

["사과", "딸기", "포도"]

추가 후

["사과", "딸기", "포도", "수박"]
```

`append()`는 리스트의 맨 뒤에 값을 추가한다.

## 5. 구현 코드 및 상세 설명

```python
# 리스트 만들기
scores = [80, 90, 70]

# 값 꺼내기
print(scores[0])
print(scores[1])

# 값 수정하기
scores[2] = 100

# 값 추가하기
scores.append(85)

# 전체 출력
print(scores)

# 리스트 길이 확인
print(len(scores))

# 반복문으로 모든 점수 출력하기
for score in scores:
    print("점수:", score)
```

### 코드 설명

```python
scores = [80, 90, 70]
```

점수 3개를 리스트에 저장한다.

```text
scores

[80] [90] [70]
 0    1    2
```

```python
scores[0]
```

0번 위치의 값을 꺼낸다.

파이썬 리스트의 인덱스는 항상 0부터 시작한다.

```python
scores[2] = 100
```

2번 위치에 있는 값을 `100`으로 바꾼다.

```text
수정 전: [80, 90, 70]
수정 후: [80, 90, 100]
```

```python
scores.append(85)
```

리스트의 맨 뒤에 `85`를 추가한다.

```text
추가 전: [80, 90, 100]
추가 후: [80, 90, 100, 85]
```

```python
len(scores)
```

리스트 안에 값이 몇 개 있는지 알려준다.

```python
for score in scores:
```

리스트 안의 값을 하나씩 꺼내 `score`에 저장한다.

리스트와 반복문은 함께 자주 사용된다.

---

## 6. 마지막 정리

리스트는 여러 값을 순서대로 담는 자료형이다.

리스트는 대괄호 `[]`를 사용해 만든다.

리스트의 위치 번호인 인덱스는 0부터 시작한다.

`append()`를 사용하면 리스트 맨 뒤에 값을 추가할 수 있다.

리스트는 반복문과 함께 사용하면 여러 값을 쉽게 처리할 수 있다.
