# 본문

## 1. 한 줄 요약

집합은 **중복 요소를 허용하지 않는 비순서(unordered) 컬렉션**이다. 멤버십 검사(membership testing)와 중복 제거, 그리고 수학적 집합 연산(합집합, 교집합, 차집합, 대칭차집합)이 주요 활용 목적이다.

---

## 2. 집합의 정의와 특성

파이썬 공식 문서의 정의에 따르면:

> 집합은 중복 요소가 없는 순서 없는 컬렉션입니다. 기본적인 사용법은 멤버십 검사와 중복 항목 제거를 포함합니다. 집합 객체는 합집합, 교집합, 차집합, 대칭차집합과 같은 수학적 연산도 지원합니다.

집합의 핵심 특성은 세 가지다.

```
집합(Set)의 핵심 특성:

1. 비순서(unordered)  — 요소 간 순서가 정의되지 않음. 인덱싱·슬라이싱 불가
2. 중복 불허          — 동일한 값의 요소는 하나만 유지됨
3. 가변(mutable)      — 요소의 추가·삭제가 가능 (frozenset은 불변)
```

비순서 특성으로 인해 같은 집합을 반복 출력하더라도 요소의 나열 순서는 실행마다 달라질 수 있다.

---

## 3. 핵심 아이디어

### 해시 기반 구조가 집합의 성능을 결정한다

집합은 내부적으로 **해시 테이블(hash table)** 로 구현된다. 요소를 해시값으로 변환해 저장하기 때문에, 멤버십 검사(`x in s`)가 리스트의 O(n)과 달리 **평균 O(1)**에 수행된다. 이 특성이 집합을 대량 데이터의 포함 여부 판별에 적합하게 만든다.

해시 기반 구조의 제약으로, **집합의 요소는 반드시 해시 가능(hashable)한 불변 객체**여야 한다. 리스트나 딕셔너리는 가변이므로 집합의 요소로 사용할 수 없다.

```
해시 가능 여부:

요소 타입        해시 가능   집합 요소 사용
─────────────────────────────────────────
int, float       ✅          ✅
str              ✅          ✅
tuple            ✅ (불변)   ✅
list             ❌ (가변)   ❌ → TypeError
dict             ❌ (가변)   ❌ → TypeError
```

## 4. 동작 과정 살펴보기

### 4-1. 집합 생성

집합은 중괄호 `{ }` 또는 `set()` 함수로 생성한다.

```python
>>> basket = {'apple', 'orange', 'apple', 'pear', 'orange', 'banana'}
>>> print(basket)
{'orange', 'banana', 'pear', 'apple'}   # 중복 제거, 순서 비보장
```

중복 요소가 자동으로 제거된다. `'apple'`과 `'orange'`가 두 번 입력되었으나 결과에는 한 번씩만 나타난다.

**주의: 빈 집합은 반드시 `set()`으로 생성해야 한다.**

```python
empty_set  = set()    # ✅ 빈 집합
empty_dict = {}       # ❌ 빈 딕셔너리 — 집합이 아님
```

`{}`는 빈 딕셔너리로 해석된다. 빈 집합 생성 시 `set()`을 명시적으로 사용해야 한다.

### 4-2. 멤버십 검사

```python
>>> 'orange' in basket
True
>>> 'crabgrass' in basket
False
```

```
멤버십 검사 성능 비교:

자료형    연산           평균 시간복잡도
─────────────────────────────────────
list      x in list      O(n) — 순차 탐색
set       x in set       O(1) — 해시 조회
```

## 5. 구현 코드 및 상세 설명

### 5-1. 집합 컴프리헨션

리스트 컴프리헨션과 동일한 문법을 중괄호 `{ }`로 사용한다.

```python
>>> a = {x for x in 'abracadabra' if x not in 'abc'}
>>> a
{'r', 'd'}
```

`'abracadabra'` 문자열에서 `'abc'`에 포함되지 않은 문자만을 중복 없이 수집한다. 결과는 집합이므로 순서가 보장되지 않는다.

---

### 5-2. 수학적 집합 연산

공식 문서의 예제를 기반으로, 두 집합 `a`와 `b`에 대한 연산을 정의한다.

```python
>>> a = set('abracadabra')
>>> b = set('alacazam')
>>> a
{'a', 'r', 'b', 'c', 'd'}
>>> b
{'a', 'l', 'c', 'z', 'm'}
```

```
집합 a, b 시각화:

      a 전용         공통      b 전용
  ┌──────────┐  ┌─────────┐  ┌──────────┐
  │  r, b, d │  │  a, c   │  │  l, z, m │
  └──────────┘  └─────────┘  └──────────┘
```

**차집합(Difference): `a - b`**
a에는 있으나 b에는 없는 요소

```python
>>> a - b
{'r', 'b', 'd'}
```

**합집합(Union): `a | b`**
a 또는 b에 있는 모든 요소

```python
>>> a | b
{'a', 'c', 'r', 'd', 'b', 'm', 'z', 'l'}
```

**교집합(Intersection): `a & b`**
a와 b 모두에 있는 요소

```python
>>> a & b
{'a', 'c'}
```

**대칭차집합(Symmetric Difference): `a ^ b`**
a 또는 b 중 하나에만 있는 요소 (공통 요소 제외)

```python
>>> a ^ b
{'r', 'd', 'b', 'm', 'z', 'l'}
```

**연산자와 메서드 대응표**

```
연산          연산자   메서드
──────────────────────────────────────────────────
차집합         a - b    a.difference(b)
합집합         a | b    a.union(b)
교집합         a & b    a.intersection(b)
대칭차집합     a ^ b    a.symmetric_difference(b)
부분집합 여부  a <= b   a.issubset(b)
상위집합 여부  a >= b   a.issuperset(b)
```

연산자 방식과 메서드 방식은 동일한 결과를 산출한다. 단, 메서드는 이터러블을 인자로 받을 수 있는 반면, 연산자는 양쪽 모두 집합이어야 한다.

```python
>>> a.union([1, 2, 3])    # ✅ 메서드: 이터러블 허용
>>> a | [1, 2, 3]         # ❌ 연산자: TypeError — 집합끼리만 가능
```

---

### 5-3. 요소 추가와 삭제

집합은 가변(mutable)이므로 생성 후에도 요소를 추가하거나 삭제할 수 있다.

```python
s = {'apple', 'banana'}

# 추가
s.add('cherry')
print(s)              # {'apple', 'banana', 'cherry'}

# 이미 존재하는 요소 추가 — 무시됨 (에러 없음)
s.add('apple')
print(s)              # {'apple', 'banana', 'cherry'} — 변화 없음

# 삭제 — remove(): 없으면 KeyError 발생
s.remove('banana')

# 삭제 — discard(): 없어도 에러 없음
s.discard('grape')    # 'grape'가 없어도 예외 미발생

# pop(): 임의의 요소 하나를 제거하고 반환 (순서 비보장)
item = s.pop()
```

```
remove() vs discard() 비교:

연산                    요소 존재     요소 부재
─────────────────────────────────────────────
s.remove('x')          삭제           KeyError 발생
s.discard('x')         삭제           무시 (예외 없음)
```

---

### 5-4. 중복 제거 활용 패턴

집합의 중복 불허 특성을 이용해 리스트에서 중복을 제거하는 관용적 패턴이다.

```python
# 리스트의 중복 제거
names = ['철수', '영희', '철수', '민수', '영희']
unique_names = list(set(names))
print(unique_names)   # ['민수', '철수', '영희'] — 순서 비보장
```

**단, 원래 순서의 보존이 필요한 경우 이 방법은 적합하지 않다.** 순서를 유지하면서 중복을 제거하려면 `dict.fromkeys()`를 활용한다.

```python
# 순서를 보존하며 중복 제거 (Python 3.7+ 딕셔너리 삽입 순서 보장 활용)
unique_ordered = list(dict.fromkeys(names))
print(unique_ordered)   # ['철수', '영희', '민수'] — 원래 순서 유지
```

## 6. 핵심 요약 및 주의점

**핵심 요약**

- 집합은 **중복 없는 비순서 컬렉션**이다. 인덱싱·슬라이싱이 불가능하다.
- **빈 집합**은 `set()`으로 생성해야 한다. `{}`는 빈 딕셔너리다.
- 멤버십 검사(`in`)는 **평균 O(1)**으로, 리스트의 O(n)에 비해 대량 데이터 처리 시 우위를 갖는다.
- 집합의 요소는 **해시 가능한 불변 객체**여야 한다. 리스트, 딕셔너리는 요소로 사용 불가.
- 합집합(`|`), 교집합(`&`), 차집합(`-`), 대칭차집합(`^`) 연산자를 지원한다.
- 연산자는 집합끼리만 사용 가능하며, 메서드는 이터러블도 인자로 허용한다.

**주의점**

```
상황                          올바른 방법          잘못된 방법
──────────────────────────────────────────────────────────────
빈 집합 생성                  set()                {} (빈 딕셔너리)
없는 요소 안전 삭제            discard()            remove() → KeyError
집합 + 리스트 연산             .union([...])        set | list → TypeError
중복 제거 후 순서 보존         dict.fromkeys()      set() → 순서 비보장
```
