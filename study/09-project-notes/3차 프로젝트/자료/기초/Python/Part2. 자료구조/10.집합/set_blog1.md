## 1. 한 줄 요약

집합은 **중복 없이, 순서 없이 값을 모아두는 자료구조**다. 리스트와 비슷해 보이지만 중복을 자동으로 제거하고, 두 묶음 사이의 공통점·차이점을 한 번에 구할 수 있는 수학적 연산이 강점이다.

---

## 2. 왜 집합이 필요할까?

쇼핑몰에서 오늘 방문한 사용자 목록을 분석한다고 해보자. 한 사람이 여러 번 방문하면 리스트에는 중복으로 쌓인다.

```python
visitors = ["김정민", "이재홍", "김정민", "양정현", "이재홍", "김정민"]
print(len(visitors))   # 6 — 방문 횟수는 6번이지만
```

실제 방문자 수(중복 제거)를 알고 싶다면? 리스트로는 직접 중복을 제거하는 코드를 짜야 한다. 집합을 쓰면 한 줄로 끝난다.

```python
unique_visitors = set(visitors)
print(unique_visitors)   # {'김정민', '이재홍', '양정현'}
print(len(unique_visitors))   # 3 — 실제 방문자 수
```

또 하나의 강점은 **집합 연산**이다. A반과 B반이 겹치는 학생이 누구인지, 어느 한 반에만 있는 학생이 누구인지를 수학의 교집합·차집합으로 단 한 줄에 구할 수 있다. 집합은 바로 이런 상황을 위해 태어난 자료구조다.

---

## 3. 핵심 아이디어 — 집합은 "멤버십 명단"이다

집합을 **중복 없는 멤버십 명단**으로 생각해보자.

헬스장 회원 명단을 생각해보면, 한 사람이 두 번 등록되는 일은 없다. 이미 회원이라면 또 추가해도 명단은 그대로다. 그리고 명단에는 순서가 없다. "3번째 회원이 누구야?"라고 묻는 게 아니라 "이 사람이 회원이야?"라고 묻는 방식으로 쓴다.

```
리스트: [1, 2, 2, 3, 3, 3]   ← 순서 있음, 중복 허용
집합:   {1, 2, 3}             ← 순서 없음, 중복 자동 제거
```

집합의 세 가지 핵심 특징을 정리하면 이렇다.

```
✅ 중복 없음  — 같은 값을 두 번 넣어도 하나만 유지된다
✅ 순서 없음  — 인덱스[0], [1]로 접근할 수 없다
✅ 집합 연산  — 합집합·교집합·차집합을 한 줄로 구할 수 있다
```

---

## 4. 동작 과정 살펴보기

### 4-1. 집합 만들기

집합은 중괄호 `{ }`를 사용하거나 `set()` 함수로 만든다. 딕셔너리도 `{ }`를 쓰기 때문에 헷갈릴 수 있는데, **딕셔너리는 `키: 값` 쌍**으로 이루어지고 **집합은 값만** 들어간다는 차이가 있다.

```python
# 중괄호로 직접 생성
fruits = {"apple", "banana", "cherry"}

# set() 함수로 생성 — 리스트, 튜플, 문자열도 변환 가능
nums = set([1, 2, 3, 4, 5])
chars = set("hello")   # 문자열 → 각 글자가 요소가 됨
print(chars)           # {'h', 'e', 'l', 'o'} — 중복 l이 하나로 합쳐짐
```

빈 집합을 만들 때는 주의가 필요하다. `{}`는 빈 딕셔너리로 인식되기 때문에, 빈 집합은 반드시 `set()`으로 만들어야 한다.

```python
empty_dict = {}         # ← 이건 빈 딕셔너리!
empty_set  = set()      # ← 빈 집합은 반드시 set()으로
```

---

### 4-2. 중복이 자동으로 제거된다

집합의 가장 편리한 특성이다. 중복된 값을 넣어도 하나만 남는다. 어떤 과정으로 일어나는지 살펴보자.

```python
numbers = {1, 2, 2, 3, 3, 3, 4}
print(numbers)   # {1, 2, 3, 4}
```

```
입력: {1, 2, 2, 3, 3, 3, 4}
           ↓  ↓     ↓  ↓
      중복된 값은 자동으로 제거됨
           ↓
결과: {1, 2, 3, 4}
```

이 특성은 리스트에서 중복을 제거할 때 매우 유용하게 활용된다.

```python
# 리스트의 중복 제거 — set()으로 변환했다가 다시 list()로
names = ["철수", "영희", "철수", "민수", "영희"]
unique_names = list(set(names))
print(unique_names)   # ['철수', '영희', '민수'] (순서는 바뀔 수 있음)
```

단, 집합으로 변환하면 **순서가 보장되지 않는다.** 원래 리스트의 순서가 중요하다면 다른 방법을 써야 한다.

---

### 4-3. 인덱스로 접근할 수 없다

집합은 순서가 없기 때문에 리스트처럼 번호(인덱스)로 값을 꺼낼 수 없다. `fruits[0]` 같은 접근을 시도하면 즉시 에러가 난다.

```python
fruits = {"apple", "banana", "cherry"}
print(fruits[0])   # ❌ TypeError: 'set' object is not subscriptable
```

왜 인덱스가 없을까? 집합은 "순서"가 아닌 "속해 있는가 아닌가"에 집중하는 자료구조이기 때문이다. 헬스장 명단에서 "3번째 회원이 누구야?"는 의미 없는 질문이지만, "이 사람이 회원이야?"는 핵심 질문인 것과 같다.

집합에서 특정 값에 접근하는 올바른 방법은 두 가지다.

```python
# 방법 1: in 연산자로 포함 여부 확인
print("apple" in fruits)    # True  — 있음
print("grape" in fruits)    # False — 없음

# 방법 2: for 반복문으로 전체 순회
for fruit in fruits:
    print(fruit)
# apple, banana, cherry (출력 순서는 매번 달라질 수 있음)
```

## 5. 구현 코드 및 상세 설명

### 5-1. 요소 추가와 삭제

집합에 값을 하나 추가할 때는 `add()`, 여러 개를 한꺼번에 추가할 때는 `update()`를 쓴다. 리스트의 `append()`와 `extend()`에 대응된다고 보면 된다.

```python
fruits = {"apple", "banana"}

# add() — 요소 하나 추가
fruits.add("cherry")
print(fruits)   # {'apple', 'banana', 'cherry'}

# 이미 있는 값을 추가하면? 아무 변화도 없음 (에러도 안 남)
fruits.add("apple")
print(fruits)   # {'apple', 'banana', 'cherry'} — 그대로

# update() — 여러 요소 한꺼번에 추가
fruits.update(["mango", "grape"])
print(fruits)   # {'apple', 'banana', 'cherry', 'mango', 'grape'}
```

삭제 방법은 두 가지가 있는데, 없는 값을 삭제하려 할 때 동작이 다르다.

```python
fruits = {"apple", "banana", "cherry"}

# remove() — 삭제, 없으면 KeyError 발생
fruits.remove("banana")
print(fruits)        # {'apple', 'cherry'}
fruits.remove("grape")  # ❌ KeyError: 'grape' — 없는 값을 지우려 하면 에러!

# discard() — 삭제, 없어도 에러 없이 조용히 넘어감
fruits.discard("cherry")
print(fruits)        # {'apple'}
fruits.discard("grape")  # ✅ 에러 없음 — 없는 값이어도 그냥 무시
```

어떤 걸 써야 할까? **"이 값이 확실히 있다"고 보장할 수 있다면 `remove()`**, 없을 수도 있는 상황이라면 `discard()`가 더 안전하다.

```
remove()  → 없으면 에러 (KeyError)  — 확실히 있을 때
discard() → 없어도 무시             — 있는지 모를 때
```

### 5-2. 집합 연산 — 집합의 진짜 강점

집합이 리스트·딕셔너리와 가장 크게 다른 점이 여기다. 수학의 집합 연산(합집합·교집합·차집합·대칭차집합)을 코드 한 줄로 구할 수 있다.

두 그룹의 데이터가 있다고 하자.

```python
set_a = {1, 2, 3, 4, 5}   # A 그룹
set_b = {4, 5, 6, 7, 8}   # B 그룹
```

```
시각화:

  A 그룹          B 그룹
{ 1, 2, 3, [4, 5], 6, 7, 8 }
            ↑  ↑
         겹치는 부분
```

---

**합집합 — 두 집합을 모두 합친 것**

A에도 있고, B에도 있는 것, 즉 **전부 다 모은** 집합이다. 중복은 제거되어 하나만 남는다.

```python
union = set_a | set_b              # | 연산자
union = set_a.union(set_b)         # 메서드
print(union)   # {1, 2, 3, 4, 5, 6, 7, 8}
```

```
A: { 1, 2, 3, 4, 5 }
B: {          4, 5, 6, 7, 8 }
              ↓
합집합: { 1, 2, 3, 4, 5, 6, 7, 8 }  ← 4, 5 중복 제거
```

실생활 예: 월요일 수업 학생 명단 + 수요일 수업 학생 명단 → 전체 수강생 명단

---

**교집합 — 두 집합에 공통으로 있는 것**

A에도 있고 B에도 있는, **겹치는 부분만** 남긴 집합이다.

```python
inter = set_a & set_b                    # & 연산자
inter = set_a.intersection(set_b)        # 메서드
print(inter)   # {4, 5}
```

```
A: { 1, 2, 3, [4, 5] }
B: {          [4, 5], 6, 7, 8 }
                ↓
교집합: { 4, 5 }  ← 둘 다 가진 것만
```

실생활 예: A 서비스 가입자 집합 & B 서비스 가입자 집합 → 두 서비스 모두 이용하는 사람

---

**차집합 — 한 집합에는 있지만 다른 집합에는 없는 것**

A에서 B와 겹치는 부분을 **제거한** 집합이다. 순서가 중요하다. `A - B`와 `B - A`는 결과가 다르다.

```python
diff = set_a - set_b                    # - 연산자
diff = set_a.difference(set_b)          # 메서드
print(diff)   # {1, 2, 3}   ← A에만 있고 B에는 없는 것
print(set_b - set_a)   # {6, 7, 8}   ← B에만 있고 A에는 없는 것
```

```
A - B:
A: { [1, 2, 3], 4, 5 }
B: {             4, 5, 6, 7, 8 }
결과: { 1, 2, 3 }  ← A에서 공통(4, 5)을 뺀 것

B - A:
결과: { 6, 7, 8 }  ← B에서 공통(4, 5)을 뺀 것
```

실생활 예: 전체 회원 명단 - 이미 결제한 회원 명단 = 아직 결제 안 한 회원 명단

---

**대칭차집합 — 공통 부분을 제외한 나머지 전부**

두 집합에서 **공통된 부분만 빼고** 나머지를 모두 모은 집합이다. "어느 한쪽에만 속한 것들"이라고 생각하면 된다.

```python
sym = set_a ^ set_b                              # ^ 연산자
sym = set_a.symmetric_difference(set_b)          # 메서드
print(sym)   # {1, 2, 3, 6, 7, 8}
```

```
A: { [1, 2, 3], 4, 5 }
B: {             4, 5, [6, 7, 8] }
                 ↑  ↑
             공통(제거)
결과: { 1, 2, 3, 6, 7, 8 }  ← 공통(4, 5)만 빠진 나머지
```

실생활 예: A반 수강생과 B반 수강생 중 **한 반에만** 있는 학생 → 두 반을 동시에 듣는 학생은 제외

---

**집합 연산 한눈에 보기**

```
연산자   메서드                   의미             예시 결과
──────────────────────────────────────────────────────────────
  |      .union()             합집합 (전부 합침)   {1,2,3,4,5,6,7,8}
  &      .intersection()      교집합 (공통만)       {4, 5}
  -      .difference()        차집합 (한쪽만)       {1, 2, 3}
  ^      .symmetric_difference() 대칭차집합 (공통 제외) {1,2,3,6,7,8}
```

### 5-3. 자주 쓰는 기타 메서드

```python
s = {1, 2, 3, 4, 5}

print(len(s))          # 5     — 요소 개수
s.clear()              # 모든 요소 제거 → set()
s2 = s.copy()          # 집합 복사본 생성
```

`pop()`으로 요소를 하나 꺼낼 수도 있는데, 집합은 순서가 없기 때문에 **어떤 값이 제거될지 예측할 수 없다.** 특정 값을 지우고 싶다면 `remove()`나 `discard()`를 쓰는 것이 맞다.

```python
s = {1, 2, 3, 4, 5}
removed = s.pop()      # 임의의 값 하나가 제거되고 반환됨
print(removed)         # 1 (어떤 값이 나올지 보장 안 됨)
print(s)               # {2, 3, 4, 5}
```

### 5-4. frozenset — 수정 불가능한 집합

집합에도 튜플처럼 "변경 불가능한" 버전이 있다. `frozenset()`으로 만들면 수정이 막히는 대신, 딕셔너리의 Key나 다른 집합의 요소로 쓸 수 있다.

```python
# 일반 set — 수정 가능
s = {1, 2, 3}
s.add(4)   # ✅ 가능

# frozenset — 수정 불가능
fs = frozenset([1, 2, 3])
fs.add(4)  # ❌ AttributeError: 'frozenset' object has no attribute 'add'
```

실무에서 `frozenset`을 자주 쓰지는 않지만, "이 집합은 변하면 안 된다"는 의도를 코드로 표현할 때 사용한다.

## 6. 집합 vs 리스트 — 언제 뭘 쓸까?

```
항목              리스트 [ ]           집합 { }
──────────────────────────────────────────────────
순서              있음                  없음
중복              허용                  자동 제거
인덱스 접근       가능                  불가
집합 연산         없음                  합집합·교집합·차집합 가능
검색 속도         느림 (전체 탐색)      빠름 (즉시 확인)
```

판단 기준은 이렇다. **"값의 순서나 중복이 중요한가?"**

순서와 중복이 중요하다면 → **리스트**
- 성적 순위 목록
- 장바구니 (같은 물건 여러 개 담기 가능)

순서·중복이 필요 없고, 포함 여부나 두 그룹의 비교가 필요하다면 → **집합**
- 방문자 중복 제거
- 두 그룹의 공통 멤버 찾기
- 어떤 값이 목록에 있는지 빠르게 확인

---

## 7. 마지막 정리

- 집합은 **중복 없음, 순서 없음**이 핵심 특징이다.
- 빈 집합은 `{}`가 아니라 **반드시 `set()`으로** 만들어야 한다. `{}`는 빈 딕셔너리다.
- 인덱스로 접근할 수 없고, **`in` 연산자나 `for` 반복문으로만** 요소에 접근한다.
- 요소 삭제 시 **`remove()`는 없으면 에러, `discard()`는 없어도 무시**한다.
- 집합의 진짜 강점은 **`|` `&` `-` `^` 연산자**로 합집합·교집합·차집합·대칭차집합을 한 줄에 구하는 것이다.
- 리스트에서 **중복을 제거**하고 싶을 때 `list(set(리스트))`를 쓰면 간단하게 해결된다.
