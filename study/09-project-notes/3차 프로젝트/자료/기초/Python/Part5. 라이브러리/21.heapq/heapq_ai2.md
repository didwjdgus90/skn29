# [Python 기초] heapq (힙 / 우선순위 큐)

# 본문

## 1. 한 줄 요약

`heapq`는 여러 값 중에서 가장 작은 값을 먼저 꺼내야 할 때 사용하는 파이썬 도구이다.

`heapq`를 이해하면 줄을 세우지 않아도 가장 급한 일이나 가장 작은 값을 빠르게 처리할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

놀이공원에서 손님들이 놀이기구를 기다린다고 생각해 보자.

보통은 먼저 온 사람이 먼저 탄다.

하지만 병원 응급실처럼 더 급한 사람이 먼저 처리되어야 하는 상황도 있다.

```text
환자 A: 위험도 5
환자 B: 위험도 1
환자 C: 위험도 3
```

위험도 숫자가 작을수록 더 급하다고 하면, B가 가장 먼저 진료를 받아야 한다.

이런 상황에서는 단순히 먼저 온 순서가 아니라 **우선순위**가 중요하다.

매번 전체 명단을 정렬해서 가장 급한 사람을 찾을 수도 있다.

하지만 사람이 계속 들어오고 나가면 매번 줄 전체를 정리해야 해서 번거롭다.

`heapq`는 이런 상황에서 가장 우선순위가 높은 값을 빠르게 꺼내게 도와준다.

---

## 3. 핵심 아이디어

`heapq`는 “항상 가장 급한 사람만 앞에 보이게 해주는 대기줄”이라고 생각하면 쉽다.

일반 리스트는 줄이 아무렇게나 서 있을 수 있다.

```text
일반 대기줄

[5] [1] [3]
```

가장 작은 값인 1을 찾으려면 전체를 확인해야 한다.

하지만 힙은 가장 작은 값을 맨 앞에 둔다.

```text
힙 대기줄

[1] [5] [3]
 ↑
가장 먼저 꺼낼 값
```

여기서 중요한 점은 전체가 완벽히 정렬된 것은 아니라는 것이다.

```text
완전히 정렬된 줄

[1] [3] [5]

힙

[1] [5] [3]
```

힙은 줄 전체를 예쁘게 정리하는 것이 목표가 아니다.

**다음에 꺼낼 가장 작은 값만 빠르게 알 수 있게 하는 것**이 목표다.

---

## 4. 동작 과정 살펴보기

아래 코드를 하나씩 보자.

```python
import heapq

heap = []

heapq.heappush(heap, 4)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)
```

### Step 1. 빈 대기줄 만들기

```text
heap

[]
```

아직 아무 값도 없다.

### Step 2. 4를 넣는다

```text
heappush(heap, 4)

[4]
```

값이 하나뿐이므로 4가 맨 앞이다.

### Step 3. 1을 넣는다

```text
기존
[4]

1 삽입
[1] [4]
```

1이 4보다 작기 때문에 앞으로 이동한다.

가장 작은 값은 항상 앞에 있어야 한다.

### Step 4. 3을 넣는다

```text
기존
[1] [4]

3 삽입
[1] [4] [3]
```

3은 1보다 크므로 1은 계속 맨 앞에 있다.

### Step 5. 가장 작은 값 꺼내기

```python
heapq.heappop(heap)
```

```text
꺼낸 값

1
```

남은 힙은 다시 정리된다.

```text
남은 값

[3] [4]
```

다음에 꺼내면 3이 나오고, 그다음 4가 나온다.

```text
꺼내는 순서

1 → 3 → 4
```

## 5. 구현 코드 및 상세 설명

```python
import heapq

# 해야 할 일 목록
# 숫자가 작을수록 더 급한 일이라고 가정
todo = []

heapq.heappush(todo, (3, "방 청소하기"))
heapq.heappush(todo, (1, "과제 제출하기"))
heapq.heappush(todo, (2, "이메일 확인하기"))

while todo:
    priority, task = heapq.heappop(todo)
    print("지금 할 일:", task, "/ 우선순위:", priority)
```

### 코드 설명

```python
todo = []
```

할 일을 담을 빈 힙을 만든다.

파이썬에서는 리스트를 힙처럼 사용한다.

```python
heapq.heappush(todo, (3, "방 청소하기"))
```

할 일을 힙에 넣는다.

여기서는 `(우선순위, 할 일)` 형태로 넣었다.

튜플은 앞의 값부터 비교된다.

그래서 우선순위 숫자가 작은 일이 먼저 나온다.

```python
priority, task = heapq.heappop(todo)
```

가장 우선순위가 높은 일을 꺼낸다.

```text
저장된 일

(3, "방 청소하기")
(1, "과제 제출하기")
(2, "이메일 확인하기")

처리 순서

과제 제출하기 → 이메일 확인하기 → 방 청소하기
```

### 가장 큰 값을 먼저 꺼내고 싶을 때

파이썬 `heapq`는 기본적으로 작은 값이 먼저 나온다.

큰 값을 먼저 꺼내고 싶다면 음수로 바꿔 넣을 수 있다.

```python
scores = [80, 95, 70]
heap = []

for score in scores:
    heapq.heappush(heap, -score)

print(-heapq.heappop(heap))
```

```text
점수 저장

80  → -80
95  → -95
70  → -70

가장 작은 음수 -95가 먼저 나옴
다시 부호를 바꾸면 95
```

---

## 6. 마지막 정리

`heapq`는 가장 작은 값을 먼저 꺼낼 수 있게 해준다.

힙은 전체를 완벽하게 정렬하지 않고, 가장 작은 값만 앞에 오도록 관리한다.

`heappush()`는 값을 넣는 함수이다.

`heappop()`은 가장 작은 값을 꺼내는 함수이다.

우선순위가 있는 작업을 처리할 때 `heapq`를 떠올리면 좋다.
