## 1. 한 줄 요약

`heapq`는 **항상 가장 작은 값을 빠르게 꺼낼 수 있는 자료구조(최소 힙)**를 파이썬에서 쓸 수 있게 해주는 모듈이다. 데이터가 아무리 많아도 최솟값을 꺼내는 속도가 일정하게 빠르다는 것이 핵심이다.

---

## 2. 왜 heapq가 필요할까?

숫자 리스트에서 가장 작은 값을 반복해서 꺼내야 하는 상황을 생각해보자.

```python
nums = [5, 3, 8, 1, 9, 2]

# 방법 1: 매번 정렬해서 꺼내기
nums.sort()
print(nums.pop(0))   # 1 꺼냄

nums.sort()          # 또 정렬
print(nums.pop(0))   # 2 꺼냄
```

값을 꺼낼 때마다 전체를 다시 정렬하는 건 매우 비효율적이다. 데이터가 많을수록 점점 느려진다.

```python
# 방법 2: heapq 사용
import heapq

nums = [5, 3, 8, 1, 9, 2]
heapq.heapify(nums)           # 한 번만 변환

print(heapq.heappop(nums))    # 1 꺼냄 — 빠름!
print(heapq.heappop(nums))    # 2 꺼냄 — 빠름!
```

힙은 "항상 최솟값이 맨 위에 있는 구조"를 유지하면서, **최솟값을 꺼내는 연산이 매우 빠르다**. 전체를 다시 정렬할 필요가 없다.

---

## 3. 핵심 아이디어 — 힙은 "우선순위 대기줄"이다

힙을 **우선순위가 있는 대기줄**로 생각해보자.

일반 줄(리스트)은 먼저 온 사람이 먼저 나간다. 하지만 응급실은 다르다. 나중에 왔어도 **더 위급한 환자가 먼저 진료를 받는다.** 이것이 우선순위 큐(Priority Queue)의 개념이고, 힙은 이를 효율적으로 구현한 자료구조다.

```
일반 리스트 (선입선출):         힙 (우선순위 순서):
  [5, 3, 8, 1, 9, 2]            항상 최솟값이 맨 위
  → pop(0)하면 5 나옴           → heappop()하면 1 나옴
     (맨 앞 것)                    (가장 작은 것)
```

파이썬의 `heapq`는 **최소 힙(Min Heap)**만 기본 제공한다. 최솟값이 항상 맨 앞(`heap[0]`)에 있다.

---

## 4. 힙의 내부 구조 — 어떻게 항상 최솟값이 위에 있을까?

힙을 완전히 이해하려면 내부 구조를 알 필요는 없지만, 직관적으로 이해하면 훨씬 쓰기 편하다.

힙은 **완전이진트리(Complete Binary Tree)** 구조로 이루어진다. 트리란 부모-자식 관계로 연결된 구조인데, 힙에는 딱 하나의 규칙이 있다.

> **부모 노드의 값은 항상 자식 노드의 값보다 작거나 같다 (최소 힙)**

```
        1          ← 루트(맨 위) = 항상 최솟값
       / \
      3   2
     / \ / \
    5  4 8  9
```

이 규칙 덕분에 **루트(맨 위)에는 항상 전체에서 가장 작은 값이 온다.** 값을 꺼낼 때마다 이 규칙을 유지하도록 자동으로 재정렬된다.

파이썬에서 힙은 리스트로 표현된다. 위의 트리를 리스트로 표현하면 이렇다.

```
트리:       1
           / \
          3   2
         / \ / \
        5  4 8  9

리스트: [1, 3, 2, 5, 4, 8, 9]
인덱스:  0  1  2  3  4  5  6

규칙: k번째 노드의 자식은 항상 (2k+1), (2k+2)번째
     → 0번(1)의 자식: 1번(3), 2번(2) ✅ 1 < 3, 1 < 2
     → 1번(3)의 자식: 3번(5), 4번(4) ✅ 3 < 5, 3 < 4
```

직접 이 구조를 만들 필요는 없다. `heapq` 함수들이 알아서 이 구조를 유지해준다.

## 5. 동작 과정 살펴보기

### 5-1. 힙 만들기

**방법 1: 빈 힙에 하나씩 추가 — `heappush()`**

빈 리스트를 만들고 `heappush()`로 값을 하나씩 넣는다. 값을 넣을 때마다 힙 구조가 자동으로 유지된다.

```python
import heapq

heap = []
heapq.heappush(heap, 5)
heapq.heappush(heap, 3)
heapq.heappush(heap, 8)
heapq.heappush(heap, 1)

print(heap)   # [1, 3, 8, 5]  ← 최솟값 1이 맨 앞
```

```
추가 과정:

push(5):  [5]
push(3):  [3, 5]           ← 3이 5보다 작으니 위로 올라옴
push(8):  [3, 5, 8]
push(1):  [1, 3, 8, 5]     ← 1이 가장 작으니 맨 위로 올라옴
```

**방법 2: 기존 리스트를 힙으로 변환 — `heapify()`**

이미 값이 들어있는 리스트를 힙 구조로 한 번에 변환한다. 새 리스트를 만들지 않고 **원본 리스트 자체가 변환**된다.

```python
nums = [5, 3, 8, 1, 9, 2]
heapq.heapify(nums)
print(nums)   # [1, 3, 2, 5, 9, 8]  ← 힙 구조로 재배열됨
              #  ↑ 맨 앞이 최솟값(1)
```

> 💡 `heapify()` 후 리스트가 완전히 정렬된 것처럼 보이지 않아도 괜찮다. **`heap[0]`이 최솟값이라는 것만 보장**되면 된다.

### 5-2. 최솟값 꺼내기 — `heappop()`

`heappop()`은 힙에서 **가장 작은 값을 꺼내면서 동시에 힙 구조를 자동으로 복원**한다.

```python
heap = []
for num in [5, 3, 8, 1, 9, 2]:
    heapq.heappush(heap, num)

print(heapq.heappop(heap))   # 1  ← 최솟값
print(heapq.heappop(heap))   # 2  ← 다음 최솟값
print(heapq.heappop(heap))   # 3
print(heap)                  # [5, 9, 8]  ← 나머지
```

```
heappop() 동작:

힙: [1, 3, 2, 5, 9, 8]
      ↑ 최솟값(1) 꺼냄
      → 힙 구조 자동 복원
힙: [2, 3, 8, 5, 9]
      ↑ 새로운 최솟값(2)이 맨 앞으로
```

**삭제 없이 최솟값만 확인하려면** `heap[0]`으로 접근한다.

```python
print(heap[0])   # 꺼내지 않고 최솟값만 확인
```

## 6. 구현 코드 및 상세 설명

### 6-1. 최대 힙 구현하기

파이썬 `heapq`는 **최소 힙만** 제공한다. 최댓값을 빠르게 꺼내야 할 때는 **값에 `-`(마이너스)를 붙여서** 저장하는 트릭을 쓴다.

작은 값이 맨 위에 오는 구조에서, 음수로 뒤집으면 **원래 가장 큰 값의 음수가 가장 작은 음수**가 되어 맨 위에 오게 된다.

```
원래 값:    1  3  5  7  9
음수로 변환: -1 -3 -5 -7 -9
최소 힙 적용: -9가 맨 위 (가장 작은 음수)
꺼낸 뒤 다시 음수: -(-9) = 9  ← 원래 최댓값!
```

```python
heap_items = [1, 3, 5, 7, 9]
max_heap = []

for item in heap_items:
    heapq.heappush(max_heap, -item)   # 음수로 뒤집어서 저장

# 최댓값 꺼내기
max_val = -heapq.heappop(max_heap)   # 꺼낸 후 다시 음수로 뒤집음
print(max_val)   # 9  ← 원래 최댓값
```

튜플로 저장하면 원본값도 함께 보관할 수 있어 더 명확하다.

```python
max_heap = []
for item in [1, 3, 5, 7, 9]:
    heapq.heappush(max_heap, (-item, item))   # (-음수, 원본값) 튜플

max_val = heapq.heappop(max_heap)[1]   # 튜플의 두 번째 값(원본)을 꺼냄
print(max_val)   # 9
```

### 6-2. 튜플로 우선순위 지정하기

숫자 외에 **여러 정보를 담은 데이터를 우선순위 기준으로** 정렬할 때 튜플을 쓴다. 파이썬은 튜플을 비교할 때 첫 번째 요소 → 두 번째 요소 순서로 비교하므로, 첫 번째 자리에 **우선순위 기준값**을 넣으면 된다.

```python
# (비용, 도시이름) 형태로 저장 — 비용이 낮은 순서로 꺼내짐
heap = []
heapq.heappush(heap, (3, "서울"))
heapq.heappush(heap, (1, "부산"))
heapq.heappush(heap, (2, "대구"))

print(heapq.heappop(heap))   # (1, '부산')  ← 비용이 가장 낮은 것
print(heapq.heappop(heap))   # (2, '대구')
print(heapq.heappop(heap))   # (3, '서울')
```

이 패턴은 **다익스트라 알고리즘**에서 "거리가 가장 짧은 노드를 빠르게 꺼내는 용도"로 핵심적으로 활용된다.

---

### 6-3. N번째 최솟값 / 최댓값 구하기

리스트에서 가장 작은(또는 큰) N개를 뽑을 때 `heapq.nsmallest()`, `heapq.nlargest()`를 쓸 수 있다.

```python
nums = [5, 3, 8, 1, 9, 2, 7, 4]

print(heapq.nsmallest(3, nums))   # [1, 2, 3]  ← 가장 작은 3개
print(heapq.nlargest(3, nums))    # [9, 8, 7]  ← 가장 큰 3개
```

리스트 전체를 정렬하지 않고 상위/하위 N개만 필요할 때 유용하다.

### 6-4. 종합 예제 — "더 맵게" 문제 유형

힙의 강점이 잘 드러나는 대표적인 패턴이다. **리스트에서 가장 작은 두 값을 반복해서 꺼내 합치는** 유형이다.

**문제:** 음식의 스코빌 지수 리스트가 있다. 모든 음식이 K 이상이 될 때까지, 가장 스코빌이 낮은 두 음식을 섞는다. 섞는 공식: `새 스코빌 = 첫 번째 + (두 번째 × 2)`. 최소 몇 번 섞어야 하는지 구하라.

```python
import heapq

def solution(scoville, K):
    heapq.heapify(scoville)   # 리스트를 힙으로 변환
    count = 0

    while scoville[0] < K:    # 최솟값(heap[0])이 K보다 작으면 반복
        if len(scoville) < 2:
            return -1          # 섞을 음식이 1개뿐이면 불가능

        first = heapq.heappop(scoville)    # 가장 낮은 스코빌
        second = heapq.heappop(scoville)   # 두 번째로 낮은 스코빌

        new_scoville = first + second * 2
        heapq.heappush(scoville, new_scoville)  # 섞은 결과를 다시 힙에 추가
        count += 1

    return count
```

```
동작 흐름 예시: scoville = [1, 2, 3, 9, 10, 12], K = 7

초기 힙: [1, 2, 3, 9, 10, 12]
         ↑ 최솟값 1 < 7, 실행

step 1: first=1, second=2 → 1 + 2*2 = 5 → 힙에 추가
        힙: [3, 5, 12, 9, 10]

step 2: first=3, second=5 → 3 + 5*2 = 13 → 힙에 추가
        힙: [9, 10, 12, 13]

최솟값 9 >= 7 → 종료
결과: 2회
```

이처럼 "현재 가장 작은 값을 반복해서 꺼내야 할 때" 힙이 없다면 매번 정렬해야 하지만, 힙을 쓰면 효율적으로 해결할 수 있다.

## 7. 리스트 정렬 vs heapq — 언제 뭘 쓸까?

```
상황                            추천
────────────────────────────────────────────────────────
전체 데이터를 오름차순 정렬     sorted() 또는 .sort()
최솟값/최댓값 딱 한 번만 꺼냄  min() / max()
최솟값을 반복해서 계속 꺼냄    heapq ← 이때 가장 빠름
우선순위 기반 처리가 필요할 때  heapq
다익스트라, 프림 알고리즘       heapq 필수
```

핵심은 **"최솟값을 여러 번 꺼내야 하는 상황"**에서 heapq가 진가를 발휘한다는 것이다. 한 번 꺼낼 거라면 그냥 `min()`을 쓰는 게 낫다.

## 8. 주요 함수 정리

```python
import heapq

heap = []

heapq.heappush(heap, 값)       # 힙에 값 추가 (힙 구조 자동 유지)
heapq.heappop(heap)            # 최솟값 꺼내기 (힙 구조 자동 복원)
heapq.heapify(리스트)           # 기존 리스트를 힙으로 변환 (원본 변경)
heap[0]                        # 최솟값 확인 (꺼내지 않음)

heapq.nsmallest(n, 리스트)     # 가장 작은 n개 반환
heapq.nlargest(n, 리스트)      # 가장 큰 n개 반환
```

## 9. 마지막 정리

- `heapq`는 **항상 최솟값이 맨 앞(`heap[0]`)에 오는 최소 힙**을 구현한다.
- `heappush()`로 값을 추가하고, `heappop()`으로 최솟값을 꺼낸다. 둘 다 힙 구조를 **자동으로 유지**한다.
- `heapify()`는 기존 리스트를 힙으로 변환한다. **원본 리스트 자체가 변환**된다는 점에 주의하자.
- **최대 힙**이 필요하면 값을 넣을 때 **`-`(음수)로 뒤집어** 저장하고, 꺼낼 때 다시 `-`를 붙인다.
- **튜플 `(우선순위, 데이터)`** 형태로 저장하면 원하는 기준으로 우선순위를 정할 수 있다.
- "현재 가장 작은 값을 반복해서 꺼내야 할 때" 전체 정렬보다 heapq가 훨씬 빠르다.
