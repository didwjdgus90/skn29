# [Python 기초] 시간복잡도 기초 (Big-O)

# 본문

## 1. 한 줄 요약

시간복잡도는 입력 크기 `n`에 대해 알고리즘의 연산 횟수가 어떤 성장률로 증가하는지 나타내는 분석 기준이다.

시간복잡도를 이해하면 입력 제한에 맞는 알고리즘을 선택하고, 비효율적인 풀이를 사전에 걸러낼 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

코딩 테스트 문제에는 제한 시간이 있다.

따라서 단순히 올바른 답을 내는 알고리즘이 아니라, 입력 크기 안에서 실행 가능한 알고리즘을 선택해야 한다.

예를 들어 입력 크기 `n`이 100일 때는 `O(n²)` 풀이도 충분히 가능할 수 있다.

하지만 `n`이 100,000이라면 `O(n²)` 풀이는 현실적으로 어렵다.

```text
n = 100
n² = 10,000

n = 100,000
n² = 10,000,000,000
```

시간복잡도는 실제 실행 시간을 정확히 초 단위로 계산하지 않는다.

대신 입력 크기가 커질 때 연산량이 증가하는 형태를 분석한다.

이를 통해 다음과 같은 판단을 할 수 있다.

```text
완전탐색이 가능한가?
정렬이 필요한가?
해시나 힙 같은 자료구조가 필요한가?
이중 반복문을 줄일 방법이 있는가?
```

---

## 3. 핵심 아이디어

시간복잡도 분석에서는 작은 상수나 낮은 차수보다 가장 빠르게 증가하는 항을 중요하게 본다.

예를 들어 어떤 코드의 연산량이 다음과 같다고 하자.

```text
3n² + 10n + 5
```

입력 크기 `n`이 커질수록 가장 큰 영향을 주는 항은 `n²`이다.

그래서 시간복잡도는 `O(n²)`으로 표현한다.

```text
3n² + 10n + 5 → O(n²)
```

대표적인 시간복잡도는 다음과 같다.

```text
O(1)        상수 시간
O(log n)    로그 시간
O(n)        선형 시간
O(n log n)  선형 로그 시간
O(n²)       이차 시간
O(2^n)      지수 시간
```

코드 구조와 시간복잡도는 밀접한 관련이 있다.

```text
단순 인덱스 접근        → O(1)
단일 반복문             → O(n)
중첩 반복문             → O(n²)
입력을 절반씩 줄이는 반복 → O(log n)
정렬                    → O(n log n)
```

## 4. 동작 과정 살펴보기

### 4-1. 상수 시간 O(1)

```python
value = arr[0]
```

리스트의 첫 번째 원소에 접근한다.

입력 크기가 10이든 1,000,000이든 한 번의 접근으로 끝난다.

```text
arr 길이 = n

작업 횟수 = 1
```

따라서 `O(1)`이다.

### 4-2. 선형 시간 O(n)

```python
total = 0

for x in arr:
    total += x
```

모든 원소를 한 번씩 확인한다.

```text
arr 길이 = n

작업 횟수 ≈ n
```

따라서 `O(n)`이다.

### 4-3. 이차 시간 O(n²)

```python
for i in range(n):
    for j in range(n):
        print(i, j)
```

바깥 반복문이 n번 실행되고, 각 반복마다 안쪽 반복문이 n번 실행된다.

```text
전체 반복 횟수 = n × n = n²
```

따라서 `O(n²)`이다.

### 4-4. 로그 시간 O(log n)

```python
while n > 1:
    n //= 2
```

입력 크기가 매번 절반으로 감소한다.

```text
n = 32

32 → 16 → 8 → 4 → 2 → 1
```

반복 횟수는 입력 크기 자체가 아니라, 몇 번 절반으로 나눌 수 있는지에 비례한다.

따라서 `O(log n)`이다.

## 5. 구현 코드 및 상세 설명

```python
def get_first(arr):
    return arr[0]


def sum_all(arr):
    total = 0

    for x in arr:
        total += x

    return total


def print_all_pairs(arr):
    for a in arr:
        for b in arr:
            print(a, b)


def count_halving(n):
    count = 0

    while n > 1:
        n //= 2
        count += 1

    return count


def sort_values(arr):
    return sorted(arr)
```

원소 수가 n개이면 n번 더하므로 `O(n)`이다.

바깥 반복 n번, 안쪽 반복 n번이므로 `O(n²)`이다.

n을 1 이하가 될 때까지 계속 절반으로 나눈다.

반복 횟수는 `log n`에 비례한다.

정렬은 비용이 있지만, 이후 탐색이나 그리디 판단을 쉽게 만들기 때문에 자주 활용된다.

## 6. 마지막 정리

시간복잡도는 입력 크기에 따른 연산량 증가율을 표현한다.

상수와 낮은 차수보다 가장 빠르게 증가하는 항을 기준으로 분석한다.

단일 반복문은 보통 `O(n)`, 중첩 반복문은 보통 `O(n²)`이다.

입력을 절반씩 줄이는 구조는 보통 `O(log n)`이다.

입력 제한을 먼저 확인하고 가능한 시간복잡도를 예상한 뒤 풀이를 설계해야 한다.
