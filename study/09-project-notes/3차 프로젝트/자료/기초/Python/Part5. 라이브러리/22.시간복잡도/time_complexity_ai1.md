# [Python 기초] 시간복잡도 기초 (Big-O)

# 본문

## 1. 한 줄 요약

시간복잡도는 입력이 많아질수록 코드가 얼마나 많은 일을 하게 되는지 대략적으로 표현하는 방법이다.

시간복잡도를 이해하면 코딩 테스트에서 어떤 코드가 빠르고 어떤 코드가 느릴지 미리 예상할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

코딩 테스트에서는 정답을 맞히는 것만큼 시간 안에 끝내는 것도 중요하다.

예를 들어 친구 이름을 찾는 프로그램을 만든다고 해보자.

친구가 5명이라면 하나씩 확인해도 금방 끝난다.

```text
친구 5명 확인
금방 끝남
```

하지만 친구가 1,000,000명이라면 어떨까?

하나씩 모두 확인하는 방법은 오래 걸릴 수 있다.

```text
친구 1,000,000명 확인
풀이 방법에 따라 오래 걸림
```

시간복잡도는 코드가 실제로 몇 초 걸리는지 정확히 말하는 도구가 아니다.

대신 입력이 커질 때 일이 얼마나 빠르게 늘어나는지 알려준다.

```text
입력이 10배가 되면
일도 10배 늘어나는가?
100배 늘어나는가?
거의 안 늘어나는가?
```

이 차이를 알기 위해 시간복잡도를 배운다.

---

## 3. 핵심 아이디어

시간복잡도는 청소해야 할 방 개수와 비슷하다.

방이 1개면 한 번 청소하면 된다.

방이 10개면 10번 청소해야 한다.

```text
방 1개  → 청소 1번
방 5개  → 청소 5번
방 10개 → 청소 10번
```

이런 경우는 입력 개수만큼 일이 늘어난다.

보통 `O(n)`이라고 한다.

그런데 모든 방의 물건을 다른 모든 방의 물건과 비교해야 한다면 어떨까?

```text
1번 방 물건과 모든 방 물건 비교
2번 방 물건과 모든 방 물건 비교
3번 방 물건과 모든 방 물건 비교
...
```

방이 10개면 대략 100번 비교할 수 있다.

```text
10 × 10 = 100
```

이런 경우는 `O(n²)`이라고 한다.

시간복잡도는 코드가 얼마나 많은 일을 하는지 보는 돋보기이다.

## 4. 동작 과정 살펴보기

### 4-1. O(1): 한 칸만 보기

```python
numbers = [10, 20, 30, 40]
print(numbers[0])
```

```text
[10] [20] [30] [40]
 ↑
여기만 봄
```

리스트 길이가 길어져도 첫 번째 칸만 본다.

```text
데이터 4개      → 1번 확인
데이터 100개    → 1번 확인
데이터 10000개  → 1번 확인
```

이런 경우는 `O(1)`이다.

### 4-2. O(n): 전체 한 번 보기

```python
for number in numbers:
    print(number)
```

```text
[10] [20] [30] [40]
 1번  2번  3번  4번
```

데이터가 4개면 4번 확인한다.

데이터가 100개면 100번 확인한다.

```text
데이터 n개 → n번 확인
```

이런 경우는 `O(n)`이다.

### 4-3. O(n²): 전체를 전체와 비교하기

```python
for a in numbers:
    for b in numbers:
        print(a, b)
```

데이터가 3개라고 해보자.

```text
numbers = [1, 2, 3]
```

동작은 다음과 같다.

```text
a = 1일 때: b = 1, 2, 3
a = 2일 때: b = 1, 2, 3
a = 3일 때: b = 1, 2, 3
```

총 9번 실행된다.

```text
3 × 3 = 9
```

데이터가 n개라면 n번 안에서 또 n번 반복하므로 `O(n²)`이다.

### 4-4. O(log n): 절반씩 줄이기

전화번호부에서 이름을 찾는 상황을 생각해 보자.

처음부터 한 장씩 넘기는 대신 중간을 펼쳐서 앞쪽인지 뒤쪽인지 판단하면 찾는 범위가 절반으로 줄어든다.

```text
1000명
↓ 절반 버림
500명
↓ 절반 버림
250명
↓ 절반 버림
125명
```

이렇게 매번 절반씩 줄어드는 경우는 `O(log n)`이라고 한다.

## 5. 구현 코드 및 상세 설명

```python
numbers = [1, 2, 3, 4, 5]

# O(1): 첫 번째 값만 확인
print(numbers[0])


# O(n): 모든 값의 합 구하기
total = 0

for number in numbers:
    total += number

print(total)


# O(n²): 모든 쌍 만들기
for a in numbers:
    for b in numbers:
        print(a, b)


# O(log n): 숫자를 계속 절반으로 줄이기
n = 16

while n > 1:
    n //= 2
    print(n)
```

### 코드 설명

```python
print(numbers[0])
```

리스트의 첫 번째 값만 꺼낸다.

입력 크기와 상관없이 한 번만 접근하므로 `O(1)`이다.

```python
for number in numbers:
    total += number
```

리스트 전체를 한 번 훑는다.

원소가 5개면 5번, 100개면 100번 반복한다.

```python
for a in numbers:
    for b in numbers:
        print(a, b)
```

반복문 안에 반복문이 있다.

원소 개수가 n개라면 대략 n × n번 실행된다.

```python
while n > 1:
    n //= 2
```

n을 매번 절반으로 줄인다.

이런 구조는 `O(log n)`으로 생각할 수 있다.

---

## 6. 마지막 정리

시간복잡도는 입력 크기에 따라 코드의 일의 양이 늘어나는 방식을 나타낸다.

`O(1)`은 입력이 커져도 거의 일정하다.

`O(n)`은 입력 개수만큼 일이 늘어난다.

`O(n²)`은 이중 반복문에서 자주 나타나며 입력이 커질수록 빠르게 느려진다.

`O(log n)`은 매번 범위를 절반씩 줄이는 상황에서 자주 나타난다.
