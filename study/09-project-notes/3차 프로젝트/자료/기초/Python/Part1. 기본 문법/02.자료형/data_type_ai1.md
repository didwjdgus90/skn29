# 제목
[Python 기초] 파이썬 자료형

# 본문

## 1. 한 줄 요약

자료형은 값의 종류를 구분하는 이름이며, 파이썬은 값이 숫자인지, 글자인지, 여러 값을 담은 묶음인지에 따라 다르게 다룬다.

자료형을 이해하면 변수에 들어간 값을 올바르게 계산하고, 비교하고, 저장할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

컴퓨터는 모든 값을 똑같이 다루지 않는다.

`10`은 숫자라서 더하기 계산을 할 수 있다.

하지만 `"10"`은 글자라서 숫자 계산이 아니라 문자열 연결로 처리될 수 있다.

```python
print(10 + 20)
print("10" + "20")
```

출력 결과는 다르다.

```text
30
1020
```

사람 눈에는 둘 다 10처럼 보일 수 있다.

하지만 파이썬은 숫자 `10`과 문자열 `"10"`을 완전히 다르게 본다.

자료형은 이런 혼란을 줄이기 위해 필요하다.

```text
10      → 정수 int
3.14    → 실수 float
"hello" → 문자열 str
True    → 불 bool
[1, 2]  → 리스트 list
```

자료형을 알면 "이 값으로 어떤 일을 할 수 있는지" 판단할 수 있다.

---

## 3. 핵심 아이디어

자료형은 물건을 분류하는 **상자 라벨**과 비슷하다.

마트에 가면 물건이 종류별로 나뉘어 있다.

```text
과일 코너     → 사과, 바나나
음료 코너     → 물, 주스
과자 코너     → 과자, 초콜릿
```

프로그래밍에서도 값마다 종류가 있다.

```text
숫자 상자     → 10, 20, 3.14
글자 상자     → "apple", "hello"
참/거짓 상자  → True, False
묶음 상자     → [1, 2, 3]
```

파이썬은 값의 자료형에 따라 사용할 수 있는 기능을 다르게 정한다.

숫자는 계산할 수 있고, 문자열은 글자를 붙이거나 자를 수 있다.

리스트는 여러 값을 한꺼번에 담고 꺼낼 수 있다.

---

## 4. 동작 과정 살펴보기

아래 예제를 보자.

```python
age = 20
name = "민수"
scores = [80, 90, 100]
is_passed = True
```

### Step 1. 정수 자료형

```text
age ─────▶ 20

20은 소수점이 없는 숫자
자료형: int
```

`age`에는 정수 값이 들어 있다.

정수는 더하기, 빼기, 곱하기 같은 계산에 사용할 수 있다.

### Step 2. 문자열 자료형

```text
name ─────▶ "민수"

"민수"는 글자 데이터
자료형: str
```

문자열은 따옴표로 감싼다.

글자 데이터를 다룰 때 사용한다.

### Step 3. 리스트 자료형

```text
scores ─────▶ [80, 90, 100]

index:        0   1   2
value:       80  90 100
```

리스트는 여러 값을 순서대로 담는 자료형이다.

시험 점수 여러 개처럼 한 묶음으로 다루고 싶은 값에 사용한다.

### Step 4. 불 자료형

```text
is_passed ─────▶ True

True  → 참
False → 거짓
```

불 자료형은 조건문에서 자주 사용된다.

예를 들어 합격 여부, 로그인 여부, 완료 여부처럼 참과 거짓으로 나뉘는 상황에 적합하다.

## 5. 구현 코드 및 상세 설명

```python
# 정수형: 소수점이 없는 숫자
student_count = 30

# 실수형: 소수점이 있는 숫자
average_score = 87.5

# 문자열: 글자 데이터
class_name = "Python 기초반"

# 불 자료형: 참 또는 거짓
is_open = True

# 리스트: 여러 값을 순서대로 저장
scores = [80, 90, 100]

print(type(student_count))
print(type(average_score))
print(type(class_name))
print(type(is_open))
print(type(scores))

print("반 이름:", class_name)
print("학생 수:", student_count)
print("평균 점수:", average_score)
print("첫 번째 점수:", scores[0])
```

### 코드 설명

```python
student_count = 30
```

학생 수는 소수점이 필요 없으므로 정수형 `int`로 저장된다.

```python
average_score = 87.5
```

평균 점수는 소수점이 필요할 수 있으므로 실수형 `float`로 저장된다.

```python
class_name = "Python 기초반"
```

반 이름은 글자이므로 문자열 `str`로 저장된다.

문자열은 작은따옴표나 큰따옴표로 감싸야 한다.

```python
is_open = True
```

수업이 열렸는지 여부처럼 참과 거짓으로 나뉘는 값은 `bool`을 사용한다.

```python
scores = [80, 90, 100]
```

점수 여러 개를 하나의 이름으로 관리하기 위해 리스트를 사용한다.

```text
scores
  │
  ▼
[80, 90, 100]
 0   1   2
```

```python
scores[0]
```

리스트에서 첫 번째 값을 꺼낸다.

파이썬의 순서는 1이 아니라 0부터 시작한다.

---

## 6. 마지막 정리

자료형은 값의 종류를 나타낸다.

숫자와 문자열은 겉보기에는 비슷해도 파이썬에서는 다르게 처리된다.

`int`는 정수, `float`는 실수, `str`은 문자열, `bool`은 참/거짓을 의미한다.

`list`는 여러 값을 순서대로 담을 때 사용한다.

자료형을 알면 값으로 어떤 작업을 할 수 있는지 판단할 수 있다.
