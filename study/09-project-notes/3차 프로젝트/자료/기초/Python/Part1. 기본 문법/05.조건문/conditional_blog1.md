## 1. 한 줄 요약

조건문은 **"만약 이렇다면 이걸 해라"** 라고 프로그램에게 지시하는 방법이다. 조건에 따라 실행할 코드를 다르게 선택할 수 있다.

---

## 2. 왜 조건문이 필요할까?

지금까지 배운 코드는 항상 위에서 아래로 **순서대로** 실행된다.

```
print("안녕")   ← 1번
print("반가워") ← 2번
print("잘가")   ← 3번
```

하지만 현실에서는 **상황에 따라 다른 행동**을 해야 한다.

> 편의점에 들어갔다. 지갑을 열어보니 1,000원이 있다.  
> → 1,000원짜리 캔커피를 산다.  
>
> 근데 500원밖에 없다면?  
> → 그냥 나온다.

이처럼 "조건에 따라 다른 행동"을 코드로 표현하는 게 바로 **조건문**이다.

---

## 3. 핵심 아이디어 — 조건문은 "갈림길"이다

조건문을 **갈림길**로 생각해보자.

```
          조건 확인
              │
       ┌──────┴──────┐
      참(True)     거짓(False)
       │               │
   이쪽 실행        저쪽 실행
```

조건이 참이면 왼쪽 길, 거짓이면 오른쪽 길로 간다. 프로그램도 똑같이 조건을 보고 **어느 코드를 실행할지 선택**한다.

---

## 4. 동작 과정 살펴보기

### 4-1. if — "만약 ~라면"

가장 기본 형태. 조건이 참일 때만 실행하고, 거짓이면 그냥 넘어간다.

```python
# 형식
if 조건:
    조건이 참일 때 실행할 코드   # ← 반드시 들여쓰기!
```

```python
# 예시
score = 90

if score >= 60:
    print("합격!")
```

```
실행 흐름:

score = 90

if score >= 60:   →  90 >= 60  →  True  ✅
    print("합격!")              →  "합격!" 출력

출력: 합격!
```

만약 조건이 거짓이면?

```python
score = 40

if score >= 60:
    print("합격!")

# → 아무것도 출력되지 않음
```

```
실행 흐름:

if score >= 60:   →  40 >= 60  →  False  ❌
    print("합격!")              →  건너뜀

출력: (없음)
```

---

### 4-2. if~else — "만약 ~라면, 아니면"

조건이 참이면 if 블록을, 거짓이면 else 블록을 실행한다. **둘 중 하나는 반드시 실행**된다.

```python
# 형식
if 조건:
    참일 때 실행
else:
    거짓일 때 실행
```

```python
# 예시: 편의점 커피 사기
money = 1000

if money >= 1000:
    print("커피를 산다.")
else:
    print("그냥 나온다.")
```

```
실행 흐름 (money = 1000):

if money >= 1000:  →  1000 >= 1000  →  True  ✅
    "커피를 산다."                   →  실행
else:
    "그냥 나온다."                   →  건너뜀

출력: 커피를 산다.
──────────────────────────────────
실행 흐름 (money = 500):

if money >= 1000:  →  500 >= 1000  →  False  ❌
    "커피를 산다."                  →  건너뜀
else:
    "그냥 나온다."                  →  실행

출력: 그냥 나온다.
```

```
     [money = ?]
          │
     money >= 1000?
     ┌─────┴─────┐
    True        False
     │               │
"커피를 산다."   "그냥 나온다."
```

---

### 4-3. if~elif~else — "만약, 아니면 만약, 그것도 아니면"

조건이 3개 이상일 때 사용한다. 위에서부터 순서대로 확인하다가 **처음으로 참인 조건 하나만 실행**하고 끝낸다.

```python
# 형식
if 조건1:
    조건1이 참일 때
elif 조건2:
    조건2가 참일 때
elif 조건3:
    조건3이 참일 때
else:
    모두 아닐 때
```

```python
# 예시: 점수로 학점 매기기
score = 75

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("F학점")
```

```
실행 흐름 (score = 75):

score >= 90?  →  75 >= 90  →  False  ❌  건너뜀
score >= 80?  →  75 >= 80  →  False  ❌  건너뜀
score >= 70?  →  75 >= 70  →  True   ✅  실행!
  → "C학점" 출력
  → 이후 else는 확인하지 않음

출력: C학점
```

```
        [score = 75]
             │
        score >= 90?
        ┌─────┘ False
        │
        score >= 80?
        ┌─────┘ False
        │
        score >= 70?  ✅ True
        │
      "C학점"
```

> 💡 `elif`는 몇 개든 추가할 수 있다. 위에서부터 확인하다가 참인 조건 하나를 만나면 그 블록만 실행하고 나머지는 모두 건너뛴다.

## 5. 들여쓰기 — 파이썬에서 가장 중요한 규칙

파이썬은 **들여쓰기(indent)로 코드 묶음(블록)을 구분**한다. if에 속하는 코드는 반드시 한 칸(Tab 또는 스페이스 4칸) 들여써야 한다.

```python
# ✅ 올바른 예
if True:
    print("이건 if 블록 안")   # 들여쓰기 O
print("이건 if 블록 밖")       # 들여쓰기 X → 항상 실행됨
```

```python
# ❌ 잘못된 예 → SyntaxError 발생!
if True:
    print("if 블록 안")
print("if 블록 밖")
    print("이게 뭐죠?")   # 갑자기 들여쓰기 → 오류!
```

```
들여쓰기 구조 시각화:

if 조건:
│   실행코드 1   ← if 블록 (들여쓰기 있음)
│   실행코드 2   ← if 블록
실행코드 3       ← if 블록 밖 (항상 실행)
```

> ⚠️ 들여쓰기가 맞지 않으면 프로그램이 아예 실행되지 않는다. 탭과 스페이스를 혼용하지 말고 하나로 통일하자.

## 6. 구현 코드 및 상세 설명

### 비교 연산자 — 조건을 만드는 도구

조건문의 조건에는 **비교 연산자**가 자주 쓰인다.

```
연산자   의미          예시          결과
──────────────────────────────────────
==      같다          5 == 5        True
!=      같지 않다     5 != 3        True
>       크다          7 > 3         True
<       작다          2 < 1         False
>=      크거나 같다   5 >= 5        True
<=      작거나 같다   3 <= 4        True
```

### 논리 연산자 — 조건을 조합하는 도구

여러 조건을 한번에 쓸 때 사용한다.

```
연산자   의미                         예시
─────────────────────────────────────────────────────
and     둘 다 참이어야 True           age >= 19 and age <= 60
or      하나만 참이어도 True          score == 100 or bonus == True
not     참↔거짓 뒤집기               not (score >= 60)
```

```python
age = 25

if age >= 19 and age < 65:
    print("성인입니다.")
```

### 종합 예제 — 교통수단 선택

```python
money = int(input("지갑에 얼마 있나요? "))

if money >= 5000:
    print("택시를 탄다.")
elif money >= 1500:
    print("버스나 지하철을 탄다.")
else:
    print("눈물을 머금고 걷는다...")
```

```
코드 설명:

money = int(input(...))
  → 사용자 입력을 받아 정수로 변환, money에 저장

if money >= 5000:
  → money가 5000 이상이면 첫 번째 블록 실행

elif money >= 1500:
  → 위 조건이 False이고, money가 1500 이상이면 두 번째 블록 실행
  → 이미 5000 미만임이 확인된 상태이므로 "1500~4999원" 범위를 의미

else:
  → 위 조건들이 모두 False → 1500원 미만인 경우 실행
```

```
실행 흐름 (money = 2000):

money >= 5000?  →  False  ❌
money >= 1500?  →  True   ✅
→ "버스나 지하철을 탄다." 출력
```

## 7. 마지막 정리

- 조건문은 **조건에 따라 실행할 코드를 선택**하는 갈림길이다.
- `if`만 있으면 조건이 참일 때만 실행, **거짓이면 아무것도 안 한다**.
- `if~else`는 참/거짓 **둘 중 하나를 반드시 실행**한다.
- `if~elif~else`는 **3개 이상의 조건**을 위에서부터 순서대로 확인하고, 처음 참인 것 하나만 실행한다.
- 파이썬에서 **들여쓰기는 선택이 아니라 필수**다. 들여쓰기가 틀리면 오류가 난다.
