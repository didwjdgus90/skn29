# [Python 기초] 반복문 (while / for)

# 본문

## 1. 한 줄 요약

반복문은 같은 일을 여러 번 해야 할 때 컴퓨터에게 “이 작업을 계속 반복해줘”라고 부탁하는 문법이다.

반복문을 배우면 많은 데이터를 하나씩 처리하거나, 원하는 횟수만큼 코드를 자동으로 실행할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

친구 5명에게 같은 인사를 한다고 생각해 보자.

```text
민수야 안녕
지은아 안녕
현우야 안녕
수빈아 안녕
영희야 안녕
```

사람이 직접 말할 수도 있지만, 친구가 100명이라면 너무 힘들다.

코드도 마찬가지다.

```python
print("민수야 안녕")
print("지은아 안녕")
print("현우야 안녕")
print("수빈아 안녕")
print("영희야 안녕")
```

이렇게 같은 모양의 코드를 계속 쓰면 불편하다.

반복문을 사용하면 컴퓨터가 이름을 하나씩 꺼내면서 같은 일을 대신 해준다.

```python
names = ["민수", "지은", "현우", "수빈", "영희"]

for name in names:
    print(name + "야 안녕")
```

반복문은 **귀찮은 반복 작업을 컴퓨터에게 맡기는 방법**이다.

---

## 3. 핵심 아이디어

반복문은 컨베이어 벨트 위의 물건을 하나씩 처리하는 직원과 비슷하다.

```text
컨베이어 벨트

[사과] [바나나] [포도]
  │
  ▼
직원이 하나씩 확인
```

파이썬의 `for`문도 비슷하게 동작한다.

```text
리스트

["사과"] ["바나나"] ["포도"]
   │
   ▼
fruit = "사과"
```

첫 번째 물건을 꺼내서 처리한다.

그다음 두 번째 물건을 꺼내서 처리한다.

마지막 물건까지 처리하면 반복이 끝난다.

```text
1번째 반복 → 사과 처리
2번째 반복 → 바나나 처리
3번째 반복 → 포도 처리
끝
```

`while`문은 알람 시계와 비슷하다.

"아직 시간이 안 됐으면 계속 기다려"처럼 조건이 참인 동안 계속 반복한다.

```text
아직 3번 안 했니?
  │
  ├─ 응 → 한 번 더 하기
  │
  └─ 아니 → 멈추기
```

## 4. 동작 과정 살펴보기

### 4-1. for문으로 이름 하나씩 꺼내기

```python
names = ["민수", "지은", "현우"]

for name in names:
    print(name + "야 안녕")
```

처음 상태는 다음과 같다.

```text
names

[민수] [지은] [현우]
```

첫 번째 반복이다.

```text
[민수] [지은] [현우]
  │
  ▼
name = "민수"

출력: 민수야 안녕
```

두 번째 반복이다.

```text
[민수] [지은] [현우]
        │
        ▼
name = "지은"

출력: 지은아 안녕
```

세 번째 반복이다.

```text
[민수] [지은] [현우]
              │
              ▼
name = "현우"

출력: 현우야 안녕
```

더 이상 꺼낼 이름이 없으면 반복이 끝난다.

```text
최종 출력

민수야 안녕
지은아 안녕
현우야 안녕
```

### 4-2. while문으로 3번 반복하기

```python
count = 1

while count <= 3:
    print("안녕")
    count += 1
```

처음에는 `count`가 1이다.

```text
count = 1

1 <= 3 ? True
출력: 안녕
count = 2
```

다시 확인한다.

```text
count = 2

2 <= 3 ? True
출력: 안녕
count = 3
```

한 번 더 확인한다.

```text
count = 3

3 <= 3 ? True
출력: 안녕
count = 4
```

이제 조건이 거짓이다.

```text
count = 4

4 <= 3 ? False
반복 끝
```

## 5. 구현 코드 및 상세 설명

```python
# 과일 이름을 하나씩 출력하기
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print("오늘의 과일:", fruit)


# 숫자를 1부터 5까지 출력하기
number = 1

while number <= 5:
    print(number)
    number += 1
```

### 코드 설명

```python
fruits = ["사과", "바나나", "포도"]
```

과일 이름 3개를 리스트에 담았다.

리스트는 여러 값을 한 줄로 모아둔 상자라고 생각하면 된다.

```python
for fruit in fruits:
```

`fruits` 안에서 과일을 하나씩 꺼낸다.

꺼낸 과일은 잠시 `fruit`이라는 변수에 들어간다.

```text
1번째: fruit = "사과"
2번째: fruit = "바나나"
3번째: fruit = "포도"
```

```python
print("오늘의 과일:", fruit)
```

현재 꺼낸 과일 이름을 출력한다.

반복될 때마다 `fruit` 안의 값이 바뀐다.

```python
number = 1
```

숫자를 1부터 시작한다.

```python
while number <= 5:
```

`number`가 5보다 작거나 같으면 계속 반복한다.

```python
number += 1
```

숫자를 하나씩 키운다.

이 줄이 있어야 언젠가 `number`가 6이 되어 반복이 멈춘다.

## 6. 마지막 정리

반복문은 같은 일을 여러 번 할 때 사용한다.

`for`문은 리스트나 문자열에서 값을 하나씩 꺼낼 때 편리하다.

`while`문은 조건이 참인 동안 계속 반복한다.

반복문 안에서 실행할 코드는 반드시 들여쓰기해야 한다.

`while`문에서는 반복이 끝날 수 있도록 조건에 사용되는 값을 바꿔야 한다.
