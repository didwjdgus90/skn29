# 본문

## 1. 한 줄 요약

연산자는 **값과 변수를 가지고 계산하거나 비교하거나 조건을 판단할 때 사용하는 기호**다. 수학 시간에 배운 `+`, `-`, `=` 같은 기호들이 바로 연산자이며, 파이썬은 이것들을 훨씬 더 다양하게 제공한다.

---

## 2. 왜 연산자가 필요한가?

프로그램은 결국 **데이터를 가져다가 뭔가를 하는 것**이다. 장바구니 총합을 구하거나, 비밀번호가 맞는지 확인하거나, 재고가 0 이하인지 체크하는 것 — 이 모든 작업이 연산자로 이루어진다.

```python
# 장바구니 총합
price = 3000
count = 5
total = price * count   # 곱셈 연산자
print(total)            # 15000

# 비밀번호 확인
input_pw = "1234"
real_pw  = "1234"
print(input_pw == real_pw)   # True — 비교 연산자

# 재고 체크
stock = 0
print(stock <= 0)            # True — 비교 연산자
```

연산자 없이는 이런 판단이 불가능하다. 연산자는 파이썬의 가장 기본적인 도구다.

---

## 3. 연산자의 종류

파이썬이 제공하는 연산자는 크게 7가지로 나뉜다.

```
종류                      대표 기호              한 줄 설명
──────────────────────────────────────────────────────────────────────
산술 연산자               + - * / % ** //        수학 계산
할당 연산자               = += -= *= /= ...       변수에 값 저장
비교 연산자               == != > < >= <=         두 값 비교 → True/False
논리 연산자               and or not             조건 결합
아이덴티 연산자           is  is not             같은 객체인지 확인
멤버십 연산자             in  not in             컬렉션 안에 있는지 확인
비트와이즈 연산자         & | ^ ~ << >>          이진수 단위 연산
```

---

## 4. 산술 연산자 (Arithmetic Operators)

수학 시간에 배운 사칙연산 그대로다. 여기에 파이썬만의 특수 연산자 몇 가지가 추가된다.

```
연산자   이름           설명                                  예시(x=7, y=2)   결과
──────────────────────────────────────────────────────────────────────────────────
+        덧셈           두 값을 더한다                        x + y            9
-        뺄셈           왼쪽에서 오른쪽을 뺀다                x - y            5
*        곱셈           두 값을 곱한다                        x * y            14
/        나눗셈         왼쪽을 오른쪽으로 나눈다              x / y            3.5
%        나머지         나눗셈의 나머지를 구한다              x % y            1
**       거듭제곱       왼쪽을 오른쪽 횟수만큼 곱한다         x ** y           49
//       몫(정수 나눗셈) 나눗셈의 몫(소수점 버림)을 구한다    x // y           3
```

> ⚠️ **주의사항 두 가지**
> 1. `/` 는 결과가 항상 **실수(float)** 다. `7 / 2 = 3.5`이지, `3`이 아니다.
> 2. `//` 는 소수점을 **버리는** 것이지, 반올림이 아니다. `7 // 2 = 3` (`3.5`의 `.5`가 버려짐)

### 4-1. 자주 쓰이는 패턴

**`%` (나머지) — 짝수/홀수 판별에 가장 많이 쓰인다**

```python
# 짝수면 2로 나눈 나머지가 0
print(10 % 2)   # 0  → 짝수
print(7 % 2)    # 1  → 홀수
```

```
나머지 연산 시각화:

7 ÷ 2 = 3 ... 나머지 1

[  2  ][  2  ][  2  ][ 1 ]
 ──────────────────────────
    7 개를 2 개씩 묶으면 → 3 묶음, 남은 1개
```

**`**` (거듭제곱) — 제곱근도 구할 수 있다**

```python
print(2 ** 10)    # 1024  (2의 10승)
print(9 ** 0.5)   # 3.0   (9의 0.5승 = 루트 9 = 3)
```

**`//` (정수 나눗셈) — 페이지 수 계산 등에 유용**

```python
total_items = 17
per_page    = 5
pages = total_items // per_page    # 17 // 5 = 3 (3페이지 꽉 참)
remain = total_items % per_page    # 17 % 5 = 2  (마지막 페이지 2개)
print(pages, remain)               # 3 2
```

### 4-2. 산술 연산자 예제

```python
x = 7
y = 2

print(x + y)    # 9
print(x - y)    # 5
print(x * y)    # 14
print(x / y)    # 3.5   ← float 반환
print(x % y)    # 1
print(x ** y)   # 49   (7의 2승)
print(x // y)   # 3    (소수점 버림)
```

## 5. 할당 연산자 (Assignment Operators)

할당 연산자는 **변수에 값을 저장**하는 연산자다. `=` 하나로 시작해서, 연산과 저장을 한 번에 처리하는 **복합 할당 연산자**까지 확장된다.

> 비유: 할당 연산자는 **"통장에 돈을 넣고 빼는 것"** 과 같다.
> `x += 100`은 "x 통장에 100원을 더 넣어라", `x -= 50`은 "x 통장에서 50원을 빼라"는 의미다.

```
연산자   의미                         x = 3, y = 2 일 때 x에 적용    결과
──────────────────────────────────────────────────────────────────────────
=        오른쪽 값을 왼쪽에 저장      x = y                          x → 2
+=       더해서 저장 (x = x + y)     x += y                         x → 5
-=       빼서 저장   (x = x - y)     x -= y                         x → 1
*=       곱해서 저장  (x = x * y)    x *= y                         x → 6
/=       나눠서 저장  (x = x / y)    x /= y                         x → 1.5
%=       나머지 저장  (x = x % y)    x %= y                         x → 1
**=      거듭제곱 저장               x **= y                        x → 9
//=      몫 저장                     x //= y                        x → 1
```

### 5-1. 할당 연산자 예제

```python
x = 10

x += 5    # x = x + 5 = 15
print(x)  # 15

x -= 3    # x = x - 3 = 12
print(x)  # 12

x *= 2    # x = x * 2 = 24
print(x)  # 24

x /= 4    # x = x / 4 = 6.0
print(x)  # 6.0

x **= 2   # x = x ** 2 = 36.0
print(x)  # 36.0

x //= 5   # x = x // 5 = 7.0
print(x)  # 7.0

x %= 3    # x = x % 3 = 1.0
print(x)  # 1.0
```

```
할당 연산자 흐름 시각화:

x = 10
    ↓ x += 5
x = 15
    ↓ x -= 3
x = 12
    ↓ x *= 2
x = 24
    ↓ ...
```

### 5-2. 왜 복합 할당 연산자를 쓸까?

```python
# 카운터 증가 — 가장 흔한 사용 사례
count = 0
count += 1   # count = count + 1 과 동일, 더 짧고 명확

# 누적 합산
total = 0
for price in [1000, 2000, 3000]:
    total += price
print(total)   # 6000
```

## 6. 비교 연산자 (Comparison Operators)

비교 연산자는 **두 값을 비교해서 True 또는 False를 반환**한다. 조건문(`if`, `while`)에서 가장 자주 사용된다.

> 비유: 비교 연산자는 **"저울"** 이다. 두 값을 올려놓고 "같은가?", "왼쪽이 더 무거운가?"를 판단해 `True` 또는 `False` 라벨을 붙여준다.

```
연산자   설명                                  예시(x=5, y=3)   결과
──────────────────────────────────────────────────────────────────
==       두 값이 같으면 True                   x == y           False
!=       두 값이 다르면 True                   x != y           True
>        왼쪽이 오른쪽보다 크면 True            x > y            True
<        왼쪽이 오른쪽보다 작으면 True          x < y            False
>=       왼쪽이 오른쪽보다 크거나 같으면 True   x >= y           True
<=       왼쪽이 오른쪽보다 작거나 같으면 True   x <= y           False
```

> ⚠️ **`=` vs `==` — 가장 흔한 실수**
> - `=` 는 **대입** 연산자 (변수에 값을 저장)
> - `==` 는 **비교** 연산자 (두 값이 같은지 확인)
> ```python
> x = 5      # x에 5를 저장 (대입)
> x == 5     # x가 5인지 비교 → True
> ```

### 6-1. 비교 연산자 예제

```python
x = 5
y = 3

print(x == y)    # False  (5와 3은 다름)
print(x != y)    # True   (5와 3은 다름)
print(x > y)     # True   (5 > 3)
print(x < y)     # False  (5 < 3 아님)
print(x >= 5)    # True   (5 >= 5, 같으므로 True)
print(x <= 4)    # False  (5 <= 4 아님)
```

### 6-2. 실전 활용 패턴

```python
# 로그인 검증
input_pw = "mypassword"
correct_pw = "mypassword"
if input_pw == correct_pw:
    print("로그인 성공")

# 나이 제한
age = 17
if age >= 18:
    print("성인입니다.")
else:
    print("미성년자입니다.")   # 이쪽 출력

# 범위 체크 — 파이썬은 연속 비교도 가능!
score = 85
print(80 <= score < 90)   # True  (85는 80 이상 90 미만)
```

```
범위 비교 시각화:

80 <= 85 < 90

     80   85   90
──────[════●════)──────
         True 구간
```

## 7. 논리 연산자 (Logical Operators)

논리 연산자는 **여러 조건을 하나로 결합**할 때 사용한다. 조건문에서 "A이고 B일 때", "A이거나 B일 때"를 표현할 때 필수다.

> 비유:
> - `and` → **"AND" = "그리고"** — 둘 다 만족해야 통과 (엄격한 경비원)
> - `or`  → **"OR" = "또는"**  — 하나만 만족해도 통과 (너그러운 경비원)
> - `not` → **"NOT" = "아니면"** — 결과를 뒤집음

```
연산자   설명                                        예시
──────────────────────────────────────────────────────────────────
and      두 조건이 모두 True일 때만 True              A and B
or       두 조건 중 하나라도 True면 True              A or B
not      True → False, False → True (결과 반전)      not A
```

### 7-1. 진리표

```
and 진리표:                 or 진리표:                 not 진리표:
─────────────────           ─────────────────           ───────────
A      B     결과            A      B     결과            A      결과
False  False  False          False  False  False          False  True
False  True   False          False  True   True           True   False
True   False  False          True   False  True
True   True   True           True   True   True
```

### 7-2. 논리 연산자 예제

```python
age = 25
has_ticket = True
is_vip = False

# and — 둘 다 True여야 True
print(age >= 18 and has_ticket)     # True  (성인이고 티켓도 있음)
print(age >= 18 and is_vip)         # False (성인이지만 VIP 아님)

# or — 하나라도 True면 True
print(has_ticket or is_vip)         # True  (티켓이 있으면 됨)
print(age < 18 or is_vip)           # False (둘 다 아님)

# not — 결과 반전
print(not is_vip)                   # True  (VIP가 아닌 게 맞음)
print(not has_ticket)               # False (티켓이 없다는 건 거짓)
```

### 7-3. 단락 평가 (Short-circuit Evaluation)

파이썬 논리 연산자는 **결과가 확정되는 순간 나머지 평가를 멈추고 해당 값 자체를 반환**한다.

```python
# and — 왼쪽이 False면 오른쪽은 평가하지 않고 왼쪽 값 반환
print(0 and "hello")    # 0      (0이 거짓이므로 "hello" 평가 안 함)
print(1 and "hello")    # "hello" (1이 참이므로 오른쪽 "hello" 반환)

# or — 왼쪽이 True면 오른쪽은 평가하지 않고 왼쪽 값 반환
print(1 or "hello")     # 1      (1이 참이므로 "hello" 평가 안 함)
print(0 or "hello")     # "hello" (0이 거짓이므로 오른쪽 "hello" 반환)
```

```
단락 평가 흐름:

0 and "hello":
  └─ 0이 거짓 → 여기서 중단 → 0 반환

1 and "hello":
  └─ 1이 참   → 계속 진행   → "hello" 반환

1 or "hello":
  └─ 1이 참   → 여기서 중단 → 1 반환

0 or "hello":
  └─ 0이 거짓 → 계속 진행   → "hello" 반환
```

## 8. 아이덴티 연산자 (Identity Operators)

아이덴티 연산자는 **두 변수가 같은 값을 가지는지가 아니라, 메모리 상의 완전히 동일한 객체를 가리키는지**를 확인한다.

> 비유: `==` 는 두 사람의 **이름이 같은가**, `is` 는 두 사람이 **완전히 동일 인물인가**를 묻는 것과 같다. 이름이 같아도 다른 사람일 수 있다.

```
연산자      설명                                      예시
────────────────────────────────────────────────────────────
is          두 변수가 동일한 객체를 가리키면 True      x is y
is not      두 변수가 다른 객체를 가리키면 True        x is not y
```

```
== vs is 차이:

a = [1, 2, 3]
b = [1, 2, 3]  # 값은 같지만 별도로 생성한 리스트

a == b   → True   (값이 같음)
a is b   → False  (다른 객체, 메모리 주소가 다름)

c = a          # c는 a와 같은 객체를 가리킴

a is c   → True   (같은 객체)
```

### 8-1. 아이덴티 연산자 예제

```python
a = [1, 2, 3]
b = [1, 2, 3]   # 내용은 같지만 별개의 객체
c = a            # a와 동일한 객체를 참조

print(a == b)    # True  (값이 같음)
print(a is b)    # False (다른 객체)
print(a is c)    # True  (같은 객체)

# id() 함수로 메모리 주소 확인
print(id(a))     # 예: 140362...
print(id(b))     # 예: 140371... (다름!)
print(id(c))     # 예: 140362... (a와 동일)
```

### 8-2. None 판별에 is를 쓰는 이유

```python
# None 확인은 == 대신 is를 권장
x = None

# ✅ 권장
if x is None:
    print("값이 없습니다.")

# ⚠️ 동작은 하지만 권장하지 않음
if x == None:
    print("값이 없습니다.")
```

`None`은 파이썬 전체에서 단 하나만 존재하는 객체다. 따라서 `is None`이 의미상 더 정확하다.

## 9. 멤버십 연산자 (Membership Operators)

멤버십 연산자는 **리스트, 튜플, 문자열, 집합 등 컬렉션 안에 특정 값이 있는지**를 확인한다.

> 비유: 멤버십 연산자는 **출석 체크**와 같다. 명단(`y`)에 해당 이름(`x`)이 있는지 확인한다.

```
연산자      설명                                      예시
────────────────────────────────────────────────────────────
in          컬렉션 안에 값이 있으면 True               x in y
not in      컬렉션 안에 값이 없으면 True               x not in y
```

### 9-1. 멤버십 연산자 예제

```python
fruits = ["apple", "banana", "cherry"]

print("apple" in fruits)        # True
print("grape" in fruits)        # False
print("grape" not in fruits)    # True

# 문자열에서도 사용 가능
sentence = "파이썬은 재미있다"
print("파이썬" in sentence)      # True
print("자바" in sentence)        # False

# 딕셔너리에서는 키(key)를 기준으로 확인
scores = {"Alice": 90, "Bob": 85}
print("Alice" in scores)         # True  (키 확인)
print(90 in scores)              # False (값은 확인하지 않음)
print(90 in scores.values())     # True  (값 확인하려면 .values() 필요)
```

### 9-2. 멤버십 연산자 주의사항

```python
# 리스트 자체를 하나의 요소로 인식
lists = [10, 11, 12, 13]
listx = [[10, 11], 12, 13]    # 리스트를 요소로 가진 리스트

print([10, 11] in lists)      # False  ← [10, 11]이 lists의 요소가 아님
print([10, 11] in listx)      # True   ← [10, 11]이 listx의 요소로 있음
```

## 10. 비트와이즈 연산자 (Bitwise Operators)

비트 연산자는 **숫자를 이진수(0과 1의 나열) 단위로 처리**하는 연산자다. 일반 코딩에서는 자주 쓰이지 않지만, 플래그 처리나 저수준 연산에서 등장한다.

> 비유: 비트 연산자는 **8개의 전구가 켜지고 꺼지는 것**으로 생각하면 된다.
> `10`이라는 숫자는 이진수로 `00001010` — 즉 1번, 3번 전구만 켜진 상태다.

```
연산자   이름                  설명                             예시
──────────────────────────────────────────────────────────────────────
&        AND (논리곱)          같은 자리가 모두 1일 때만 1       x & y
|        OR  (논리합)          같은 자리에 하나라도 1이면 1      x | y
^        XOR (배타적 논리합)   같은 자리가 다를 때만 1           x ^ y
~        NOT (비트 반전)       0은 1로, 1은 0으로 반전           ~x
<<       왼쪽 시프트           비트를 왼쪽으로 N칸 이동          x << y
>>       오른쪽 시프트         비트를 오른쪽으로 N칸 이동        x >> y
```

### 10-1. 이진수로 이해하기

```
숫자  이진수(8자리)
 0   → 00000000
 1   → 00000001
 2   → 00000010
 3   → 00000011
10   → 00001010
12   → 00001100
```

### 10-2. AND, OR, XOR 동작

```
AND (&) — 둘 다 1이어야 1
10  = 00001010
 6  = 00000110
       --------
&   = 00000010  → 2

OR (|) — 하나라도 1이면 1
10  = 00001010
 6  = 00000110
       --------
|   = 00001110  → 14

XOR (^) — 다를 때만 1, 같으면 0
10  = 00001010
 6  = 00000110
       --------
^   = 00001100  → 12
```

### 10-3. 시프트 연산

```
Left Shift (<<) — 비트를 왼쪽으로 N칸 이동 = 2^N 배 곱하기
1  = 00000001
1 << 3 → 00001000 = 8    (1 × 2³ = 8)
3 << 2 → 00001100 = 12   (3 × 2² = 12)

Right Shift (>>) — 비트를 오른쪽으로 N칸 이동 = 2^N 으로 나누기
8  = 00001000
8 >> 2 → 00000010 = 2    (8 ÷ 2² = 2)
10 >> 1 → 00000101 = 5   (10 ÷ 2¹ = 5)
```

### 10-4. NOT 연산자

```
~N = -(N + 1)

~0  = -1
~1  = -2
~10 = -11
```

### 10-5. 비트와이즈 연산자 예제

```python
x = 10   # 00001010
y = 6    #  00000110

print(x & y)     # 2   (00000010)
print(x | y)     # 14  (00001110)
print(x ^ y)     # 12  (00001100)
print(~x)        # -11 (-(10+1))
print(x << 2)    # 40  (10 × 4)
print(x >> 1)    # 5   (10 ÷ 2)

# 이진수 출력으로 확인
print(bin(x))           # 0b1010
print(bin(x & y))       # 0b10
print(bin(x | y))       # 0b1110
print(bin(x ^ y))       # 0b1100
```

## 11. 연산자 우선순위

한 식에 여러 연산자가 섞이면 **어떤 것을 먼저 계산할지**가 중요하다. 수학의 "곱셈이 덧셈보다 먼저"와 같은 규칙이 파이썬에도 있다.

```
순위   연산자               설명                        예시
─────────────────────────────────────────────────────────────────
높음
 1    ()                   괄호                         (2+3)*4
 2    **                   거듭제곱                     2**3**2 → 2**(3**2)
 3    ~  +x  -x            단항 연산자                  ~5, -3
 4    *  /  %  //           곱하기/나누기/나머지/몫     3*4+2
 5    +  -                  덧셈/뺄셈                   1+2-3
 6    <<  >>                비트 시프트
 7    &                     비트 AND
 8    ^                     비트 XOR
 9    |                     비트 OR
10    ==  !=  >  <  >=  <=  비교 연산자
      is  is not
      in  not in
11    not                   논리 NOT
12    and                   논리 AND
13    or                    논리 OR
낮음
```

### 11-1. 우선순위 예제

```python
# 곱셈이 먼저
print(2 + 3 * 4)          # 14   (3*4=12 먼저, 2+12=14)
print((2 + 3) * 4)        # 20   (괄호 먼저 → 5*4=20)

# ** 은 오른쪽부터 계산
print(2 ** 3 ** 2)        # 512  (3**2=9 먼저, 2**9=512)
print((2 ** 3) ** 2)      # 64   (2**3=8 먼저, 8**2=64)

# 비교 후 논리 연산
print(5 > 3 and 2 < 4)    # True  (비교 두 개 먼저, 그 다음 and)
print(not 5 > 10)          # True  (5>10=False, not False=True)

# 혼합 예시
print(1 + 2 * 3 == 7)     # True  (2*3=6, 1+6=7, 7==7=True)
```

> **팁**: 우선순위가 헷갈릴 때는 **괄호를 적극 사용**하자. 코드의 의도가 명확해지고 실수도 줄어든다.

## 12. 마지막 정리

| 연산자 종류 | 핵심 키워드 | 반환값 |
|---|---|---|
| 산술 | `+` `-` `*` `/` `%` `**` `//` | 계산 결과 (숫자) |
| 할당 | `=` `+=` `-=` `*=` ... | 없음 (변수에 저장) |
| 비교 | `==` `!=` `>` `<` `>=` `<=` | `True` / `False` |
| 논리 | `and` `or` `not` | `True` / `False` 또는 원래 값 |
| 아이덴티 | `is` `is not` | `True` / `False` |
| 멤버십 | `in` `not in` | `True` / `False` |
| 비트 | `&` `\|` `^` `~` `<<` `>>` | 숫자 (이진 연산 결과) |

- `/` 는 항상 **float** 를 반환한다. 정수 몫이 필요하면 `//` 를 사용한다.
- `=`(대입)과 `==`(비교)를 절대 혼동하지 말자.
- `is`는 **값이 같은지**가 아닌 **같은 객체인지**를 확인한다. `None` 비교에는 `is None`을 쓰자.
- `in`은 컬렉션 안에 값이 있는지 확인한다. 딕셔너리는 기본적으로 **키(key)** 를 기준으로 검색한다.
- 우선순위가 헷갈리면 **괄호 `()`** 를 사용해 명확하게 표현하자.
