# 본문

변수와 상수는 파이썬뿐만 아니라 **모든 프로그래밍 언어에서 공통적으로 사용되는 가장 기본적인 개념**이다.

변수와 상수가 무엇인지, 어떻게 생성하는지, 그리고 기본적인 활용 방법에 대해서 제대로 이해해 두도록 하자.

---

## 1. 파이썬 변수(Variable) 란?

변수(變數, Variable)라는 단어는 사전적 의미 그대로 **"어떠한 대응 관계로 변화하는 수"** 를 말하는 것으로, 수학에서는 "어떤 정해지지 않은 임의의 값을 표현해 사용된 기호"로 정의한다.

프로그래밍에서는 수없이 사용되는 **데이터(자료, 수 또는 값 등)를 저장하고 관리하기 위해서 사용자가 직접 이름**을 만들어 사용하는 컴퓨터 메모리에 임시로 저장하는 공간을 의미한다. 이렇게 생성된 **변수에 값을 할당하면 해당 값이 메모리에 저장**되고, 필요할 때 해당 **변수 이름을 통해 저장된 값을 불러오거나 접근 및 수정**할 수 있다.

---

### 변수 선언 및 할당 예시

```python
a = 10
b = "https://esajin.kr"
c = 3.14159
```

위와 같이 변수를 사용하기 위해 특별한 키워드는 필요하지 않고, 일반적인 `a, b, c`등과 같은 변수 이름을 작성하고, 값을 할당하면 변수가 자동으로 생성되는 구조이다.

**변수 할당 연산자는 ` = ` 을 기본으로 가장 많이 사용하고, ` += `, ` -= `, ` *= `, ` /= ` 등과 같은 복합 대입 연산자와 ` &= `, ` |= `, ` ^= ` 등과 같은 비트 연산과 함께 사용하는 복합 대입 연산자 등 다양하게 적용될 수 있지만, 이런 것은 우선 이런 게 있다는 것만 알아두고, 우선은 ` = ` 를 사용하여 값을 변수에 할당한다는 것만 알아두자.**

> **※ 참고 :**
> 변수 할당 연산자에서 ` = ` 은 "**같다**"라는 뜻이 아니고, **할당 또는 대입한다** 라는 의미로 사용된다.

오른쪽에 있는 값을 왼쪽에 있는 변수에 할당하는 구조는 다른 프로그래밍 언어에서도 동일하게 찾아볼 수 있으며, 약간의 차이는 있지만 거의 비슷하게 변수를 선언한다고 보면 된다.

---

### 변수가 왜 변수인가? 예시

```python
# 변수 a에 대입된 10을 출력
a = 10

print(a)
```

출력 결과:
```
10
```

```python
a = 10
a = "변경됨"  # 최초 대입된 값이 동일한 변수에 다른 내용으로 대치되어 출력

print(a)
```

출력 결과:
```
변경됨
```

위와 같이 `a`로 선언된 변수에 처음에는 `10`으로 값을 할당했다가, 똑같은 변수 이름에 `"변경됨"`으로 다시 할당하면, 최종적인 결과 값은 `변경됨`으로 출력되는 것을 확인할 수 있다.

**이처럼 변수에 대입된 값은 중간에 다른 값으로 언제든지 변할 수 있기 때문에 '변수'라고 한다.**

---

### 변수 선언(이름 지정) 시 유의사항

변수는 사용자가 직접 입력하여 사용하는 메모리 임시 저장소이기 때문에, 몇 가지 작성 규칙이 있다.

1. **의미 있는 이름을 만들어서 사용한다.**
   ※ 의미 있다는 것은 해당 값 또는 하는 일의 목적에 맞는 적당한 이름을 부여하는 것을 말하며, 대부분 영어 단어를 많이 차용한다.

2. 변수는 **대문자와 소문자를 다르게 인식**하므로, 대/소문자 구분을 확실하게 해야 한다.
   ※ 파이썬은 변수뿐만 아니라, 각종 함수들도 대/소문자를 구분하기 때문에 확실히 구분할 필요가 있다.

3. 변수는 **영문자와 숫자, 언더바(`_`)로만 작성**한다.

4. 변수 중간에 **공백(사이 띄우기)이 있으면 안 되며**, 필요하다면 언더바로 단어를 구분한다.

5. **처음부터 숫자로 변수 이름을 시작할 수 없다.**
   ※ 무조건 영문부터 시작하고, 가능하면 숫자는 사용하지 않는 것을 추천한다.

6. `#`, `@`, `&` 등과 같은 **특수 문자는 사용할 수 없다.**

7. 파이썬의 **예약어(`print`, `if`, `for` 등)는 변수 이름으로 사용할 수 없다.**

```
올바른 예시:          잘못된 예시:
────────────────────────────────────────
user_name            user name     (공백 포함)
age2024              2024age       (숫자로 시작)
total_score          total@score   (특수문자 포함)
myValue              print         (예약어 사용)
```

### 변수 선언 연습 해보기

아래 코드를 이용해서 직접 변수 선언 및 선언된 변수가 어떻게 활용되는지 확인해 보자.

```python
name = "돌출과 회전"
age = 2
height = 168.3

print(name)
print(age)
print(height)
```

출력 결과:
```
돌출과 회전
2
168.3
```

간단하게 변수를 선언하고 값을 대입해서 `print()` 함수를 이용해 변수에 저장된 데이터를 출력하는 내용을 확인했다.

특별하게 변수 선언이 어렵다고 느껴지지 않았을 것이지만, 중요한 것은 **변수 이름 짓기가 장난 아니게 스트레스를 안겨주기 때문에** 이참에 영어 단어 공부한다고 생각하고 제대로 된 이름을 지정할 수 있도록 노력하자.

특히, `aaa, bbb, ccc, abcd, a123, b123` 등과 같은 **무의미한 변수를 지정하는 버릇은 애초에 들이지 않는 것을 추천**한다. 나중에 엄청 고생하고 싶지 않으면 말이다.

### 변수 다중 할당 방법

파이썬에서 기본적으로 위에서와 같은 방법으로 변수를 지정하고 할당하는 것이 대부분이지만, 때로는 **한 줄에 여러 변수에 값을 동시에 할당**하거나, **하나의 값을 여러 개의 변수에 할당**하는 경우도 있다.

**방법 1 — 한 줄에 여러 변수와 여러 값을 동시에 할당**

```python
# 한 줄에 사용할 변수와 동일한 수량의 값으로 선언
val1, val2, val3 = 15, 25, 35

print(val1)
print(val2)
print(val3)
```

출력 결과:
```
15
25
35
```

생성할 변수와 값이 **동일한 수량**으로 이루어져야 하며, **순서대로 값이 대입**된다.

**방법 2 — 하나의 값을 여러 변수에 동시에 할당**

```python
# 하나의 값을 각기 다른 변수에 대입
val_x = val_y = val_z = "https://esajin.kr"

print(val_x)
print(val_y)
print(val_z)
```

출력 결과:
```
https://esajin.kr
https://esajin.kr
https://esajin.kr
```

한 개의 값을 각기 다른 변수에 동일하게 대입시켜 사용해야 하는 경우, 위 코드와 같은 방식으로 변수를 선언하면 조금 더 효과적으로 코딩할 수 있다.

**어떤 방법이 좋다 나쁘다의 개념이 아니라, 목적에 따라 또는 코딩하는 사람들의 성향과 조건에 따라 변수를 지정하는 방법이 달라지기 때문에, 나름대로 많은 연습을 통해 어떤 방법이 조금 더 가독성이 좋은지 판단해서 공부하면 좋을 것이다.**

## 2. 파이썬 상수(Constant) 란?

상수(常數)는 **"변하지 않고 항상 같은 값을 가지는 수"** 를 말하는 것으로, 프로그래밍에서는 **프로그램 실행 중에 변하지 않는 데이터**를 말하며, **변수의 반대 의미**를 가지고 있다.

파이썬은 다른 프로그래밍 언어와 달리 **상수를 특별히 정의하는 문법은 존재하지 않으며**, **직접적으로 값을 사용**하거나, 상수로 사용될 값을 변수로 지정할 때는 **변수 이름을 대문자로 작성**하여 명시적으로 구분하는 경우가 있다. 이렇게 선언된 변수는 **값을 변경하지 않겠다는 의미**로 사용하게 된다.

여기서 변하지 않는다는 의미는, 일반적인 변수는 중간에 다른 값으로 바뀌는 경우가 많은 반면, **처음부터 변하지 않는 값을 사용해야 하는 경우 상수를 이용**한다는 뜻이다.

---

### 상수의 사용 예시-01

```python
ab = 2  # ab 변수에 2를 대입

print(ab * 10)  # ab는 변수, 10은 상수
```

출력 결과:
```
20
```

위 예시에서 `ab`는 변수이고, `10`은 코드 내에 직접 쓰인 값, 즉 **리터럴 상수(literal constant)** 이다.

---

### 상수의 사용 예시-02

```python
# 대문자로 이름을 지정하여 상수처럼 사용
PI = 3.141592
MAX_SIZE = 100
BASE_URL = "https://esajin.kr"

print(PI)
print(MAX_SIZE)
print(BASE_URL)
```

출력 결과:
```
3.141592
100
https://esajin.kr
```

위와 같이 변수 이름을 **대문자**로 작성하면, 코드를 읽는 사람이 "이 값은 변경하지 않겠다"는 의도임을 쉽게 알아볼 수 있다. 이것은 파이썬 커뮤니티에서 널리 통용되는 **관례(convention)** 이며, 파이썬 자체적으로 변경을 강제로 막아주는 기능은 없다.

```
변수 vs 상수 비교:

구분     선언 방식          변경 가능 여부    예시
──────────────────────────────────────────────────────
변수     소문자 / 스네이크    가능             user_name = "홍길동"
상수     대문자 / 스네이크    관례상 변경 안 함  MAX_SIZE = 100
```

> **※ 참고 :**
> 파이썬에서 대문자로 선언된 변수도 기술적으로는 값을 바꿀 수 있다. 하지만 대문자로 선언된 변수의 값을 임의로 변경하는 것은 **관례에 어긋나는 코딩**이다. 팀 프로젝트나 협업 환경에서 이 관례를 지키는 것은 매우 중요하다.

## 3. 마지막 정리

- **변수**는 프로그램 실행 중에 **값이 변할 수 있는** 메모리 임시 저장 공간이다.
- 변수는 `변수명 = 값` 형태로 선언하며, `=`는 **"같다"가 아니라 "대입"** 의 의미이다.
- 변수 이름은 영문자·숫자·언더바만 허용하며, **숫자로 시작하거나 예약어를 이름으로 쓸 수 없다.**
- 파이썬은 **대/소문자를 구분**하므로 `Name`과 `name`은 서로 다른 변수이다.
- **처음부터 의미 있는 변수 이름을 짓는 습관**을 들이는 것이 나중을 위해서 절대적으로 중요하다.
- **상수**는 프로그램 실행 중에 **변하지 않는 값**을 말하며, 파이썬은 상수를 강제하는 문법이 없다.
- 파이썬에서는 **변수 이름을 대문자로 작성**하는 관례로 상수임을 표현한다. (예: `PI`, `MAX_SIZE`)
