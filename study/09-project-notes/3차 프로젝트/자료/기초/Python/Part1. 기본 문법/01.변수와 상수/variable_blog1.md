## 1. 한 줄 요약

변수는 **값을 담아두는 이름표**다. 한 번 저장한 값은 언제든지 꺼내 쓸 수 있고, 언제든지 바꿀 수도 있다.

---

## 2. 왜 변수가 필요할까?

계산기를 쓴다고 생각해보자. `3 + 5 = 8`을 계산했는데, 나중에 이 결과에 2를 더 더해야 한다면? 결과 `8`을 어딘가에 적어두지 않으면 다시 계산해야 한다.

코드도 마찬가지다. 값을 매번 직접 적는 대신, **이름을 붙여서 저장**해두면 나중에 그 이름으로 꺼내 쓸 수 있다. 이것이 변수다.

```
변수 없이:
print(3 + 5)      # 결과를 어딘가 기억해야 함
print(3 + 5 + 2)  # 3 + 5를 또 계산해야 함

변수 있이:
result = 3 + 5    # "result"라는 이름표에 8을 붙여둠
print(result)     # 8 출력
print(result + 2) # 10 출력 — 다시 계산 불필요
```

## 3. 핵심 아이디어 — 변수는 "이름표가 붙은 상자"

변수를 **이름표가 붙은 상자**로 생각해보자.

```
 ┌─────────────┐
 │     5       │  ← 상자 안에 값이 들어있음
 └─────────────┘
       ↑
      age         ← 상자에 붙은 이름표
```

`age = 5`라고 쓰면, `age`라는 이름표가 붙은 상자에 `5`를 넣는 것이다. 나중에 `age`를 부르면 상자 안의 `5`를 꺼내준다.

값을 바꾸고 싶으면? 상자 안 내용물만 교체하면 된다. 이름표는 그대로다.

```
 ┌─────────────┐      ┌─────────────┐
 │     5       │  →   │     10      │  ← 내용만 바뀜
 └─────────────┘      └─────────────┘
       ↑                    ↑
      age                  age        ← 이름표는 그대로
```

## 4. 동작 과정 살펴보기

### 4-1. 기본 사용법

```python
a = 5
print(a)  # 5
```

```
실행 흐름:

1단계: a = 5
  → "a"라는 이름표가 붙은 상자에 5를 넣는다

2단계: print(a)
  → "a" 상자를 열어 안에 있는 5를 꺼내 출력한다

출력: 5
```

### 4-2. 값 바꾸기

```python
a = 3
a = 10
print(a)  # ?
```

```
실행 흐름:

a = 3  → [3]  이름표: a
a = 10 → [10] 이름표: a  (기존 3은 사라짐)

출력: 10
```

> 💡 값을 새로 넣으면 이전 값은 덮어씌워진다.

### 4-3. 변수를 다른 변수에 넣기

```python
a = 3
b = a     # a의 값(3)을 b에 복사
a = 7     # a를 바꿔도...
print(a, b)  # ?
```

```
실행 흐름:

a = 3  →  a:[3]
b = a  →  a:[3]  b:[3]  ← 3이라는 값이 복사됨

a = 7  →  a:[7]  b:[3]  ← b는 그대로!

출력: 7  3
```

> 💡 `b = a`는 "b가 a와 연결된다"는 게 아니라 **"a의 값을 복사해서 b에 넣는다"** 는 뜻이다.
> a를 나중에 바꿔도 b는 영향을 받지 않는다.

## 5. 변수의 타입 — 상자에는 종류가 있다

상자(변수)에 뭘 넣느냐에 따라 종류가 달라진다. 파이썬에서는 **값을 넣는 순간 타입이 자동으로 결정**된다.

```
값            타입          설명
─────────────────────────────────────────
5             int           정수 (소수점 없는 숫자)
3.14          float         소수 (소수점 있는 숫자)
"Hello"       str           문자열 (글자)
True / False  bool          참 / 거짓
None          NoneType      값이 없음
```

```python
a = 5          # int
b = 3.14       # float
c = "Hello!"   # str
d = True       # bool
e = None       # NoneType

print(type(a)) # <class 'int'>
print(type(c)) # <class 'str'>
```

> 💡 `type(변수)`를 쓰면 그 변수의 타입을 확인할 수 있다.

## 6. 변수 연산 — 상자 안의 값으로 계산하기

### 6-1. 기본 연산자

```
연산자   의미             예시          결과
────────────────────────────────────────
+       더하기           3 + 5         8
-       빼기             10 - 4        6
*       곱하기           3 * 4         12
/       나누기           10 / 4        2.5
//      몫 (정수 나눗셈)  10 // 3       3
%       나머지           10 % 3        1
**      거듭제곱         2 ** 3        8
```

```python
a = 10
b = 3

print(a + b)   # 13
print(a // b)  # 3   (몫만)
print(a % b)   # 1   (나머지만)
print(a ** 2)  # 100 (10의 제곱)
```

> 💡 `/` 나눗셈 결과는 항상 `float`이다. `10 / 2 = 5.0` (5가 아님!)

### 6-2. 연산 순서

수학과 똑같다. 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 계산된다.
괄호로 묶으면 그 안을 먼저 계산한다.

```python
print(3 + 2 * 4)    # 11  (2*4 먼저)
print((3 + 2) * 4)  # 20  (괄호 먼저)
```

> ⚠️ 파이썬에선 `{}`, `[]`를 계산 우선순위 표시로 쓰지 않는다. 괄호 `()`만 중첩해서 사용한다.

### 6-3. 문자열 연산

문자열끼리는 `+`로 이어붙일 수 있다.

```python
a = "Hello"
b = "World"
print(a + b)   # HelloWorld
print(a + " " + b)  # Hello World
```

### 6-4. 타입이 다르면 에러가 난다

```python
a = 5
b = "3"
print(a - b)  # ❌ 에러! int와 str은 연산 불가
```

```
해결 방법: 타입을 맞춰준다 (형변환)

int("3")  → 3     (문자열을 정수로)
str(5)    → "5"   (정수를 문자열로)
float("3.14") → 3.14 (문자열을 소수로)
```

```python
a = 5
b = "3"
print(a - int(b))  # ✅ 2
```

### 6-5. 축약 연산자

같은 변수에 연산 결과를 다시 저장하는 패턴이 자주 나온다.

```python
a = 5
a = a + 2  # a에 2를 더해서 다시 a에 저장
print(a)   # 7

# 아래와 완전히 같은 의미
a = 5
a += 2
print(a)   # 7
```

```
a += 2   →  a = a + 2
a -= 2   →  a = a - 2
a *= 2   →  a = a * 2
a //= 2  →  a = a // 2
a %= 2   →  a = a % 2
```

## 7. 변수 이름 짓는 법

### 규칙 (반드시 지켜야 함)

```
✅ 사용 가능: 영문자, 숫자, 언더바(_)
✅ 숫자로 시작 불가
✅ 대소문자 구분 (age ≠ Age ≠ AGE)

예시:
  name = "정현"     ✅
  age_2026 = 52    ✅
  _temp = 0        ✅

  이름 = "정현"     ❌  (한글 불가)
  2age = 52        ❌  (숫자로 시작)
  my-name = "..."  ❌  (하이픈 불가)
  Hello World = "" ❌  (공백 불가)
```

### 좋은 이름 짓는 습관

변수가 무엇을 담는지 이름만 봐도 알 수 있게 짓자.

```python
# ❌ 나쁜 예: 뭘 의미하는지 모름
a = "2047218"
b = "kkk111222"

# ✅ 좋은 예: 한눈에 의미가 보임
student_id = "2047218"
password = "kkk111222"
```

## 8. 마지막 정리

- 변수는 **값을 저장하는 이름표 붙은 상자**다.
- `변수명 = 값` 한 줄로 만들고 바로 사용할 수 있다.
- 값을 다시 넣으면 **이전 값은 사라지고** 새 값으로 덮어씌워진다.
- 파이썬은 넣는 값에 따라 **타입이 자동 결정**된다 (int, float, str, bool...).
- 타입이 다른 변수끼리 연산하면 **에러가 난다** → `int()`, `str()` 등으로 형변환 필요.
- 변수 이름은 **영문, 숫자, 언더바만** 사용하고, **숫자로 시작하면 안 된다**.
