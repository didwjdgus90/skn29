# [Python 기초] 변수 (Variable)

# 본문

## 1. 한 줄 요약

변수는 값을 담아두는 이름표이고, 상수는 프로그램 안에서 바뀌지 않도록 약속한 값이다.

파이썬에서 변수와 상수를 이해하면 숫자, 글자, 계산 결과를 기억해두고 필요할 때 다시 사용할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

프로그램은 여러 값을 다룬다.

예를 들어 쇼핑몰 프로그램이라면 상품 가격, 개수, 할인율, 최종 결제 금액 같은 값이 필요하다.

이 값을 매번 직접 쓰면 코드가 길어지고 실수하기 쉽다.

```python
print(30000 * 2)
print(30000 * 2 * 0.9)
```

위 코드만 보면 `30000`이 무엇인지, `2`가 무엇인지, `0.9`가 무엇인지 바로 알기 어렵다.

변수를 사용하면 값에 이름을 붙일 수 있다.

```python
price = 30000
count = 2
discount_rate = 0.9
```

이제 코드를 읽는 사람이 "아, 가격과 개수와 할인율이구나" 하고 이해할 수 있다.

변수는 **값을 기억하는 도구**이고, 상수는 **절대 바뀌면 안 되는 값을 표시하는 약속**이다.

---

## 3. 핵심 아이디어

변수는 값에 붙이는 **이름표**라고 생각하면 쉽다.

```text
값: 30000
↓ 이름표 붙이기
price = 30000
```

컴퓨터 입장에서는 `30000`이라는 숫자만 있어도 계산할 수 있다.

하지만 사람 입장에서는 이 숫자가 가격인지, 나이인지, 점수인지 알기 어렵다.

그래서 변수 이름을 붙인다.

```text
price ─────▶ 30000
count ─────▶ 2
name  ─────▶ "민수"
```

상수는 "이 값은 바꾸지 말자"라고 팀원끼리 정한 변수다.

파이썬에는 상수를 강제로 막는 문법이 따로 없다.

그래서 보통 대문자로 이름을 작성해서 상수처럼 사용한다.

```python
PI = 3.14159
MAX_STUDENT = 30
```

이렇게 쓰면 "이 값은 중간에 바꾸지 말아야 하는 중요한 값이구나"라고 알아볼 수 있다.

---

## 4. 동작 과정 살펴보기

아래 코드를 한 줄씩 따라가 보자.

```python
score = 80
score = score + 10
print(score)
```

### Step 1. 변수에 처음 값을 넣는다

```text
score
  │
  ▼
 80
```

`score = 80`은 `score`라는 이름표를 만들고, 거기에 `80`이라는 값을 연결한다는 뜻이다.

### Step 2. 기존 값을 꺼내서 계산한다

```text
score = score + 10

오른쪽 score는 현재 값 80을 의미한다.

80 + 10 = 90
```

파이썬은 오른쪽을 먼저 계산한다.

즉, `score + 10`을 먼저 계산해서 `90`을 만든다.

### Step 3. 계산 결과를 다시 변수에 저장한다

```text
기존 상태

score ─────▶ 80

계산 후

score ─────▶ 90
```

`score`가 가리키던 값이 `80`에서 `90`으로 바뀐다.

### Step 4. 출력한다

```text
print(score)

score가 가리키는 값은 90

출력 결과
90
```

변수는 값 자체가 아니라 값을 다시 꺼내 쓰기 위한 이름이라고 생각하면 된다.

## 5. 구현 코드 및 상세 설명

```python
# 상품 가격
price = 15000

# 구매 개수
count = 3

# 배송비
DELIVERY_FEE = 2500

# 총 상품 금액 계산
total_price = price * count

# 최종 결제 금액 계산
final_price = total_price + DELIVERY_FEE

print("상품 가격:", price)
print("구매 개수:", count)
print("총 상품 금액:", total_price)
print("배송비:", DELIVERY_FEE)
print("최종 결제 금액:", final_price)
```

### 코드 설명

```python
price = 15000
```

`price`라는 변수에 상품 가격을 저장한다.

숫자 `15000`만 쓰는 것보다 `price`라고 이름을 붙이면 의미가 분명해진다.

```python
count = 3
```

`count`는 구매 개수를 의미한다.

나중에 구매 개수가 바뀌면 이 값만 수정하면 된다.

```python
DELIVERY_FEE = 2500
```

배송비는 중간에 자주 바뀌면 안 되는 값이라고 가정한다.

그래서 대문자 이름을 사용해 상수처럼 표현했다.

```python
total_price = price * count
```

상품 가격과 개수를 곱해서 총 상품 금액을 계산한다.

```text
price = 15000
count = 3

15000 × 3 = 45000
```

```python
final_price = total_price + DELIVERY_FEE
```

총 상품 금액에 배송비를 더해서 최종 결제 금액을 만든다.

```text
total_price  ─────▶ 45000
DELIVERY_FEE ─────▶ 2500

45000 + 2500 = 47500
```

---

## 6. 마지막 정리

변수는 값에 이름을 붙여서 나중에 다시 사용하기 위한 도구다.

변수 이름을 잘 지으면 코드의 의미를 쉽게 이해할 수 있다.

파이썬에서는 `=`를 사용해 변수에 값을 저장한다.

상수는 바꾸지 않기로 약속한 값이며, 보통 대문자 이름으로 작성한다.

오른쪽 계산이 먼저 실행되고, 그 결과가 왼쪽 변수에 저장된다.
