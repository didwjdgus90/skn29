# 제목
[C/Cpp 기초] 재귀 함수

# 본문

## 1. 한 줄 요약

재귀 함수는 거울 속의 거울이다. 자기 자신을 반복해서 비추다가, 마지막에 멈추는 조건이 있어야 한다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

러시아 전통 인형 마트료시카를 상상해보자.

큰 인형을 열면 안에 작은 인형이 있고, 그 안에 더 작은 인형이 있다.

가장 작은 인형(마지막)에는 더 이상 인형이 없다.

```text
마트료시카 크기5 열기
  → 크기4 발견
  → 마트료시카 크기4 열기
    → 크기3 발견
    → 마트료시카 크기3 열기
      → 크기2 발견
      → ...
        → 크기1: 더 이상 없음 (종료!)
```

재귀 함수가 바로 이 구조이다. 자신을 반복해서 호출하다가 종료 조건에 걸리면 멈춘다.

---

## 3. 핵심 아이디어

### 재귀의 두 가지 규칙

1. **멈추는 조건** (기저 조건): "여기서 멈춰!"
2. **계속하는 방법** (재귀 조건): "작은 것으로 나눠서 다시 해!"

```text
factorial(3) = ?

"3의 팩토리얼은 3 × (3-1의 팩토리얼)"
             = 3 × factorial(2)
                   = "2 × (2-1의 팩토리얼)"
                   = 2 × factorial(1)
                         = "1! = 1 (멈춰!)"

역방향 계산:
  1 → 2*1=2 → 3*2=6
  
factorial(3) = 6
```

### 기저 조건이 없으면?

```text
거울 앞에 거울을 놓으면 무한히 반사된다 → 끝이 없음!
기저 조건 없는 재귀 = 무한 반사 → 스택 꽉 참 → 프로그램 종료!
```

---

## 4. 동작 과정 살펴보기

### 계단 내려가기 → 올라오기

```text
factorial(4) 호출
  ┌─── 4 × factorial(3) 호출
  │     ┌─── 3 × factorial(2) 호출
  │     │     ┌─── 2 × factorial(1) 호출
  │     │     │     └── return 1 (기저!)
  │     │     └── return 2 × 1 = 2
  │     └── return 3 × 2 = 6
  └── return 4 × 6 = 24

내려갈 때: 계속 쪼갬
올라올 때: 결과를 합산
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

/* 팩토리얼: n! = n × (n-1)! */
long long factorial(int n) {
    /* 멈추는 조건 */
    if (n <= 1) return 1;
    /* 계속하는 방법 */
    return n * factorial(n - 1);
}

/* 문자열 뒤집기: 첫 글자는 마지막에 */
void reverse_print(char *str, int pos) {
    if (str[pos] == '\0') return;  /* 멈추는 조건 */
    reverse_print(str, pos + 1);   /* 다음으로 */
    printf("%c", str[pos]);         /* 돌아오면서 출력 */
}

/* 카운트다운 */
void countdown(int n) {
    if (n == 0) {                  /* 멈추는 조건 */
        printf("발사!\n");
        return;
    }
    printf("%d... ", n);
    countdown(n - 1);              /* 하나 줄여서 다시 */
}

int main() {
    /* 팩토리얼 */
    printf("5! = %lld\n", factorial(5));  /* 120 */

    /* 카운트다운 */
    countdown(5);

    /* 문자열 뒤집어 출력 */
    printf("Hello 뒤집기: ");
    reverse_print("Hello", 0);
    printf("\n");

    return 0;
}
```

### 피보나치 수열 - 두 갈래로 나뉘는 재귀

```text
fib(4)
├── fib(3)
│   ├── fib(2)
│   │   ├── fib(1) = 1
│   │   └── fib(0) = 0
│   └── fib(1) = 1
└── fib(2)
    ├── fib(1) = 1
    └── fib(0) = 0

결과: 3
```

이 구조는 나무 모양과 같다. 재귀는 트리 구조 문제에 딱 맞다.

## 6. 마지막 정리

재귀는 마트료시카처럼 자신 안에 자신을 품는 구조이다.

반드시 **멈추는 조건(기저 조건)**이 있어야 한다.

너무 깊이 들어가면 스택이 꽉 차서 프로그램이 종료된다.

재귀는 트리 탐색, 분할 정복 등 자연스럽게 재귀적인 문제에 어울린다.
