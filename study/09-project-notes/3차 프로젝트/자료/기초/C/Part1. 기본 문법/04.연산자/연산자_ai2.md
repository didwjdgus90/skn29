# 본문

## 1. 한 줄 요약

연산자는 프로그래머의 도구 상자에 있는 각종 도구이다. 더하기 도구, 비교 도구, 논리 판단 도구 등 용도에 따라 골라 쓴다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

요리사에게 칼, 냄비, 뒤집개 같은 도구가 있듯이, 프로그래머에게는 연산자라는 도구가 있다.

각 도구는 특정 작업에 최적화되어 있다.

```text
칼       → 산술 연산자 (+, -, *, /)  : 값을 계산한다
저울     → 비교 연산자 (==, >, <)    : 값을 비교한다
체       → 논리 연산자 (&&, ||, !)   : 조건을 거른다
스위치   → 삼항 연산자 (? :)         : 두 가지 중 하나를 선택한다
```

---

## 3. 핵심 아이디어

### 산술 연산자 - 계산 도구

```text
10 + 3 = 13   더하기
10 - 3 = 7    빼기
10 * 3 = 30   곱하기
10 / 3 = 3    나누기 (정수끼리: 소수점 버림)
10 % 3 = 1    나머지 (10을 3으로 나눈 나머지)
```

`%`(나머지)는 특히 유용하다.
- 짝수/홀수 구분: `n % 2`가 0이면 짝수
- 순환: `n % 7`은 0~6 사이를 반복

### 비교 연산자 - 저울

비교 결과는 참(1) 또는 거짓(0)이다.

```text
5 == 5  → 1 (같다 → 참)
5 != 3  → 1 (다르다 → 참)
5 > 3   → 1 (크다 → 참)
5 < 3   → 0 (작지 않다 → 거짓)
```

### 논리 연산자 - 체(필터)

여러 조건을 연결한다.

```text
&&(AND): 두 조건이 모두 참이어야 통과
  배가 고프다 && 돈이 있다 → 밥을 먹는다

||(OR): 하나라도 참이면 통과
  비가 온다 || 날씨가 춥다 → 외투를 입는다

!(NOT): 참을 거짓으로, 거짓을 참으로
  !배가 고프다 = 배가 고프지 않다
```

## 4. 동작 과정 살펴보기

### 삼항 연산자 - 간단한 스위치

삼항 연산자는 두 가지 값 중 하나를 선택하는 작은 if문이다.

```text
조건 ? 참일 때 값 : 거짓일 때 값
   ↓
점수 >= 60 ? "합격" : "불합격"
  ↓
점수가 60 이상이면 "합격", 아니면 "불합격"
```

### 비트 연산자 - 설정 스위치 패널

비트 연산자는 컴퓨터 내부의 0과 1을 직접 다룬다.

```text
0b1010  (10진수 10)
0b1100  (10진수 12)

AND(&): 둘 다 1인 자리만 1
  0b1010
& 0b1100
= 0b1000  (10진수 8)

OR(|): 하나라도 1이면 1
  0b1010
| 0b1100
= 0b1110  (10진수 14)
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    int price = 10000;
    int quantity = 3;

    /* 산술 연산자: 총 금액 계산 */
    int total = price * quantity;
    printf("총 금액: %d원\n", total);

    /* 비교 + 논리 연산자: 할인 조건 판단 */
    int is_member = 1;   /* 1 = 참 */
    int over_50000 = (total >= 50000);

    if (is_member && over_50000) {
        printf("10%% 할인 적용!\n");
        total = total * 90 / 100;
    }

    /* 삼항 연산자: 배송비 결정 */
    int shipping = (total >= 30000) ? 0 : 3000;
    printf("배송비: %d원\n", shipping);
    printf("최종 금액: %d원\n", total + shipping);

    /* 나머지 연산자: 짝수/홀수 */
    printf("총 금액은 %s입니다.\n",
           (total % 2 == 0) ? "짝수" : "홀수");

    return 0;
}
```

### 연산자 우선순위 - 수학 시간 순서

수학에서 곱셈이 덧셈보다 먼저인 것처럼, C에도 우선순위가 있다.

```text
높음 ──→ 낮음
  ()  →  !~  →  */%  →  +-  →  <><= >=  →  ==!=  →  &&  →  ||
```

헷갈리면 괄호로 명시하면 된다.

## 6. 마지막 정리

연산자는 값을 다루는 도구이다.

산술 연산자(`+`, `-`, `*`, `/`, `%`)로 계산하고, 비교 연산자(`==`, `!=`, `<`, `>`)로 비교하고, 논리 연산자(`&&`, `||`, `!`)로 조건을 연결한다.

삼항 연산자(`? :`)는 간단한 선택문이고, 복합 대입 연산자(`+=`, `-=` 등)로 코드를 간결하게 쓸 수 있다.

우선순위가 헷갈리면 괄호를 사용하는 것이 가장 안전하다.
