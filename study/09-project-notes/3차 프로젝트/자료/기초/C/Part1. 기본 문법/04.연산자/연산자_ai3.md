# 본문

## 1. 한 줄 요약

C 연산자는 피연산자에 특정 연산을 수행하는 토큰이며, 우선순위와 결합 방향(associativity)에 따라 표현식의 평가 순서가 결정된다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

C 표현식은 연산자와 피연산자의 조합이다. 연산자의 우선순위와 결합 방향을 이해하지 못하면 표현식이 예상과 다르게 평가될 수 있다.

```c
int result = 2 + 3 * 4;      /* 14, not 20 */
int cmp    = 1 < 2 < 3;      /* 1: (1<2)=1, 1<3=1 — 의도와 다를 수 있음 */
int logic  = 1 & 2 == 2;     /* 0: == 우선순위 > & */
```

## 3. 핵심 아이디어

### 연산자 우선순위 (높음 → 낮음, 핵심만)

| 우선순위 | 연산자 | 결합 방향 |
|---|---|---|
| 1 | `()` `[]` `->` `.` | 왼쪽 |
| 2 | `!` `~` `++` `--` `+`(단항) `-`(단항) `*`(역참조) `&`(주소) `sizeof` | 오른쪽 |
| 3 | `*` `/` `%` | 왼쪽 |
| 4 | `+` `-` | 왼쪽 |
| 5 | `<<` `>>` | 왼쪽 |
| 6 | `<` `<=` `>` `>=` | 왼쪽 |
| 7 | `==` `!=` | 왼쪽 |
| 8 | `&` | 왼쪽 |
| 9 | `^` | 왼쪽 |
| 10 | `\|` | 왼쪽 |
| 11 | `&&` | 왼쪽 |
| 12 | `\|\|` | 왼쪽 |
| 13 | `?:` | 오른쪽 |
| 14 | `=` `+=` `-=` ... | 오른쪽 |

### 단락 평가 (Short-circuit Evaluation)

`&&`와 `||`는 왼쪽 피연산자 결과만으로 전체 결과가 결정되면 오른쪽을 평가하지 않는다.

```c
int x = 0;
if (x != 0 && 10 / x > 1) { ... }  /* x==0이면 오른쪽 평가 안 함 (0 나누기 방지) */

char *p = NULL;
if (p != NULL && *p == 'A') { ... }  /* p가 NULL이면 역참조 안 함 */
```

## 4. 동작 과정 살펴보기

### 비트 연산의 실용적 활용

플래그(flag) 관리에 비트 연산이 효과적이다.

```c
/* 권한 플래그 정의 */
#define READ    0x01  /* 0001 */
#define WRITE   0x02  /* 0010 */
#define EXECUTE 0x04  /* 0100 */

int perm = 0;

/* 비트 설정 (OR) */
perm |= READ | WRITE;      /* 0011 */

/* 비트 해제 (AND NOT) */
perm &= ~WRITE;            /* 0001 */

/* 비트 확인 (AND) */
if (perm & READ) { printf("읽기 가능\n"); }

/* 비트 토글 (XOR) */
perm ^= EXECUTE;           /* 0101 */
```

### 정수 승격과 묵시적 변환

```c
char a = 200;  /* 부호 있는 char이면 -56 (오버플로우) */
unsigned char b = 200;
int result = a + b;  /* a는 -56으로 승격, b는 200으로 승격 → 144 */
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    /* 비트 연산: 2의 거듭제곱 최적화 */
    int x = 16;
    printf("x * 2  = %d\n", x << 1);  /* 32: 왼쪽 시프트 = *2 */
    printf("x / 2  = %d\n", x >> 1);  /* 8:  오른쪽 시프트 = /2 (양수에 한해) */
    printf("x * 4  = %d\n", x << 2);  /* 64 */

    /* 나머지와 비트 AND (2의 거듭제곱일 때) */
    printf("x %% 8  = %d\n", x % 8);       /* 0 */
    printf("x & 7  = %d\n", x & 7);         /* 0: 2의 거듭제곱 나머지를 비트 AND로 */

    /* 연산자 우선순위 주의 */
    int a = 2, b = 3, c = 4;
    printf("%d\n", a + b * c);           /* 14: * 먼저 */
    printf("%d\n", (a + b) * c);         /* 20: () 먼저 */
    printf("%d\n", a & b | c);           /* (2&3)|4 = 2|4 = 6 */
    printf("%d\n", a | b & c);           /* 2|(3&4) = 2|0 = 2: & 우선순위 > | */

    /* 증감 연산자: 평가 순서 주의 */
    int n = 5;
    int p = n++;  /* p=5, n=6 (후위: 값 먼저, 증가 나중) */
    int q = ++n;  /* q=7, n=7 (전위: 증가 먼저, 값 나중) */
    printf("p=%d, q=%d, n=%d\n", p, q, n);

    return 0;
}
```

### 미정의 동작(Undefined Behavior) 주의

```c
int i = 5;
int j = i++ + i++;  /* UB: 같은 표현식에서 i를 두 번 수정 */
```

같은 표현식 내에서 한 변수를 두 번 이상 수정하면 C 표준은 결과를 보장하지 않는다.

## 6. 마지막 정리

연산자 우선순위와 결합 방향을 이해해야 표현식이 의도대로 평가된다.

`&&`, `||`는 단락 평가를 하므로 사이드 이펙트가 있는 코드는 주의해야 한다.

비트 연산(`&`, `|`, `^`, `~`, `<<`, `>>`)은 플래그 관리와 저수준 최적화에 활용된다.

같은 표현식에서 변수를 두 번 수정하는 것은 정의되지 않은 동작이다.
