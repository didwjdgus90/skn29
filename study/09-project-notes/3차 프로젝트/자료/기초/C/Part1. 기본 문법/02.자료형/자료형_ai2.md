# 제목
[C/Cpp 기초] 자료형

# 본문

## 1. 한 줄 요약

자료형은 데이터를 담을 그릇의 종류이다. 그릇마다 담을 수 있는 내용물의 종류와 크기가 다르다.

C에서 자료형을 배우면 각 데이터에 맞는 적절한 크기의 그릇을 선택할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

주방에 다양한 크기의 그릇이 있다고 상상해보자.

라면 하나를 담는데 거대한 솥을 쓰거나, 반대로 국물이 넘치도록 작은 그릇을 쓰면 안 된다.

```text
작은 종지  → 간장 몇 방울 (1바이트 - char)
밥공기     → 밥 한 그릇  (2~4바이트 - short, int)
냄비       → 국 한 솥    (8바이트 - long long)
눈금 있는 실린더 → 정확한 액체량 (float, double)
```

프로그래밍에서도 데이터의 종류와 크기에 맞는 그릇(자료형)을 선택해야 한다.

---

## 3. 핵심 아이디어

### 그릇의 종류 (자료형 분류)

**정수 그릇** - 자연수와 음의 정수를 담는다

```text
char      [  ] → 1바이트, -128~127 (알파벳, 작은 숫자)
short     [    ] → 2바이트, 약 -3만~3만
int       [        ] → 4바이트, 약 -21억~21억
long long [                ] → 8바이트, 아주 큰 정수
```

**실수 그릇** - 소수점이 있는 수를 담는다

```text
float  [눈금 7칸] → 4바이트, 소수점 7자리
double [눈금 15칸] → 8바이트, 소수점 15자리 (더 정밀)
```

**문자 그릇**

```text
char → 'A', 'B', '0', '!' 같은 문자 하나
```

### 그릇에 넘치면 어떻게 될까?

그릇이 넘치면(오버플로우) 값이 엉뚱하게 변한다.

```text
short 그릇의 최대: 32767
           +1 하면 → -32768 (그릇이 넘쳐서 반대쪽으로 튀어나옴!)
```

---

## 4. 동작 과정 살펴보기

### 그릇 크기 비교하기

각 그릇이 실제로 얼마나 큰지 직접 확인해볼 수 있다.

```c
#include <stdio.h>

int main() {
    printf("char 그릇 크기: %zu바이트\n", sizeof(char));
    printf("int 그릇 크기: %zu바이트\n", sizeof(int));
    printf("double 그릇 크기: %zu바이트\n", sizeof(double));
    return 0;
}
```

### 눈금 있는 그릇 (실수형) 주의점

```text
float(눈금 7칸):
  3.1415926...  → 3.141593 (7자리까지만)

double(눈금 15칸):
  3.14159265358979... → 훨씬 정밀하게 저장
```

과학 계산처럼 정밀도가 중요할 때는 `double`을 쓴다.

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    /* 사람 정보 저장하기 */
    char grade = 'A';          /* 문자 그릇: 학점 */
    int age = 25;              /* 정수 그릇: 나이 */
    double height = 175.5;    /* 실수 그릇: 키 */
    float weight = 68.3f;     /* 실수 그릇: 몸무게 (f는 float 표시) */

    printf("학점: %c\n", grade);
    printf("나이: %d세\n", age);
    printf("키: %.1f cm\n", height);
    printf("몸무게: %.1f kg\n", weight);

    return 0;
}
```

### unsigned - 양수만 담는 그릇

```text
int (부호 있는):     -21억 ~ +21억
unsigned int (부호 없는):  0 ~ 42억

음수가 필요 없다면 unsigned를 써서 더 큰 양수를 담을 수 있다.
예: 사람 수, 파일 크기 등
```

```c
unsigned int people = 4000000000;  /* 40억 */
```

### 그릇에 잘못된 내용물 넣기

```c
int x = 3.7;  /* 실수를 정수 그릇에! */
/* x에는 3이 저장됨 (소수점 이하 버려짐) */
printf("%d\n", x);  /* 3 출력 */
```

잘못된 그릇을 쓰면 데이터가 손실될 수 있다.

---

## 6. 마지막 정리

자료형은 데이터를 담는 그릇이다. 데이터 종류와 크기에 맞는 그릇을 선택해야 한다.

정수 그릇: `char` < `short` < `int` < `long long` 순으로 커진다.

실수 그릇: `float`(7자리 정밀도) < `double`(15자리 정밀도).

그릇보다 큰 값을 넣으면 오버플로우가 발생한다.

`sizeof`를 사용하면 그릇의 크기를 바이트 단위로 확인할 수 있다.
