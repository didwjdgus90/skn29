# 제목
[C/Cpp 기초] 변수와 상수

# 본문

## 1. 한 줄 요약

변수는 이름표가 붙은 상자이고, 상수는 한 번 넣으면 자물쇠가 걸리는 상자이다.

C에서 변수와 상수를 배우면 데이터에 이름을 붙여 헷갈리지 않게 관리할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

창고에 물건을 보관한다고 생각해보자.

아무 상자에나 물건을 넣고 상자에 이름표를 붙이지 않으면, 나중에 어떤 상자에 무엇이 들어있는지 찾기 힘들다.

```text
상자1: 15000
상자2: 3
상자3: 2500
```

이 숫자들이 무엇인지 도무지 알 수 없다.

이름표를 붙이면 바로 알 수 있다.

```text
[price]   상자: 15000
[count]   상자: 3
[fee]     상자: 2500
```

프로그래밍에서 이 이름표가 바로 **변수**이다.

---

## 3. 핵심 아이디어

### 변수 = 이름표가 붙은 상자

변수는 값을 담아두는 상자와 같다. 상자에 이름표(변수명)가 붙어 있어서 나중에 찾을 수 있다.

```text
┌─────────┐
│  15000  │  ← price 상자
└─────────┘

┌─────┐
│  3  │  ← count 상자
└─────┘
```

C에서는 상자를 만들 때 어떤 종류의 물건을 담을지도 미리 정해야 한다.

```text
int price = 15000;
 │     │       │
 │     │       └── 상자에 넣을 초기 값
 │     └────────── 상자 이름
 └──────────────── 담을 수 있는 물건 종류 (정수)
```

### 상수 = 자물쇠가 걸린 상자

상수는 변수와 비슷하지만, 한 번 값을 넣으면 자물쇠가 걸려서 내용물을 바꿀 수 없다.

```text
┌──────────┐
│  3.14159 │🔒  ← PI 상자 (자물쇠 잠김)
└──────────┘
```

배송비처럼 정책상 바꾸면 안 되는 값에 사용한다.

## 4. 동작 과정 살펴보기

### 물건 창고 예시로 이해하기

```text
처음 상태:
┌──────┐
│  80  │  ← score 상자
└──────┘

점수 10점 추가:
score = score + 10
      = 80 + 10
      = 90

변경 후:
┌──────┐
│  90  │  ← score 상자 (값이 바뀜)
└──────┘
```

변수는 내용물을 바꿀 수 있다.

### 상수는 내용물을 바꿀 수 없다

```text
┌──────┐
│ 2500 │🔒  ← DELIVERY_FEE 상자 (자물쇠)
└──────┘

DELIVERY_FEE = 3000;  ← 자물쇠가 잠겨 있어서 불가능! (컴파일 오류)
```

---

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    /* 변수: 내용물 교체 가능한 상자 */
    int price = 15000;
    int count = 3;

    /* 상수: 자물쇠 걸린 상자 (const) */
    const int DELIVERY_FEE = 2500;

    int total = price * count + DELIVERY_FEE;

    printf("최종 금액: %d원\n", total);

    /* 변수는 값 변경 가능 */
    price = 12000;
    printf("할인 후 가격: %d원\n", price);

    /* 상수는 값 변경 불가 - 아래 줄은 컴파일 오류 발생 */
    /* DELIVERY_FEE = 3000; */

    return 0;
}
```

### const와 #define 비교

자물쇠를 거는 방법이 두 가지 있다.

**방법 1: const - 고급 자물쇠**

```c
const double PI = 3.14159;
```

타입(double)이 명시되어 있어서 컴파일러가 타입 검사를 해준다. 더 안전하다.

**방법 2: #define - 스티커 교체**

```c
#define PI 3.14159
```

코드가 컴파일되기 전에 `PI`라는 글자를 `3.14159`로 모두 교체한다. 단순한 텍스트 교체이므로 타입 검사가 없다.

```text
#define PI 3.14159
       ↓
컴파일 전에 PI → 3.14159 로 모두 바꿈
```

### 변수 이름 짓기 규칙

좋은 이름표를 만드는 규칙이 있다.

```text
가능:
  - age, score, total_price
  - 소문자와 숫자, 밑줄 사용
  - 영문자나 밑줄로 시작

불가능:
  - 1score  (숫자로 시작)
  - my-age  (하이픈 불가)
  - int     (예약어 불가)
```

## 6. 마지막 정리

변수는 이름표 붙은 상자이다. 내용물을 자유롭게 바꿀 수 있다.

상수는 자물쇠가 걸린 상자이다. 한 번 넣으면 바꿀 수 없다.

C에서 상수를 만드는 방법은 두 가지이다.
- `const`: 타입 있는 안전한 상수
- `#define`: 컴파일 전 텍스트 치환

이름 있는 상수를 쓰면 코드의 의미가 명확해지고, 나중에 값을 바꿀 때 한 곳만 수정하면 된다.
