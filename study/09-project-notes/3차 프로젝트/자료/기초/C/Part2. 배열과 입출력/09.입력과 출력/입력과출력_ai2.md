# 본문

## 1. 한 줄 요약

`printf`는 방송(출력), `scanf`는 우편함(입력)이다. 프로그램이 세상과 소통하는 창구이다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

TV 방송을 생각해보자.

아나운서(프로그램)는 시청자에게 정보를 전달(출력)하고, 시청자는 전화나 문자로 의견을 보낸다(입력).

```text
프로그램 → printf → 화면 (방송)
사용자 → scanf → 프로그램 (우편함)
```

이 두 가지 소통 방법이 없으면 프로그램은 혼자서만 작동하는 블랙박스가 된다.

---

## 3. 핵심 아이디어

### printf - 방송 안내문

printf는 "이렇게 보여줘라"는 형식을 정해서 출력한다.

```text
printf("안녕하세요, %s! 나이: %d세\n", name, age);
                  ↑             ↑
               이름 자리      나이 자리
```

`%s`, `%d` 같은 것이 자리 표시자(형식 지정자)이다.

| 자리 표시자 | 용도 |
|---|---|
| `%d` | 정수 숫자 |
| `%f` | 소수점 있는 숫자 |
| `%c` | 글자 하나 |
| `%s` | 문자열 |

### scanf - 우편함

scanf는 사용자가 키보드로 입력한 값을 받아서 변수에 넣는다.

```text
scanf("%d", &age);
       ↑      ↑
  "정수 받겠어"  "age 우편함 주소"
```

`&`는 "이 변수의 주소(우편함 번호)"를 의미한다. 주소를 알아야 거기에 값을 넣을 수 있다.

## 4. 동작 과정 살펴보기

### printf 형식 꾸미기

```text
printf("%10d", 42);    →  "        42"  (오른쪽 정렬, 10칸)
printf("%-10d", 42);   →  "42        "  (왼쪽 정렬, 10칸)
printf("%.2f", 3.14159);→  "3.14"      (소수점 2자리)
```

표를 깔끔하게 출력할 때 유용하다.

### scanf의 우편함 비유

```text
int score;
scanf("%d", &score);

키보드에서 "85" 입력
          ↓
scanf가 "85"를 받아서
          ↓
score 우편함(&score)에 85를 넣음
          ↓
score = 85
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    /* 사용자에게 정보 요청 */
    char name[50];
    int age;
    double score;

    printf("이름: ");
    scanf("%s", name);      /* 문자열은 & 없이 */

    printf("나이: ");
    scanf("%d", &age);      /* 정수는 & 필요 */

    printf("평균 점수: ");
    scanf("%lf", &score);   /* double은 %lf */

    /* 영수증처럼 깔끔하게 출력 */
    printf("\n╔══════════════════╗\n");
    printf("║  학생 정보       ║\n");
    printf("╠══════════════════╣\n");
    printf("║ 이름: %-10s  ║\n", name);
    printf("║ 나이: %2d세       ║\n", age);
    printf("║ 점수: %5.1f점    ║\n", score);
    printf("╚══════════════════╝\n");

    return 0;
}
```

### 특수 문자 - 방송의 신호

```text
\n → 줄바꿈 (방송 자막에서 다음 줄로)
\t → 탭 (표에서 열 맞추기)
\\ → 역슬래시 문자 자체
\"  → 따옴표 문자
%%  → % 문자
```

```c
printf("할인율: 20%%\n");    /* "할인율: 20%" 출력 */
printf("경로: C:\\Users\n"); /* "경로: C:\Users" 출력 */
```

## 6. 마지막 정리

`printf`는 형식에 맞게 화면에 방송한다. `%d`, `%f`, `%s` 등의 자리 표시자를 사용한다.

`scanf`는 키보드 우편함에서 값을 받는다. 변수 주소(`&`)를 알려줘야 거기에 값을 넣을 수 있다.

문자열 배열은 이미 주소이므로 `&`가 필요 없다.

공백 포함 한 줄을 읽으려면 `scanf` 대신 `fgets`를 사용한다.
