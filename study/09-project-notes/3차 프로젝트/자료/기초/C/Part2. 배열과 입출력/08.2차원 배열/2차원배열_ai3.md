# 제목
[C/Cpp 기초] 2차원 배열

# 본문

## 1. 한 줄 요약

C의 2차원 배열은 행 우선(row-major) 순서로 연속 메모리에 배치된 1차원 배열의 논리적 재해석이며, `arr[i][j]`는 `*(arr[0] + i*cols + j)`와 동치이다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

행렬 연산, 게임 보드, 픽셀 이미지 등 2차원 구조의 데이터를 다룰 때 논리적으로 행/열 인덱싱을 제공한다.

C는 2차원 배열을 언어 수준에서 지원하지만, 내부적으로는 연속 1차원 메모리이다. 이 이해가 포인터 전달과 동적 할당에서 중요하다.

---

## 3. 핵심 아이디어

### 메모리 레이아웃 (Row-major Order)

```c
int A[3][4];
```

```text
논리적 표현:
      col0  col1  col2  col3
row0 [0,0] [0,1] [0,2] [0,3]
row1 [1,0] [1,1] [1,2] [1,3]
row2 [2,0] [2,1] [2,2] [2,3]

실제 메모리 (row-major):
A[0][0] A[0][1] A[0][2] A[0][3] | A[1][0] A[1][1] A[1][2] A[1][3] | A[2][0] ...

원소 주소 공식:
&A[i][j] = base + (i * 4 + j) * sizeof(int)
```

### 타입 시스템에서의 2차원 배열

`int A[3][4]`의 타입은 "`int[4]` 원소를 3개 가진 배열"이다.

```c
int A[3][4];
int (*row_ptr)[4] = A;  /* A → &A[0]: int(*)[4] 타입의 포인터 */
/* row_ptr + 1은 다음 행(4 * sizeof(int) = 16바이트 이동) */
```

### 함수에 전달 시 열 크기 필요

```c
/* 올바른 선언: 열 크기 명시 */
void process(int arr[][4], int rows);

/* C99 VLA 이용: 가변 열 크기 */
void process_vla(int rows, int cols, int arr[rows][cols]);
```

## 4. 동작 과정 살펴보기

### 캐시 성능: 행 우선 vs 열 우선 접근

```c
#define N 1000
int A[N][N];

/* 캐시 친화적: 행 우선 접근 (메모리 순서와 일치) */
for (int i = 0; i < N; i++)
    for (int j = 0; j < N; j++)
        A[i][j] = 0;

/* 캐시 비친화적: 열 우선 접근 (캐시 미스 빈발) */
for (int j = 0; j < N; j++)
    for (int i = 0; i < N; i++)
        A[i][j] = 0;
```

행 우선 접근이 대형 배열에서 수십 배 빠를 수 있다.

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

#define ROWS 3
#define COLS 3

/* 2차원 배열을 함수에 전달 */
void print_matrix(int A[][COLS], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < COLS; j++) {
            printf("%4d", A[i][j]);
        }
        printf("\n");
    }
}

/* 행렬 덧셈 */
void matrix_add(int A[][COLS], int B[][COLS], int C[][COLS], int rows) {
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < COLS; j++)
            C[i][j] = A[i][j] + B[i][j];
}

/* 행렬 전치 (정방행렬) */
void transpose(int A[][COLS], int n) {
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int tmp = A[i][j];
            A[i][j] = A[j][i];
            A[j][i] = tmp;
        }
}

int main() {
    int A[ROWS][COLS] = {{1,2,3},{4,5,6},{7,8,9}};
    int B[ROWS][COLS] = {{9,8,7},{6,5,4},{3,2,1}};
    int C[ROWS][COLS];

    printf("행렬 A:\n");
    print_matrix(A, ROWS);

    matrix_add(A, B, C, ROWS);
    printf("A + B:\n");
    print_matrix(C, ROWS);

    transpose(A, ROWS);
    printf("A의 전치:\n");
    print_matrix(A, ROWS);

    /* 포인터로 원소 직접 접근 */
    int *flat = &A[0][0];
    printf("연속 메모리 출력: ");
    for (int k = 0; k < ROWS * COLS; k++) {
        printf("%d ", flat[k]);
    }
    printf("\n");

    return 0;
}
```

## 6. 마지막 정리

C의 2차원 배열은 행 우선(row-major) 연속 메모리이며, `A[i][j] = *(A[0] + i*cols + j)`이다.

함수에 전달 시 열 크기는 컴파일러가 포인터 산술에 필요하므로 반드시 명시한다.

행 우선 순회가 캐시 지역성을 최대화한다.

`&A[0][0]`을 `int *`로 캐스팅하면 1차원 배열처럼 다룰 수 있다.
