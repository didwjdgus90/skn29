# 제목
[C/Cpp 기초] 2차원 배열

# 본문

## 1. 한 줄 요약

2차원 배열은 행과 열로 구성된 격자 형태의 배열이다. 표, 행렬, 게임 보드 등을 표현할 때 사용한다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

학생 3명의 과목별(국어, 영어, 수학) 점수를 저장한다고 하자.

1차원 배열 3개로도 표현할 수 있지만 관리가 복잡하다.

```c
int korean[3] = {85, 90, 78};
int english[3] = {92, 88, 95};
int math[3] = {79, 85, 91};
```

2차원 배열을 쓰면 표처럼 깔끔하게 표현된다.

```c
int scores[3][3] = {
    {85, 92, 79},  /* 학생 0 */
    {90, 88, 85},  /* 학생 1 */
    {78, 95, 91}   /* 학생 2 */
};
```

## 3. 핵심 아이디어

### 선언과 초기화

```c
자료형 배열명[행][열];

int matrix[3][4];  /* 3행 4열 */

/* 초기화 */
int mat[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

/* 중괄호 없이도 가능 */
int mat2[2][3] = {1, 2, 3, 4, 5, 6};
```

### 원소 접근

```c
int mat[2][3] = {{1,2,3},{4,5,6}};

mat[0][0]  /* 1: 0행 0열 */
mat[0][2]  /* 3: 0행 2열 */
mat[1][1]  /* 5: 1행 1열 */
```

---

## 4. 동작 과정 살펴보기

### 메모리 레이아웃 (행 우선)

```text
int mat[2][3] = {{1,2,3},{4,5,6}};

실제 메모리 (연속으로 저장):
[1][2][3][4][5][6]
 ↑           ↑
mat[0][0]   mat[1][0]

행이 통째로 나란히 저장됨 (row-major order)
```

### 2중 반복문으로 순회

```c
for (int i = 0; i < 행수; i++) {
    for (int j = 0; j < 열수; j++) {
        printf("%d ", mat[i][j]);
    }
    printf("\n");
}
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    int scores[3][3] = {
        {85, 92, 79},
        {90, 88, 85},
        {78, 95, 91}
    };
    int students = 3, subjects = 3;

    /* 출력 */
    printf("       국어 영어 수학\n");
    for (int i = 0; i < students; i++) {
        printf("학생 %d:  ", i + 1);
        for (int j = 0; j < subjects; j++) {
            printf("%3d  ", scores[i][j]);
        }
        printf("\n");
    }

    /* 각 학생의 평균 */
    printf("\n각 학생 평균:\n");
    for (int i = 0; i < students; i++) {
        int sum = 0;
        for (int j = 0; j < subjects; j++) {
            sum += scores[i][j];
        }
        printf("학생 %d: %.1f\n", i + 1, (double)sum / subjects);
    }

    /* 과목별 평균 */
    char *subject_names[] = {"국어", "영어", "수학"};
    printf("\n과목별 평균:\n");
    for (int j = 0; j < subjects; j++) {
        int sum = 0;
        for (int i = 0; i < students; i++) {
            sum += scores[i][j];
        }
        printf("%s: %.1f\n", subject_names[j], (double)sum / students);
    }

    /* 단위 행렬 생성 */
    int identity[3][3] = {0};
    for (int i = 0; i < 3; i++) {
        identity[i][i] = 1;  /* 대각선만 1 */
    }

    printf("\n단위 행렬:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", identity[i][j]);
        }
        printf("\n");
    }

    return 0;
}
```

### 행렬 곱셈 예제

```c
/* A(2x3) * B(3x2) = C(2x2) */
int A[2][3] = {{1,2,3},{4,5,6}};
int B[3][2] = {{7,8},{9,10},{11,12}};
int C[2][2] = {0};

for (int i = 0; i < 2; i++)
    for (int j = 0; j < 2; j++)
        for (int k = 0; k < 3; k++)
            C[i][j] += A[i][k] * B[k][j];
```

## 6. 마지막 정리

2차원 배열은 `배열명[행][열]`로 선언하며 표나 행렬을 표현한다.

원소 접근은 `배열명[행인덱스][열인덱스]`이다.

메모리에는 행 순서대로(row-major) 연속 저장된다.

2중 반복문으로 모든 원소를 순회할 수 있다.
