# 본문

## 1. 한 줄 요약

배열은 번호가 붙은 사물함이다. 같은 종류의 물건을 정해진 수량만큼 나란히 보관한다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

학교 사물함을 생각해보자.

학생 30명의 물건을 보관하려면 사물함 30개가 필요하다.

각각의 사물함에는 번호가 붙어 있어서 "3번 사물함"처럼 찾을 수 있다.

```text
사물함 번호: [0] [1] [2] [3] [4]
내용물:      85   92  78  90  88
```

프로그래밍에서 이것이 바로 배열이다.

변수 여러 개를 일일이 만드는 대신, 번호 붙은 사물함 묶음 하나를 만드는 것이다.

---

## 3. 핵심 아이디어

### 사물함 만들기

```text
사물함 5개 만들기:
int scores[5];

번호:    [0]   [1]   [2]   [3]   [4]

처음부터 물건 넣기:
int scores[5] = {85, 92, 78, 90, 88};
```

### 번호로 찾기 (인덱스)

사물함 번호는 0부터 시작한다.

```text
scores[0] → 85  (첫 번째 사물함)
scores[1] → 92  (두 번째 사물함)
scores[4] → 88  (다섯 번째 사물함, 마지막)
scores[5] → 위험! (6번째 사물함은 없음)
```

5개짜리 사물함의 마지막 번호는 4 (= 5 - 1).

### 사물함들이 나란히 붙어있다

배열의 사물함들은 메모리에서 나란히 붙어 있다.

```text
주소  →  1000  1004  1008  1012  1016
번호  →  [0]   [1]   [2]   [3]   [4]
값   →    85    92    78    90    88
```

## 4. 동작 과정 살펴보기

### 반복문으로 모든 사물함 순서대로 열기

```text
for (i = 0; i < 5; i++) {
  i=0: scores[0] = 85 출력
  i=1: scores[1] = 92 출력
  i=2: scores[2] = 78 출력
  i=3: scores[3] = 90 출력
  i=4: scores[4] = 88 출력
  i=5: 종료 (5 < 5 거짓)
}
```

반복문과 배열은 찰떡궁합이다.

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    /* 학생 점수 사물함 5개 */
    int scores[5] = {85, 92, 78, 90, 88};

    /* 모든 사물함 열어보기 */
    for (int i = 0; i < 5; i++) {
        printf("%d번 사물함: %d점\n", i, scores[i]);
    }

    /* 평균 구하기 */
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += scores[i];
    }
    printf("평균: %.1f점\n", (double)sum / 5);

    /* 최고 점수 찾기 */
    int max = scores[0];
    for (int i = 1; i < 5; i++) {
        if (scores[i] > max) {
            max = scores[i];
        }
    }
    printf("최고 점수: %d점\n", max);

    /* 사물함 내용 바꾸기 */
    scores[0] = 100;
    printf("수정 후 0번: %d점\n", scores[0]);

    return 0;
}
```

### 사물함 크기 자동 계산

```c
int arr[] = {10, 20, 30, 40, 50};
/* 몇 개인지 세는 방법 */
int size = sizeof(arr) / sizeof(arr[0]);
printf("사물함 개수: %d\n", size);  /* 5 */
```

`sizeof(arr)` = 전체 바이트 수 (20)
`sizeof(arr[0])` = 사물함 하나 바이트 수 (4)
20 / 4 = 5개

## 6. 마지막 정리

배열은 같은 종류의 번호 붙은 사물함들의 묶음이다.

번호(인덱스)는 0부터 시작하고, 마지막 번호는 `크기-1`이다.

범위를 벗어난 번호로 접근하면 프로그램이 오작동한다.

배열과 반복문을 함께 쓰면 많은 데이터를 효율적으로 처리할 수 있다.
