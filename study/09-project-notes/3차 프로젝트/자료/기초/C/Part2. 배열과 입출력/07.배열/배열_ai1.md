# 본문

## 1. 한 줄 요약

배열은 같은 자료형의 값 여러 개를 연속된 메모리에 저장하는 자료 구조이다.

C에서 배열을 이해하면 여러 데이터를 하나의 이름으로 묶어서 효율적으로 관리할 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

학생 5명의 점수를 저장하려면 변수가 5개 필요하다.

```c
int score1 = 85;
int score2 = 92;
int score3 = 78;
int score4 = 90;
int score5 = 88;
```

학생이 100명이면 변수 100개가 필요하다. 반복문으로 처리도 할 수 없다.

배열을 사용하면 하나의 이름으로 여러 값을 묶을 수 있다.

```c
int scores[5] = {85, 92, 78, 90, 88};
```

## 3. 핵심 아이디어

### 배열 선언과 초기화

```c
자료형 배열명[크기];
자료형 배열명[크기] = {값1, 값2, ...};
```

```c
int arr[5];                      /* 선언만 (초기화 안 됨) */
int arr[5] = {1, 2, 3, 4, 5};   /* 선언 + 초기화 */
int arr[] = {1, 2, 3, 4, 5};    /* 크기 자동 결정 */
int arr[5] = {0};                /* 모두 0으로 초기화 */
```

### 인덱스로 접근

배열의 첫 번째 원소는 인덱스 0이다.

```c
int arr[5] = {10, 20, 30, 40, 50};

arr[0]  /* 10 */
arr[1]  /* 20 */
arr[2]  /* 30 */
arr[3]  /* 40 */
arr[4]  /* 50 */
arr[5]  /* 범위 초과! 위험 */
```

## 4. 동작 과정 살펴보기

### 배열의 메모리 레이아웃

```text
int arr[5] = {10, 20, 30, 40, 50};

주소:   1000  1004  1008  1012  1016
값:      10    20    30    40    50
인덱스: [0]   [1]   [2]   [3]   [4]

각 int는 4바이트이므로 주소가 4씩 증가
```

### 배열 순회

```c
int arr[5] = {10, 20, 30, 40, 50};
int n = 5;

for (int i = 0; i < n; i++) {
    printf("arr[%d] = %d\n", i, arr[i]);
}
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    int scores[5] = {85, 92, 78, 90, 88};
    int n = 5;

    /* 출력 */
    printf("점수 목록:\n");
    for (int i = 0; i < n; i++) {
        printf("학생 %d: %d점\n", i + 1, scores[i]);
    }

    /* 합계와 평균 */
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += scores[i];
    }
    printf("합계: %d\n", sum);
    printf("평균: %.1f\n", (double)sum / n);

    /* 최댓값 */
    int max = scores[0];
    for (int i = 1; i < n; i++) {
        if (scores[i] > max) {
            max = scores[i];
        }
    }
    printf("최고 점수: %d\n", max);

    /* 배열 크기 구하기 */
    int arr[] = {1, 2, 3, 4, 5};
    int size = sizeof(arr) / sizeof(arr[0]);
    printf("배열 크기: %d\n", size);

    /* 배열 값 변경 */
    scores[2] = 95;
    printf("변경 후 학생3: %d점\n", scores[2]);

    return 0;
}
```

### 배열 초기화 주의

```c
/* 지역 변수 배열은 초기화하지 않으면 쓰레기값이 들어있다 */
int arr[5];
/* arr[0], arr[1] ... 은 예측 불가능한 값 */

/* 0으로 초기화 */
int arr2[5] = {0};
/* arr2[0] ~ arr2[4] 모두 0 */

/* 전역/정적 배열은 자동으로 0 초기화 */
int global_arr[5];  /* 전역: 자동으로 {0,0,0,0,0} */
```

## 6. 마지막 정리

배열은 같은 자료형의 값을 연속된 메모리에 저장한다.

인덱스는 0부터 시작하며, 크기-1이 마지막 인덱스이다.

범위를 벗어난 인덱스 접근은 정의되지 않은 동작으로 매우 위험하다.

배열 크기는 `sizeof(arr) / sizeof(arr[0])`으로 구할 수 있다.

지역 변수 배열은 반드시 초기화해야 한다.
