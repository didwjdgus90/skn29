# 제목
[C/Cpp 기초] 배열과 포인터

# 본문

## 1. 한 줄 요약

배열은 아파트 단지이고, 포인터는 특정 호수의 주소이다. 주소 하나만 알면 몇 호 건너서도 찾아갈 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

아파트 101호 주소를 알면 102호, 103호도 쉽게 찾을 수 있다.

```text
101호 주소: 1000번지
102호 주소: 101호 + 4(집 크기) = 1004번지
103호 주소: 101호 + 8 = 1008번지
```

C 배열도 마찬가지다. 첫 번째 원소의 주소만 알면 나머지도 계산으로 찾을 수 있다.

---

## 3. 핵심 아이디어

### 배열 = 아파트 단지

```text
int arr[5] = {10, 20, 30, 40, 50};

주소:  1000  1004  1008  1012  1016
집:   [10]  [20]  [30]  [40]  [50]
번호: [0]   [1]   [2]   [3]   [4]
```

### 배열 이름 = 101호 주소

```text
arr = 1000번지 (첫 번째 집 주소)

int *p = arr;  → p = 1000번지 (101호 주소 저장)
```

### 이동하기 (포인터 산술)

```text
p + 0 → 1000번지 (arr[0] = 10)
p + 1 → 1004번지 (arr[1] = 20)  ← +1이면 int 크기(4바이트)만큼 이동
p + 2 → 1008번지 (arr[2] = 30)
```

---

## 4. 동작 과정 살펴보기

### 두 가지 접근 방법 비교

```text
인덱스 방식:   포인터 방식:
arr[0] = 10   *(arr+0) = 10
arr[1] = 20   *(arr+1) = 20
arr[2] = 30   *(arr+2) = 30

둘 다 완전히 같은 동작!
```

### 포인터로 이동하면서 보기

```text
int *p = arr;  → p가 arr[0]을 가리킴

*p = 10        (현재 위치 값)
p++            → p가 arr[1]로 이동
*p = 20        (다음 집 값)
p++            → p가 arr[2]로 이동
...
```

---

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    /* 아파트 주소 확인 */
    printf("arr의 주소: %p\n", (void *)arr);
    printf("arr[0]의 주소: %p\n", (void *)&arr[0]);
    printf("같은 주소인가: %s\n\n",
           (arr == &arr[0]) ? "예! 같음" : "아니오");

    /* 인덱스 vs 포인터 - 둘 다 같음 */
    printf("인덱스로:  arr[2] = %d\n", arr[2]);
    printf("포인터로: *(arr+2) = %d\n\n", *(arr + 2));

    /* 포인터로 단지 순회 */
    printf("포인터 이동으로 순회:\n");
    int *p = arr;
    for (int i = 0; i < 5; i++) {
        printf("주소: %p, 값: %d\n", (void *)p, *p);
        p++;  /* 다음 집으로 이동 */
    }

    /* 역방향 순회 */
    printf("\n역순으로:\n");
    int *last = arr + 4;  /* 마지막 집 */
    while (last >= arr) {
        printf("%d ", *last);
        last--;
    }
    printf("\n");

    return 0;
}
```

### 함수에 배열 넘기기 - 주소만 전달

```text
함수에 배열을 보낼 때는 전체 단지를 복사하는 게 아니라
"101호 주소"만 전달한다.

void func(int *arr) {  ← 주소만 받음
    arr[0] = 99;       ← 원본 단지의 101호를 바꿈
}
```

---

## 6. 마지막 정리

배열은 연속된 집들의 단지이고, 포인터는 그 단지의 특정 호수 주소이다.

배열 이름 자체가 첫 번째 집의 주소이다.

`arr[i]`와 `*(arr+i)`는 완전히 같은 방식으로 동작한다.

포인터로 `+1`하면 집 하나 크기(자료형 크기)만큼 이동한다.

함수에 배열을 전달할 때는 전체가 아닌 주소(포인터)만 전달된다.
