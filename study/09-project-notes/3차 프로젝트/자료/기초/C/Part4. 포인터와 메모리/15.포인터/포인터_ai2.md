# 본문

## 1. 한 줄 요약

포인터는 주소가 적힌 메모지이다. 주소를 알면 그 집에 직접 찾아가서 내용을 바꿀 수 있다.

---

## 2. 어떤 문제를 해결하기 위해 사용하는가?

친구에게 선물을 보내려면 주소가 필요하다.

이름만 알아서는 찾아갈 수 없다. 정확한 주소(포인터)가 있어야 직접 방문할 수 있다.

```text
변수 x = 10 (서울시 강남구 ... 주소에 사는 "10"이라는 값)

int *p = &x;
p = "서울시 강남구 ..." (x의 주소를 저장한 메모지)

*p = 20 → 그 주소로 찾아가서 값을 20으로 바꿈
```

---

## 3. 핵심 아이디어

### 주소 얻기: & 연산자

```text
int x = 10;
&x → x가 살고 있는 주소 (예: 0x7fff100)
```

`&x`는 x의 주민등록 주소를 알아내는 것이다.

### 주소 저장: 포인터 변수

```text
int *p = &x;

p = 0x7fff100  (주소가 적힌 메모지)
```

`*` 별표는 "이 변수는 주소를 저장하는 메모지"라는 표시이다.

### 찾아가기: * 역참조

```text
*p → "p에 적힌 주소(0x7fff100)로 찾아가"
    → 그 주소에 있는 값: 10

*p = 20 → 그 주소로 찾아가서 20으로 바꾸기
         → x = 20이 됨
```

---

## 4. 동작 과정 살펴보기

### 우편배달부 비유

```text
편지(데이터):  "값: 10"
주소(포인터):  "0x100번지"

*p (역참조) = 0x100번지로 배달 가기

*p = 20 = 0x100번지 집(x)에 새 편지(20) 남기기
```

### 값을 바꿀 수 있는 이유

```text
포인터 없을 때 (복사 전달):
  n = 5 → 함수에 5를 복사해서 전달
  함수에서 복사본 변경 → 원본 n은 그대로 5

포인터 있을 때 (주소 전달):
  &n = 0x100 → 함수에 주소를 전달
  함수에서 0x100번지로 찾아가 값 변경 → 원본 n이 10으로 변경!
```

## 5. 구현 코드 및 상세 설명

```c
#include <stdio.h>

/* 우편배달: 주소로 찾아가서 값 변경 */
void change_value(int *p) {
    *p = 999;  /* 주소로 찾아가서 값 변경 */
}

/* 두 집 바꾸기 */
void swap(int *a, int *b) {
    int temp = *a;  /* a집의 값을 임시 저장 */
    *a = *b;        /* b집의 값을 a집에 넣기 */
    *b = temp;      /* 임시 저장값을 b집에 넣기 */
}

int main() {
    int x = 42;

    printf("변경 전: x = %d\n", x);
    change_value(&x);    /* x의 주소 전달 */
    printf("변경 후: x = %d\n", x);

    printf("\n");

    int a = 10, b = 20;
    printf("교환 전: a=%d, b=%d\n", a, b);
    swap(&a, &b);
    printf("교환 후: a=%d, b=%d\n", a, b);

    /* 포인터로 같은 변수 가리키기 */
    int n = 100;
    int *p = &n;
    int *q = &n;  /* p와 q 모두 n을 가리킴 */

    *p = 200;
    printf("*p 변경 후 *q: %d\n", *q);  /* 200: 같은 곳을 가리킴 */

    return 0;
}
```

### NULL - 주소 없음 표시

```text
NULL = "이 메모지는 아무 주소도 가리키지 않음"

int *p = NULL;  ← 빈 메모지

if (p == NULL) {
    /* 주소 없음 → 찾아가면 위험! */
}

*p  → NULL 역참조 = 존재하지 않는 주소로 찾아가기 = 프로그램 종료!
```

## 6. 마지막 정리

포인터는 변수의 주소를 저장하는 메모지이다.

`&`는 변수의 주소를 알아내고, `*`는 그 주소로 찾아가서 값을 읽거나 쓴다.

포인터 덕분에 함수에서 원본 변수를 직접 수정할 수 있다.

NULL 포인터는 역참조하면 프로그램이 종료된다. 항상 NULL 체크를 하자.
