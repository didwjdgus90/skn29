# [알고리즘] 정렬 개념

## 1. 한 줄 요약

> 정렬은 데이터를 정해진 기준에 맞게 다시 배치해, 탐색과 비교를 더 쉽게 만드는 기본 알고리즘입니다.

---

## 2. 선수 지식

- 리스트: 정렬할 데이터를 순서대로 담는 자료구조입니다.
- 비교 연산: 두 값 중 어떤 값이 앞에 와야 하는지 판단합니다.
- 반복문: 여러 원소를 차례대로 확인하고 위치를 바꿀 때 사용합니다.
- 시간복잡도: 데이터 개수가 늘어날 때 정렬 시간이 얼마나 커지는지 나타냅니다.
- 안정 정렬: 같은 값을 가진 데이터들의 기존 순서가 유지되는 정렬입니다.

---

## 3. 어떤 문제를 해결하기 위해 사용하는가?

정렬은 흩어진 데이터를 의미 있는 순서로 정리해야 할 때 사용합니다.

### 기존 방식의 문제

- 정렬되지 않은 데이터에서는 원하는 값을 찾거나 비교하기 어렵습니다.
- 가장 작은 값, 가장 큰 값, 중간값, 순위 같은 정보를 매번 직접 찾아야 합니다.
- 구간 탐색이나 중복 처리 같은 작업이 복잡해질 수 있습니다.

예를 들어 학생 점수가 뒤섞여 있으면 1등, 꼴등, 특정 점수 이상인 학생을 찾을 때 매번 전체를 확인해야 합니다.

### 이 알고리즘을 사용하면

- 데이터의 순서가 정리되어 결과를 이해하기 쉬워집니다.
- 이진 탐색처럼 정렬된 데이터를 전제로 하는 알고리즘을 사용할 수 있습니다.
- 가장 작은 값이나 큰 값을 빠르게 확인할 수 있습니다.
- 같은 값끼리 모이므로 중복 처리도 쉬워집니다.

## 4. 핵심 아이디어

정렬의 핵심은 "어떤 기준으로 앞뒤를 정할 것인가"입니다.

숫자는 작은 수부터 또는 큰 수부터 정렬할 수 있습니다. 문자열은 사전순으로 정렬할 수 있습니다. 객체나 튜플은 나이, 점수, 이름 같은 특정 속성을 기준으로 정렬할 수 있습니다.

정렬 알고리즘은 이 기준에 따라 데이터를 비교하고, 필요한 경우 위치를 바꾸며, 전체 데이터가 기준에 맞게 배열될 때까지 반복합니다.

### 쉬운 비유

책장을 정리한다고 생각해 봅시다.

책을 제목순으로 꽂을 수도 있고, 출판 연도순으로 꽂을 수도 있고, 자주 읽는 순서로 꽂을 수도 있습니다. 책은 그대로지만 기준이 달라지면 배치 결과가 달라집니다.

정렬도 같습니다. 데이터 자체보다 "어떤 기준으로 줄 세울 것인가"가 먼저 정해져야 합니다.

### 직관적으로 이해하기

`[7, 2, 5, 1]`을 오름차순으로 정렬하려면 작은 값이 앞에 오도록 만들어야 합니다.

결과는 다음과 같습니다.

```text
[1, 2, 5, 7]
```

내림차순이면 큰 값이 앞에 와야 하므로 결과가 달라집니다.

```text
[7, 5, 2, 1]
```

## 5. 동작 과정 살펴보기

### 예제 상황

선택 정렬을 사용해 숫자 리스트를 오름차순으로 정렬하겠습니다.

선택 정렬은 남은 구간에서 가장 작은 값을 찾아 앞쪽에 놓는 방식입니다.

### 예제 입력

```text
numbers = [6, 3, 8, 2, 5]
```

### 예제 출력

```text
[2, 3, 5, 6, 8]
```

### 단계별 동작

1. 전체 구간 `[6, 3, 8, 2, 5]`에서 가장 작은 값 `2`를 찾습니다.
2. `2`를 맨 앞의 `6`과 바꿉니다. 결과는 `[2, 3, 8, 6, 5]`입니다.
3. 이제 첫 번째 원소는 정렬됐으므로 남은 구간 `[3, 8, 6, 5]`를 봅니다.
4. 남은 구간에서 가장 작은 값은 `3`이므로 그대로 둡니다.
5. 다음 구간 `[8, 6, 5]`에서 가장 작은 값 `5`를 찾습니다.
6. `5`를 구간의 맨 앞인 `8`과 바꿉니다. 결과는 `[2, 3, 5, 6, 8]`입니다.
7. 남은 구간도 이미 정렬되어 있으므로 최종 결과가 완성됩니다.

## 7. 기본 코드 템플릿

```python
def selection_sort(values):
    result = values[:]

    for fixed_index in range(len(result) - 1):
        smallest_index = fixed_index

        for check_index in range(fixed_index + 1, len(result)):
            if result[check_index] < result[smallest_index]:
                smallest_index = check_index

        result[fixed_index], result[smallest_index] = (
            result[smallest_index],
            result[fixed_index],
        )

    return result


def sort_students_by_score(students):
    return sorted(students, key=lambda student: (student["score"], student["name"]))


if __name__ == "__main__":
    print(selection_sort([6, 3, 8, 2, 5]))

    students = [
        {"name": "min", "score": 80},
        {"name": "ara", "score": 70},
        {"name": "jun", "score": 80},
    ]
    print(sort_students_by_score(students))
```

### 코드 흐름 설명

* `selection_sort`는 원본 리스트를 바꾸지 않기 위해 복사본 `result`를 만듭니다.
* `fixed_index`는 이번에 값을 확정할 위치입니다.
* `smallest_index`는 아직 정렬되지 않은 구간에서 가장 작은 값의 위치입니다.
* 안쪽 반복문은 남은 구간을 훑으며 가장 작은 값을 찾습니다.
* 가장 작은 값을 찾으면 현재 위치와 교환합니다.
* `sort_students_by_score`는 Python 내장 정렬을 사용합니다.
* `key=lambda student: (student["score"], student["name"])`는 점수 기준으로 먼저 정렬하고, 점수가 같으면 이름 기준으로 정렬한다는 뜻입니다.

## 8. 시간복잡도와 공간복잡도

### 시간복잡도

* 선택 정렬은 매번 남은 구간에서 최솟값을 찾으므로 `O(n^2)`입니다.
* 삽입 정렬은 거의 정렬된 데이터에서는 빠를 수 있지만 평균적으로 `O(n^2)`입니다.
* 병합 정렬은 보통 `O(n log n)`을 안정적으로 유지합니다.
* 퀵 정렬은 평균적으로 `O(n log n)`이지만 기준 선택이 나쁘면 `O(n^2)`이 될 수 있습니다.
* Python의 내장 정렬은 일반적으로 `O(n log n)`이며, 일부 정렬된 구간을 잘 활용합니다.

### 공간복잡도

* 선택 정렬은 제자리에서 바꿀 수 있어 추가 공간이 적습니다.
* 병합 정렬은 병합 과정에서 추가 배열이 필요할 수 있습니다.
* 내장 정렬은 구현 방식에 따라 추가 메모리를 사용합니다.

초급 단계에서는 직접 정렬 알고리즘을 구현하는 이유와, 실제 문제에서는 내장 정렬을 언제 써야 하는지를 함께 이해하는 것이 중요합니다.

## 9. 예제로 이해하기

이번에는 상품 목록을 가격순으로 정렬하겠습니다.

입력 데이터:

```text
items = [
  ("notebook", 3000),
  ("pen", 800),
  ("folder", 1200),
  ("eraser", 500)
]
```

가격 기준 오름차순 정렬 결과:

```text
[
  ("eraser", 500),
  ("pen", 800),
  ("folder", 1200),
  ("notebook", 3000)
]
```

처리 과정:

1. 각 데이터에서 비교 기준을 가격으로 정합니다.
2. 가장 낮은 가격인 `500`을 가진 상품을 먼저 둡니다.
3. 그다음 `800`, `1200`, `3000` 순서로 배치합니다.
4. 상품 이름은 함께 따라오지만, 정렬 기준은 가격입니다.

정렬 문제에서는 데이터 전체가 아니라 "비교할 기준"이 무엇인지 먼저 찾아야 합니다.

## 11. 비슷한 알고리즘과 헷갈리는 부분

### 정렬과 탐색

정렬은 데이터를 순서대로 배치하는 작업입니다. 탐색은 원하는 값을 찾는 작업입니다.

정렬을 먼저 해 두면 이진 탐색처럼 빠른 탐색을 사용할 수 있습니다.

### 선택 정렬과 삽입 정렬

선택 정렬은 남은 구간에서 가장 작은 값을 찾아 앞에 둡니다.

삽입 정렬은 현재 값을 이미 정렬된 구간의 알맞은 위치에 끼워 넣습니다.

### 안정 정렬과 불안정 정렬

안정 정렬은 같은 기준값을 가진 데이터의 기존 순서를 유지합니다.

예를 들어 점수만 기준으로 정렬할 때, 같은 점수 학생들의 입력 순서가 유지되면 안정 정렬입니다.

### 내장 정렬과 직접 구현

코딩 테스트에서 일반적인 정렬이 필요하면 내장 정렬을 쓰는 것이 보통 더 안전합니다.

직접 구현은 정렬 알고리즘의 원리를 이해하거나, 문제에서 특정 정렬 방식을 요구할 때 필요합니다.

## 12. 자주 하는 실수

* 오름차순과 내림차순 조건을 반대로 구현합니다.
* 정렬 기준이 여러 개인데 하나만 고려합니다.
* 원본 리스트를 바꾸면 안 되는 문제에서 직접 정렬해 버립니다.
* 안정성이 필요한 문제에서 같은 값의 기존 순서가 깨지는 방식을 사용합니다.
* 선택 정렬에서 최솟값의 값과 인덱스를 헷갈립니다.
* 반복 범위를 잘못 잡아 마지막 원소를 비교하지 않습니다.
* `sort()`와 `sorted()`의 차이를 헷갈립니다.
* 문자열 숫자를 숫자로 변환하지 않고 정렬해 `"10"`이 `"2"`보다 앞서는 결과를 만듭니다.

## 13. 힌트 생성용 관점

### 1단계 힌트: 개념 힌트

이 문제는 데이터를 특정 기준에 따라 먼저 정리하면 쉬워질 수 있습니다. 어떤 값이 앞에 와야 하는지 기준을 찾아보세요.

### 2단계 힌트: 접근 힌트

정렬 기준이 하나인지, 여러 개인지 확인하세요. 여러 기준이 있다면 튜플 형태의 key를 사용해 우선순위를 표현할 수 있습니다.

### 3단계 힌트: 구현 힌트

Python에서는 `sorted(data, key=...)`를 사용할 수 있습니다. 직접 구현해야 한다면 선택 정렬처럼 현재 위치에 들어갈 값을 남은 구간에서 찾아 교환하는 방식부터 생각해 보세요.

## 14. 언제 사용하면 좋은가

* 입력 조건: 데이터를 순서대로 정리한 뒤 처리하면 문제가 단순해질 때 좋습니다.
* 문제 유형: 순위 구하기, 회의 시간 정렬, 좌표 정렬, 중복 제거, 이진 탐색 전처리에 적합합니다.
* 자주 등장하는 표현: "정렬", "순서대로", "가장 작은", "가장 큰", "사전순", "우선순위"가 단서입니다.
* 적합한 자료구조: 리스트와 배열이 기본입니다.
* 사용하면 안 되는 경우: 매번 값이 추가되고 최솟값만 필요하다면 힙이 더 적합할 수 있습니다. 특정 값 조회만 빠르게 해야 한다면 해시가 더 좋을 수 있습니다.

## 15. 요약 정리

* 정렬은 데이터를 기준에 맞게 다시 배치하는 알고리즘입니다.
* 정렬 기준을 먼저 정해야 올바른 결과를 만들 수 있습니다.
* 선택 정렬은 남은 구간에서 최솟값을 찾아 앞에 놓는 방식입니다.
* 선택 정렬의 시간복잡도는 `O(n^2)`입니다.
* 안정 정렬은 같은 값의 기존 순서를 유지합니다.
* Python에서는 실전에서 `sort()`와 `sorted()`를 자주 사용합니다.
* 정렬 후에는 탐색, 중복 처리, 인접 비교가 쉬워집니다.
* 데이터 크기와 안정성 필요 여부에 따라 정렬 방식을 선택해야 합니다.
