# [알고리즘] 스택 개념

## 1. 한 줄 요약

> 스택은 가장 나중에 넣은 데이터를 가장 먼저 꺼내는 후입선출 구조의 자료구조입니다.

---

## 2. 선수 지식

- 리스트: Python에서 스택을 간단히 구현할 때 사용하는 기본 자료구조입니다.
- 인덱스: 리스트의 마지막 원소를 확인할 때 필요합니다.
- 조건문: 스택이 비어 있는지 확인하고 예외 상황을 처리합니다.
- 반복문: 입력 데이터를 하나씩 확인하며 스택에 넣거나 꺼냅니다.
- 자료구조: 데이터를 어떤 규칙으로 저장하고 꺼낼지 정한 방식입니다.

---

## 3. 어떤 문제를 해결하기 위해 사용하는가?

스택은 "최근에 들어온 데이터부터 먼저 처리해야 하는 문제"에서 사용합니다.

### 기존 방식의 문제

- 최근 값을 계속 비교해야 할 때 리스트 전체를 매번 훑으면 비효율적입니다.
- 되돌아가기처럼 직전 상태를 기억해야 하는 문제를 변수 하나로 처리하기 어렵습니다.
- 괄호 짝 검사처럼 나중에 열린 것이 먼저 닫혀야 하는 구조는 일반 큐나 단순 카운트만으로 부족할 수 있습니다.

예를 들어 문서 편집기에서 마지막으로 한 작업을 취소하려면, 가장 최근 작업부터 순서대로 되돌려야 합니다.

### 이 알고리즘을 사용하면

- 마지막에 넣은 값을 `O(1)`에 꺼낼 수 있습니다.
- 최근 상태를 차곡차곡 저장했다가 역순으로 처리할 수 있습니다.
- 괄호 검사, 뒤로 가기, DFS, 수식 계산 같은 문제를 명확하게 표현할 수 있습니다.

## 4. 핵심 아이디어

스택의 핵심은 입구가 하나라는 점입니다.

데이터를 넣는 곳과 꺼내는 곳이 모두 같은 끝입니다. 그래서 먼저 넣은 데이터는 아래에 깔리고, 나중에 넣은 데이터가 위에 놓입니다.

가장 위에 있는 데이터만 바로 꺼낼 수 있으므로, 마지막에 넣은 데이터가 가장 먼저 나옵니다.

### 쉬운 비유

책상 위에 노트를 한 권씩 쌓는다고 생각해 봅시다.

처음 놓은 노트는 아래에 있고, 가장 최근에 놓은 노트는 맨 위에 있습니다. 노트를 꺼낼 때는 맨 위의 노트부터 집어야 합니다. 아래 노트를 바로 꺼내려면 위에 있는 노트들을 먼저 치워야 합니다.

스택도 이와 같은 방식으로 동작합니다.

### 직관적으로 이해하기

스택에 `A`, `B`, `C`를 차례로 넣으면 내부 모습은 다음과 같습니다.

```text
Top -> C
       B
       A
```

이 상태에서 하나를 꺼내면 `C`가 먼저 나옵니다. 그다음은 `B`, 마지막은 `A`입니다.

## 5. 동작 과정 살펴보기

### 예제 상황

웹 브라우저에서 방문한 페이지를 저장하고, 뒤로 가기 버튼을 눌렀을 때 최근 페이지부터 돌아간다고 생각해 봅시다.

### 예제 입력

```text
visit: "home"
visit: "search"
visit: "article"
back
back
```

### 예제 출력

```text
article
search
```

### 단계별 동작

1. 빈 스택을 준비합니다.
2. `"home"`을 방문하면 스택에 넣습니다.
3. `"search"`를 방문하면 그 위에 넣습니다.
4. `"article"`을 방문하면 다시 그 위에 넣습니다.
5. 뒤로 가기를 누르면 가장 위의 `"article"`을 꺼냅니다.
6. 다시 뒤로 가기를 누르면 이제 가장 위에 있는 `"search"`를 꺼냅니다.
7. 마지막에 들어온 페이지부터 처리됩니다.

## 7. 기본 코드 템플릿

```python
class SimpleStack:
    def __init__(self):
        self._items = []

    def push(self, value):
        self._items.append(value)

    def pop(self):
        if self.is_empty():
            return None
        return self._items.pop()

    def peek(self):
        if self.is_empty():
            return None
        return self._items[-1]

    def is_empty(self):
        return len(self._items) == 0

    def size(self):
        return len(self._items)


def is_valid_brackets(text):
    pairs = {
        ")": "(",
        "]": "[",
        "}": "{",
    }
    stack = []

    for char in text:
        if char in "([{":
            stack.append(char)
        elif char in ")]}":
            if not stack:
                return False
            if stack[-1] != pairs[char]:
                return False
            stack.pop()

    return len(stack) == 0


if __name__ == "__main__":
    history = SimpleStack()
    history.push("home")
    history.push("search")
    history.push("article")

    print(history.pop())
    print(history.peek())
    print(history.size())

    print(is_valid_brackets("{[()]}"))
    print(is_valid_brackets("{[(])}"))
```

### 코드 흐름 설명

* `SimpleStack`은 Python 리스트를 이용해 스택을 구현합니다.
* `push`는 리스트 마지막에 값을 추가합니다.
* `pop`은 리스트 마지막 값을 제거하고 반환합니다.
* `peek`은 마지막 값을 확인만 하고 제거하지 않습니다.
* `is_empty`는 꺼낼 값이 있는지 확인합니다.
* 괄호 검사에서는 여는 괄호를 만나면 스택에 넣습니다.
* 닫는 괄호를 만나면 스택 맨 위의 여는 괄호와 짝이 맞는지 확인합니다.
* 모든 문자를 본 뒤 스택이 비어 있으면 모든 괄호가 알맞게 닫힌 것입니다.

## 8. 시간복잡도와 공간복잡도

### 시간복잡도

* `push`: 리스트 끝에 추가하므로 평균 `O(1)`입니다.
* `pop`: 리스트 끝에서 제거하므로 `O(1)`입니다.
* `peek`: 마지막 원소만 확인하므로 `O(1)`입니다.
* 괄호 검사는 문자열을 한 번 순회하므로 `O(n)`입니다.

### 공간복잡도

* 스택에 최대 `n`개의 데이터가 들어갈 수 있으므로 `O(n)`입니다.
* 괄호 검사에서도 여는 괄호가 모두 쌓일 수 있으므로 최악의 경우 `O(n)` 공간이 필요합니다.

## 9. 예제로 이해하기

문자열 `"[{()}]"`가 올바른 괄호인지 확인해 봅시다.

입력 데이터:

```text
[{()}]
```

처리 과정:

1. `[`를 만나 스택에 넣습니다. 스택: `[`
2. `{`를 만나 스택에 넣습니다. 스택: `[ {`
3. `(`를 만나 스택에 넣습니다. 스택: `[ { (`
4. `)`를 만나 맨 위 `(`와 짝을 확인하고 꺼냅니다.
5. `}`를 만나 맨 위 `{`와 짝을 확인하고 꺼냅니다.
6. `]`를 만나 맨 위 `[`와 짝을 확인하고 꺼냅니다.
7. 문자열이 끝났을 때 스택이 비어 있으므로 올바른 괄호입니다.

반대로 `"[(])"`는 `]`를 만났을 때 스택 맨 위가 `(`입니다. 닫는 대괄호와 짝이 맞지 않으므로 잘못된 괄호입니다.

## 11. 비슷한 알고리즘과 헷갈리는 부분

### 스택과 큐

스택은 마지막에 들어간 값이 먼저 나옵니다. 큐는 먼저 들어간 값이 먼저 나옵니다.

되돌아가기나 최근 값 처리는 스택이 어울리고, 대기열이나 순서대로 처리하는 작업은 큐가 어울립니다.

### `pop`과 `peek`

`pop`은 값을 확인하면서 제거합니다. `peek`은 값을 확인만 하고 제거하지 않습니다.

값을 계속 사용해야 한다면 `peek`을 쓰고, 처리 완료 후 없애야 한다면 `pop`을 씁니다.

### 리스트와 스택

Python 리스트는 여러 위치에 접근할 수 있지만, 스택처럼 사용할 때는 마지막 위치에서만 넣고 빼는 규칙을 지키는 것이 중요합니다.

중간 원소를 자주 삭제하면 스택의 장점을 잃고 시간도 더 오래 걸릴 수 있습니다.

## 12. 자주 하는 실수

* 빈 스택에서 `pop`이나 `peek`을 시도합니다.
* `peek`해야 하는 상황에서 `pop`을 사용해 값을 실수로 제거합니다.
* 괄호 검사에서 닫는 괄호가 먼저 나오는 경우를 처리하지 않습니다.
* 문자열을 모두 확인한 뒤 스택이 비어 있는지 확인하지 않습니다.
* Python 리스트 앞쪽에서 `pop(0)`을 사용해 큐처럼 동작시킵니다.
* 스택의 맨 위가 리스트의 마지막 원소라는 점을 헷갈립니다.
* 재귀를 스택으로 바꿀 때 방문 처리나 상태 저장을 빠뜨립니다.
* 문제에서 FIFO가 필요한데 LIFO인 스택을 사용합니다.

* 적합한 자료구조: Python에서는 리스트를 스택처럼 사용하는 것이 가장 간단합니다.
* 사용하면 안 되는 경우: 먼저 들어온 값을 먼저 처리해야 한다면 큐를 사용해야 합니다.

## 15. 요약 정리

* 스택은 후입선출, 즉 마지막에 넣은 값이 먼저 나오는 자료구조입니다.
* 주요 연산은 `push`, `pop`, `peek`, `is_empty`, `size`입니다.
* Python에서는 리스트의 `append`, `pop`, `[-1]`로 쉽게 구현할 수 있습니다.
* 스택의 기본 연산은 보통 `O(1)`입니다.
* 괄호 검사, 되돌아가기, DFS, 최근 값 비교 문제에서 자주 사용합니다.
* 빈 스택에서 값을 꺼내는 실수를 조심해야 합니다.
* `pop`은 제거, `peek`은 확인만 한다는 차이를 명확히 알아야 합니다.
