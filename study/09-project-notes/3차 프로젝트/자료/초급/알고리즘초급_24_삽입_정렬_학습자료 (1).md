# [알고리즘] 삽입 정렬

## 1. 한 줄 요약

> 삽입 정렬은 왼쪽의 정렬된 구간에 새 값을 알맞은 위치로 끼워 넣으며 정렬 범위를 넓혀 가는 정렬 알고리즘입니다.

---

## 2. 선수 지식

- 배열과 리스트: 정렬할 데이터를 순서대로 저장합니다.
- 인덱스: 현재 값과 그 왼쪽 값을 비교할 때 사용합니다.
- 반복문: 두 번째 원소부터 끝까지 차례대로 확인합니다.
- 비교 연산: 두 값 중 어느 값이 앞에 와야 하는지 판단합니다.
- 값 이동: 삽입할 자리를 만들기 위해 기존 값을 한 칸씩 뒤로 미룹니다.
- 안정 정렬: 같은 값을 가진 원소들의 기존 순서를 유지하는 정렬입니다.

---

## 3. 어떤 문제를 해결하기 위해 사용하는가?

삽입 정렬은 작은 데이터나 거의 정렬된 데이터를 단순하게 정렬할 때 사용합니다.

### 기존 방식의 문제

- 정렬되지 않은 전체 목록에서 매번 복잡한 구조를 만들 필요가 없을 수 있습니다.
- 데이터가 이미 어느 정도 정렬되어 있는데 무거운 정렬 방식을 쓰면 오히려 부담이 될 수 있습니다.
- 정렬 원리를 처음 배울 때, 값이 제자리를 찾는 과정을 눈으로 이해하기 어렵습니다.

예를 들어 숫자 목록이 `[1, 2, 4, 5, 3]`처럼 거의 정렬되어 있다면 `3`만 알맞은 위치에 끼워 넣으면 됩니다.

### 이 알고리즘을 사용하면

- 왼쪽 정렬 구간을 유지하면서 한 원소씩 정렬할 수 있습니다.
- 데이터가 거의 정렬된 상태라면 비교 횟수가 크게 줄어듭니다.
- 추가 배열을 거의 쓰지 않고 제자리에서 정렬할 수 있습니다.

삽입 정렬은 큰 무작위 데이터에는 느릴 수 있지만, 정렬 원리를 이해하기에 매우 좋은 알고리즘입니다.

## 4. 핵심 아이디어

삽입 정렬은 항상 "왼쪽은 이미 정렬되어 있다"고 생각합니다.

1. 두 번째 원소부터 시작합니다.
2. 현재 값을 잠시 저장합니다.
3. 왼쪽 정렬 구간에서 현재 값보다 큰 값을 한 칸씩 뒤로 밉니다.
4. 빈자리에 현재 값을 넣습니다.
5. 이 과정을 마지막 원소까지 반복합니다.

### 쉬운 비유

번호가 적힌 서류를 책상 위에 정리한다고 생각해봅시다. 왼손에는 이미 번호순으로 정리된 서류 묶음이 있습니다. 새 서류를 하나 집으면, 정리된 묶음 안에서 들어갈 자리를 찾아 끼워 넣습니다.

삽입 정렬도 같습니다. 새 값을 정렬된 왼쪽 구간에 끼워 넣으며 정렬된 부분을 조금씩 키웁니다.

### 직관적으로 이해하기

`[4, 7, 2, 5]`를 정렬한다고 해봅시다.

- 처음에는 `[4]`가 정렬된 구간입니다.
- `7`은 `4`보다 크므로 그대로 둡니다. 정렬 구간은 `[4, 7]`입니다.
- `2`는 `7`, `4`보다 작으므로 두 값을 뒤로 밀고 맨 앞에 넣습니다.
- `5`는 `7`보다 작고 `4`보다 크므로 `4`와 `7` 사이에 넣습니다.

결과는 `[2, 4, 5, 7]`입니다.

## 5. 동작 과정 살펴보기

### 예제 상황

숫자 카드 `6 2 9 4 7`을 오름차순으로 정렬합니다.

### 예제 입력

```text
5
6 2 9 4 7
```

### 예제 출력

```text
2 4 6 7 9
```

### 단계별 동작

1. `6` 하나만 있는 왼쪽 구간은 이미 정렬된 상태로 봅니다.
2. `2`를 꺼내 왼쪽의 `6`과 비교합니다. `6`을 뒤로 밀고 `2`를 앞에 넣습니다.
3. `9`는 왼쪽의 `6`보다 크므로 그대로 둡니다.
4. `4`는 `9`, `6`보다 작으므로 두 값을 뒤로 밀고 `2` 뒤에 넣습니다.
5. `7`은 `9`보다 작고 `6`보다 크므로 `6`과 `9` 사이에 넣습니다.
6. 모든 원소를 처리하면 정렬이 끝납니다.

## 7. 기본 코드 템플릿

```python
def insertion_sort(numbers):
    for index in range(1, len(numbers)):
        value_to_insert = numbers[index]
        position = index

        while position > 0 and numbers[position - 1] > value_to_insert:
            numbers[position] = numbers[position - 1]
            position -= 1

        numbers[position] = value_to_insert

    return numbers


def main():
    count = int(input())
    numbers = list(map(int, input().split()))

    sorted_numbers = insertion_sort(numbers)
    print(*sorted_numbers)


if __name__ == "__main__":
    main()
```

### 코드 흐름 설명

* 바깥 반복문은 두 번째 원소부터 하나씩 선택합니다.
* `value_to_insert`는 이번에 제자리를 찾아야 하는 값입니다.
* `position`은 현재 값을 넣을 위치를 찾기 위해 왼쪽으로 이동합니다.
* `while`문은 왼쪽 값이 더 크면 한 칸 뒤로 밀어냅니다.
* 더 이상 밀 필요가 없으면 빈자리에 `value_to_insert`를 넣습니다.
* 정렬은 입력 리스트 안에서 직접 이루어집니다.

## 8. 시간복잡도와 공간복잡도

### 시간복잡도

* 평균적인 경우: 왼쪽 정렬 구간을 여러 번 비교하므로 `O(n^2)`입니다.
* 최악의 경우: 내림차순처럼 완전히 반대로 정렬되어 있으면 매번 맨 앞까지 이동해야 하므로 `O(n^2)`입니다.
* 최선의 경우: 이미 정렬되어 있으면 각 원소가 한 번씩만 비교되고 거의 이동하지 않아 `O(n)`입니다.
* 입력 크기가 커졌을 때 부담되는 부분: 원소가 많고 무작위에 가까울수록 비교와 이동 횟수가 크게 늘어납니다.

### 공간복잡도

* 추가 배열을 만들지 않고 입력 리스트 안에서 정렬합니다.
* 임시 변수 몇 개만 사용하므로 추가 공간은 `O(1)`입니다.
* 제자리 정렬에 해당합니다.

삽입 정렬은 안정 정렬입니다. 같은 값을 만났을 때 기존 순서를 유지하려면 `>` 비교를 사용하고, 같은 값까지 밀어내는 `>=` 비교는 피해야 합니다.

## 9. 예제로 이해하기

다른 예제로 `[5, 1, 4, 4, 2]`를 정렬해봅시다.

처리 과정:

```text
단계   처리 값   배열 상태
초기   -         [5, 1, 4, 4, 2]
1      1         [1, 5, 4, 4, 2]
2      4         [1, 4, 5, 4, 2]
3      4         [1, 4, 4, 5, 2]
4      2         [1, 2, 4, 4, 5]
```

3단계에서 두 번째 `4`는 앞에 있는 `4`와 값이 같습니다. 안정 정렬을 유지하려면 앞의 `4`를 뒤로 밀지 않습니다. 그래서 같은 값들의 상대적인 순서가 유지됩니다.

최종 결과:

```text
1 2 4 4 5
```

## 10. 문제에서 이 알고리즘을 떠올리는 신호

* 데이터 크기가 작습니다.
* 거의 정렬된 배열을 정렬해야 합니다.
* 추가 메모리를 적게 쓰는 정렬이 필요합니다.
* 정렬 과정을 직접 구현해야 합니다.
* 안정 정렬 성질이 필요합니다.
* 새로운 값이 들어올 때마다 정렬된 위치에 끼워 넣는 상황입니다.
* 기본 정렬 알고리즘의 동작 원리를 설명해야 합니다.

## 11. 비슷한 알고리즘과 헷갈리는 부분

### 삽입 정렬과 선택 정렬

선택 정렬은 남은 값 중 가장 작은 값을 찾아 앞쪽에 놓습니다. 삽입 정렬은 현재 값을 왼쪽 정렬 구간의 알맞은 위치에 끼워 넣습니다. 선택 정렬은 보통 안정 정렬이 아니지만, 삽입 정렬은 안정 정렬로 구현하기 쉽습니다.

### 삽입 정렬과 버블 정렬

버블 정렬은 인접한 두 값을 계속 비교하며 큰 값을 뒤로 보냅니다. 삽입 정렬도 인접 비교를 할 수 있지만, 핵심은 현재 값을 정렬된 구간에 삽입하는 것입니다.

### swap 방식과 shift 방식

swap 방식은 현재 값이 왼쪽으로 이동할 때마다 두 값을 맞바꿉니다. shift 방식은 현재 값을 따로 저장하고 큰 값들을 한 칸씩 뒤로 민 뒤 마지막에 넣습니다. 일반적으로 shift 방식이 대입 횟수를 줄이기 좋습니다.

### 삽입 정렬과 이진 삽입 정렬

이진 삽입 정렬은 삽입 위치를 이진 탐색으로 찾습니다. 하지만 실제로 값을 뒤로 미는 작업은 여전히 필요하므로 전체 시간복잡도는 보통 `O(n^2)` 범위입니다.

## 12. 자주 하는 실수

* 첫 번째 원소부터 비교하려고 해서 인덱스 범위를 벗어나는 실수
* 현재 값을 임시 변수에 저장하지 않고 덮어써 버리는 실수
* `position`을 감소시키지 않아 무한 반복이 되는 실수
* 삽입 위치를 찾은 뒤 값을 다시 넣지 않는 실수
* 같은 값을 `>=`로 밀어 안정 정렬 성질을 깨는 실수
* 최선의 경우가 `O(n)`이라는 점을 놓치는 실수
* 큰 데이터에도 삽입 정렬을 그대로 사용해 시간초과가 나는 실수
* 오름차순과 내림차순 비교 조건을 반대로 쓰는 실수

## 13. 힌트 생성용 관점

### 1단계 힌트: 개념 힌트

왼쪽 구간이 이미 정렬되어 있다고 생각해보세요. 새 값 하나를 그 정렬된 구간 안의 알맞은 위치에 끼워 넣으면 됩니다.

### 2단계 힌트: 접근 힌트

두 번째 원소부터 시작하세요. 현재 값을 저장해 두고, 왼쪽 값들이 현재 값보다 크면 한 칸씩 뒤로 밀어 빈자리를 만드세요.

### 3단계 힌트: 구현 힌트

`while position > 0 and numbers[position - 1] > value_to_insert` 조건으로 왼쪽을 확인하세요. 반복이 끝난 뒤 `numbers[position] = value_to_insert`를 반드시 실행해야 합니다.

## 14. 언제 사용하면 좋은가

* 데이터 수가 적을 때 좋습니다.
* 이미 거의 정렬된 데이터에 적합합니다.
* 정렬 알고리즘의 기본 원리를 설명하거나 학습할 때 좋습니다.
* 안정 정렬이 필요하고 구현이 단순해야 할 때 사용할 수 있습니다.
* 큰 무작위 데이터에는 비효율적입니다.
* 빠른 범용 정렬이 필요하면 내장 정렬, 병합 정렬, 퀵 정렬, 힙 정렬 등을 고려해야 합니다.

## 15. 요약 정리

* 삽입 정렬의 목적은 새 값을 왼쪽 정렬 구간에 끼워 넣으며 전체를 정렬하는 것입니다.
* 핵심 아이디어는 현재 값을 저장하고, 큰 값들을 뒤로 민 뒤 빈자리에 삽입하는 것입니다.
* 주요 자료구조는 배열 또는 리스트입니다.
* 시간복잡도는 최선 `O(n)`, 평균과 최악 `O(n^2)`입니다.
* 문제에서 거의 정렬된 데이터, 안정 정렬, 작은 입력이 보이면 떠올릴 수 있습니다.
* 초급자는 임시 값 저장, 삽입 위치 갱신, 안정 정렬 조건을 특히 주의해야 합니다.
