# [알고리즘] 올바른 괄호

## 1. 한 줄 요약

> 올바른 괄호 문제는 여는 괄호를 스택에 쌓아 두고, 닫는 괄호가 나올 때 가장 최근의 여는 괄호와 짝을 맞추는 문제입니다.

---

## 2. 선수 지식

- 스택: 나중에 넣은 값을 먼저 꺼내는 자료구조입니다.
- `append`: Python 리스트의 끝에 값을 추가합니다.
- `pop`: Python 리스트의 마지막 값을 꺼냅니다.
- 조건문: 현재 문자가 여는 괄호인지 닫는 괄호인지 구분합니다.
- 문자열 순회: 문자열을 왼쪽부터 한 글자씩 확인합니다.
- 빈 리스트 판별: 리스트가 비어 있으면 `False`처럼 사용할 수 있습니다.

---

## 3. 어떤 문제를 해결하기 위해 사용하는가?

수식, 코드, 문자열에서 괄호가 제대로 열리고 닫혔는지 확인할 때 사용합니다.

### 기존 방식의 문제

- 여는 괄호와 닫는 괄호의 개수만 세면 순서 오류를 잡을 수 없습니다.
- `())(`처럼 개수는 같아도 올바르지 않은 문자열이 있습니다.
- 괄호가 여러 단계로 중첩되면 가장 안쪽 괄호부터 맞춰야 합니다.

예를 들어 `(()())`는 올바르지만 `())(()`는 여는 괄호와 닫는 괄호 개수가 같아도 중간에 닫는 괄호가 먼저 많아져 잘못된 문자열입니다.

### 이 알고리즘을 사용하면

- 가장 최근에 열린 괄호를 바로 확인할 수 있습니다.
- 닫는 괄호가 나왔을 때 짝이 될 여는 괄호가 있는지 즉시 판단할 수 있습니다.
- 문자열을 한 번만 훑어도 올바른지 확인할 수 있습니다.

괄호 문제에서 스택이 잘 맞는 이유는 괄호가 "가장 나중에 열린 것이 가장 먼저 닫혀야 하는 구조"이기 때문입니다.

---

## 4. 핵심 아이디어

스택은 괄호의 대기열처럼 사용됩니다.

1. 여는 괄호 `(`가 나오면 스택에 넣습니다.
2. 닫는 괄호 `)`가 나오면 스택에서 하나를 꺼냅니다.
3. 꺼낼 여는 괄호가 없으면 잘못된 문자열입니다.
4. 모든 문자를 확인한 뒤 스택이 비어 있어야 올바른 문자열입니다.

### 쉬운 비유

상자를 여러 개 포개서 열었다고 생각해봅시다. 가장 마지막에 연 상자를 먼저 닫아야 깔끔하게 정리됩니다. 중간에 아래쪽 상자를 먼저 닫으려고 하면 구조가 맞지 않습니다.

괄호도 같습니다. 가장 최근에 열린 괄호가 먼저 닫혀야 올바른 짝이 됩니다.

### 직관적으로 이해하기

문자열 `(())`를 봅시다.

```text
(  → 스택: (
(  → 스택: ((
)  → 스택: (
)  → 스택: 비어 있음
```

끝났을 때 스택이 비었으므로 모든 괄호가 짝을 찾았습니다.

반대로 `(()`는 마지막에 여는 괄호 하나가 남습니다. 이 경우 닫히지 않은 괄호가 있으므로 올바르지 않습니다.

## 5. 동작 과정 살펴보기

### 예제 상황

문자열에 들어 있는 소괄호가 올바르게 짝을 이루는지 확인합니다. 괄호가 아닌 문자는 무시합니다.

### 예제 입력

```text
(x + (y * z)) - w
```

### 예제 출력

```text
True
```

### 단계별 동작

1. 빈 스택을 준비합니다.
2. 문자열을 왼쪽부터 한 글자씩 확인합니다.
3. `(`를 만나면 스택에 넣습니다.
4. `)`를 만나면 스택에서 `(` 하나를 꺼냅니다.
5. 닫는 괄호를 만났는데 스택이 비어 있으면 `False`입니다.
6. 모든 문자를 확인한 뒤 스택이 비어 있으면 `True`, 남아 있으면 `False`입니다.


## 7. 기본 코드 템플릿

```python
def is_valid_parentheses(text):
    open_stack = []

    for character in text:
        if character == "(":
            open_stack.append(character)
        elif character == ")":
            if not open_stack:
                return False
            open_stack.pop()

    return len(open_stack) == 0


def main():
    text = input()
    print(is_valid_parentheses(text))


if __name__ == "__main__":
    main()
```

### 코드 흐름 설명

* `open_stack`은 아직 닫히지 않은 여는 괄호를 저장합니다.
* 반복문은 문자열을 왼쪽부터 한 글자씩 확인합니다.
* 여는 괄호를 만나면 스택에 추가합니다.
* 닫는 괄호를 만나면 짝이 될 여는 괄호가 있는지 확인합니다.
* 스택이 비어 있는데 닫는 괄호가 나오면 바로 `False`를 반환합니다.
* 끝까지 확인한 뒤 스택이 비어 있으면 모든 괄호가 닫힌 것입니다.

---

## 8. 시간복잡도와 공간복잡도

### 시간복잡도

* 평균적인 경우: 문자열을 한 번 순회하므로 `O(n)`입니다.
* 최악의 경우: 모든 문자를 끝까지 확인해야 하므로 `O(n)`입니다.
* 입력 크기가 커졌을 때 부담되는 부분: 문자 수가 늘어난 만큼 순회 시간이 늘어납니다.

스택에 넣고 빼는 작업은 Python 리스트의 끝에서 수행하므로 평균적으로 `O(1)`입니다.

### 공간복잡도

* 최악의 경우 모든 문자가 여는 괄호라면 스택에 `n`개가 쌓입니다.
* 따라서 공간복잡도는 `O(n)`입니다.
* 괄호가 적거나 빠르게 닫히면 실제 사용 공간은 더 작습니다.

## 9. 예제로 이해하기

이번에는 잘못된 문자열을 보겠습니다.

```text
(()))(
```

처리 과정:

```text
문자   스택 상태       판단
(      (              여는 괄호 저장
(      ((             여는 괄호 저장
)      (              하나 제거
)      비어 있음      하나 제거
)      비어 있음      제거할 여는 괄호 없음
```

다섯 번째 문자에서 닫는 괄호가 나왔지만 스택이 비어 있습니다. 이미 닫을 괄호가 없는데 닫으려고 한 것이므로 결과는 `False`입니다.

최종 결과:

```text
False
```

이 예제는 전체 괄호 개수를 끝까지 세기 전에 중간에서 잘못된 상태를 발견할 수 있음을 보여줍니다.

## 10. 문제에서 이 알고리즘을 떠올리는 신호

* 괄호의 짝이 맞는지 확인해야 합니다.
* 최근에 들어온 값부터 먼저 처리해야 합니다.
* 문자열을 왼쪽부터 읽으며 이전 문자를 기억해야 합니다.
* 중첩된 구조가 등장합니다.
* "올바른 괄호", "짝이 맞는지", "닫히는 순서" 같은 표현이 나옵니다.
* 바로 앞 값 또는 가장 마지막에 저장한 값과 비교해야 합니다.
* 같은 문자가 붙어 있으면 제거하는 문제처럼 최근 값과 현재 값을 비교하는 패턴이 보입니다.

## 11. 비슷한 알고리즘과 헷갈리는 부분

### 스택과 큐

스택은 마지막에 넣은 값을 먼저 꺼냅니다. 괄호는 가장 최근에 열린 괄호가 먼저 닫혀야 하므로 스택이 맞습니다. 큐는 먼저 넣은 값을 먼저 꺼내므로 괄호 짝 검사에는 맞지 않습니다.

### 개수 세기와 스택

소괄호만 있고 단순한 경우에는 개수를 세는 방식처럼 보일 수 있습니다. 하지만 여러 종류의 괄호가 섞이면 개수만으로는 순서와 모양을 확인할 수 없습니다. 이때는 스택에 실제 괄호를 저장해야 합니다.

### 소괄호 검사와 여러 괄호 검사

소괄호만 검사할 때는 `(`와 `)`만 보면 됩니다. `{}`, `[]`까지 검사하려면 닫는 괄호마다 기대하는 여는 괄호가 다르므로 짝 정보를 따로 저장해야 합니다.

### 짝지어 제거하기 문제와 괄호 문제

같은 문자가 연속해서 만나면 제거하는 문제도 스택으로 풀 수 있습니다. 현재 문자와 스택의 마지막 문자를 비교한다는 점이 비슷합니다.

## 12. 자주 하는 실수

* 닫는 괄호가 나왔을 때 스택이 비었는지 확인하지 않는 실수
* 문자열을 끝까지 본 뒤 스택이 비었는지 검사하지 않는 실수
* 괄호가 아닌 문자를 잘못 처리하는 실수
* 여러 종류의 괄호에서 모양이 맞는지 확인하지 않는 실수
* `pop()`을 먼저 하고 나중에 빈 스택 여부를 확인하는 실수
* 큐를 사용해서 먼저 열린 괄호부터 닫으려고 하는 실수
* 괄호 개수만 같으면 올바르다고 판단하는 실수
* `stack[-1]`을 사용할 때 스택이 비어 있는지 먼저 확인하지 않는 실수

## 13. 힌트 생성용 관점

### 1단계 힌트: 개념 힌트

가장 최근에 열린 괄호가 가장 먼저 닫혀야 합니다. 이런 구조는 스택의 마지막 값 확인과 잘 맞습니다.

### 2단계 힌트: 접근 힌트

문자열을 왼쪽부터 하나씩 보세요. 여는 괄호는 저장하고, 닫는 괄호가 나오면 저장된 여는 괄호 하나를 꺼내 짝을 맞추면 됩니다.

### 3단계 힌트: 구현 힌트

Python 리스트를 스택처럼 사용할 수 있습니다. `append()`로 넣고 `pop()`으로 꺼내세요. 닫는 괄호를 처리하기 전에 리스트가 비어 있는지 반드시 확인해야 합니다.

## 14. 언제 사용하면 좋은가

* 괄호나 태그처럼 열고 닫는 구조를 검사할 때 좋습니다.
* 최근에 들어온 값과 현재 값을 비교해야 할 때 적합합니다.
* 중첩 구조를 왼쪽부터 해석해야 할 때 사용할 수 있습니다.
* 문자열에서 인접한 짝을 제거하는 문제에도 응용할 수 있습니다.
* 처리 순서가 먼저 들어온 값부터라면 스택보다 큐를 검토해야 합니다.
* 전체 순서보다 현재까지의 열린 상태를 관리하는 문제가 스택과 잘 맞습니다.

## 15. 요약 정리

* 올바른 괄호 문제의 목적은 괄호가 순서와 짝을 모두 만족하는지 확인하는 것입니다.
* 핵심 아이디어는 여는 괄호를 스택에 저장하고 닫는 괄호가 나올 때 하나씩 제거하는 것입니다.
* 주요 자료구조는 스택이며, Python에서는 리스트로 구현할 수 있습니다.
* 시간복잡도는 `O(n)`, 공간복잡도는 최악의 경우 `O(n)`입니다.
* 문제에서 중첩, 짝, 최근 값 비교가 보이면 스택을 떠올릴 수 있습니다.
* 초급자는 빈 스택에서 꺼내는 상황과 마지막 스택 잔여 검사를 특히 주의해야 합니다.
