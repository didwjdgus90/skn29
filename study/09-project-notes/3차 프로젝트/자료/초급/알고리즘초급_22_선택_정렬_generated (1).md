# [알고리즘] 선택 정렬

## 1. 한 줄 요약

> 선택 정렬은 아직 정렬되지 않은 구간에서 가장 작은 값을 찾아 앞자리와 바꾸는 과정을 반복하는 정렬 알고리즘입니다.

---

## 2. 선수 지식

- 리스트: 정렬할 값을 순서대로 담는 자료구조입니다.
- 인덱스: 현재 위치와 최솟값 위치를 추적할 때 사용합니다.
- 비교 연산: 두 값 중 더 작은 값을 찾기 위해 필요합니다.
- 교환: 두 위치의 값을 서로 바꾸는 작업입니다.
- 제자리 정렬: 입력 리스트 안에서 값을 바꾸며 정렬하고, 큰 추가 메모리를 쓰지 않는 방식입니다.
- 안정 정렬: 같은 값을 가진 데이터의 기존 순서가 유지되는 정렬입니다.

---

## 3. 어떤 문제를 해결하기 위해 사용하는가?

선택 정렬은 데이터를 오름차순이나 내림차순으로 정리하는 가장 기본적인 방법 중 하나입니다.

### 기존 방식의 문제

- 정렬되지 않은 데이터에서는 가장 작은 값이나 큰 값을 매번 직접 찾아야 합니다.
- 원하는 순서로 데이터를 정리하지 않으면 탐색, 순위 계산, 비교가 불편합니다.
- 정렬 원리를 처음 배우는 단계에서는 복잡한 정렬보다 단순한 구조가 필요합니다.

### 이 알고리즘을 사용하면

- 정렬되지 않은 구간과 정렬된 구간을 명확히 나눌 수 있습니다.
- 매 단계에서 어떤 값이 확정되는지 눈으로 따라가기 쉽습니다.
- 추가 메모리를 거의 사용하지 않고 리스트 내부에서 정렬할 수 있습니다.

다만 선택 정렬은 모든 구간을 반복해서 확인하므로 데이터가 많을 때는 느립니다. 실전에서는 내장 정렬이나 더 빠른 정렬을 쓰는 경우가 많습니다.

---

## 4. 핵심 아이디어

선택 정렬의 핵심은 "이번 위치에 들어갈 값을 선택한다"입니다.

오름차순 정렬이라면 첫 번째 위치에는 전체에서 가장 작은 값이 와야 합니다. 두 번째 위치에는 첫 번째 값을 제외한 나머지 중 가장 작은 값이 와야 합니다.

이 과정을 반복하면 왼쪽부터 하나씩 자리가 확정됩니다.

### 쉬운 비유

키 순서대로 줄을 세운다고 생각해 봅시다.

먼저 전체 사람 중 가장 키가 작은 사람을 찾아 맨 앞에 세웁니다. 그다음 남은 사람 중 가장 작은 사람을 찾아 두 번째에 세웁니다. 이렇게 남은 사람들 중에서 매번 한 명을 선택해 앞쪽 자리를 채워 나갑니다.

선택 정렬도 같은 방식입니다.

### 직관적으로 이해하기

리스트가 `[9, 4, 7, 2]`라면 첫 번째 자리에 들어갈 값은 `2`입니다.

`2`를 찾아 첫 번째 값 `9`와 바꾸면 `[2, 4, 7, 9]`가 됩니다.

이제 첫 번째 값 `2`는 더 이상 볼 필요가 없습니다. 남은 구간 `[4, 7, 9]`에서 다시 가장 작은 값을 찾으면 됩니다.

## 5. 동작 과정 살펴보기

### 예제 상황

숫자 리스트를 선택 정렬로 오름차순 정렬하겠습니다.

### 예제 입력

```text
numbers = [8, 3, 6, 1, 5]
```

### 예제 출력

```text
[1, 3, 5, 6, 8]
```

### 단계별 동작

1. 전체 구간 `[8, 3, 6, 1, 5]`에서 가장 작은 값 `1`을 찾습니다.
2. `1`을 첫 번째 값 `8`과 바꿉니다. 결과는 `[1, 3, 6, 8, 5]`입니다.
3. 이제 첫 번째 위치는 확정입니다.
4. 남은 구간 `[3, 6, 8, 5]`에서 가장 작은 값은 `3`입니다. 이미 제자리에 있으므로 그대로 둡니다.
5. 남은 구간 `[6, 8, 5]`에서 가장 작은 값 `5`를 찾습니다.
6. `5`를 현재 구간의 첫 값 `6`과 바꿉니다. 결과는 `[1, 3, 5, 8, 6]`입니다.
7. 남은 구간 `[8, 6]`에서 가장 작은 값 `6`을 찾아 `8`과 바꿉니다.
8. 최종 결과는 `[1, 3, 5, 6, 8]`입니다.

  └─ 예 → [정렬 완료]

## 7. 기본 코드 템플릿

```python
def selection_sort(values, reverse=False):
    sorted_values = values[:]

    for target_index in range(len(sorted_values) - 1):
        selected_index = target_index

        for scan_index in range(target_index + 1, len(sorted_values)):
            should_update = (
                sorted_values[scan_index] > sorted_values[selected_index]
                if reverse
                else sorted_values[scan_index] < sorted_values[selected_index]
            )

            if should_update:
                selected_index = scan_index

        if selected_index != target_index:
            sorted_values[target_index], sorted_values[selected_index] = (
                sorted_values[selected_index],
                sorted_values[target_index],
            )

    return sorted_values


if __name__ == "__main__":
    data = [8, 3, 6, 1, 5]

    print(selection_sort(data))
    print(selection_sort(data, reverse=True))
    print(data)
```

### 코드 흐름 설명

* `sorted_values = values[:]`는 원본을 바꾸지 않기 위해 복사본을 만듭니다.
* `target_index`는 이번에 값을 확정할 위치입니다.
* `selected_index`는 남은 구간에서 가장 작거나 큰 값의 위치입니다.
* `reverse=False`이면 오름차순으로 정렬합니다.
* `reverse=True`이면 내림차순으로 정렬합니다.
* 안쪽 반복문은 남은 구간을 끝까지 훑으면서 선택할 위치를 갱신합니다.
* 마지막에 현재 위치와 선택된 위치의 값을 교환합니다.
* 마지막 원소는 앞의 원소들이 정렬되면 자동으로 제자리에 오므로 바깥 반복은 `len - 1`번만 수행합니다.

## 8. 시간복잡도와 공간복잡도

### 시간복잡도

* 선택 정렬은 최선, 평균, 최악 모두 `O(n^2)`입니다.
* 이미 정렬된 리스트여도 남은 구간에서 최솟값을 찾기 위해 비교를 계속합니다.
* 비교 횟수는 대략 `(n - 1) + (n - 2) + ... + 1`입니다.
* 따라서 데이터가 커질수록 시간이 빠르게 늘어납니다.

### 공간복잡도

* 입력 리스트 내부에서 직접 바꾸면 추가 공간은 `O(1)`입니다.
* 위 코드처럼 원본 보호를 위해 복사본을 만들면 `O(n)` 공간이 추가로 필요합니다.
* 알고리즘 자체는 큰 별도 저장 공간을 요구하지 않는 제자리 정렬 방식입니다.

## 9. 예제로 이해하기

이번에는 점수 목록 `[42, 17, 33, 25]`를 오름차순으로 정렬해 보겠습니다.

입력 데이터:

```text
[42, 17, 33, 25]
```

처리 과정:

1. 전체에서 가장 작은 값은 `17`입니다. `42`와 바꿉니다.

```text
[17, 42, 33, 25]
```

2. 남은 구간 `[42, 33, 25]`에서 가장 작은 값은 `25`입니다. `42`와 바꿉니다.

```text
[17, 25, 33, 42]
```

3. 남은 구간 `[33, 42]`에서 가장 작은 값은 `33`입니다. 이미 제자리에 있습니다.

```text
[17, 25, 33, 42]
```

4. 마지막 값은 자동으로 정렬된 상태입니다.

최종 결과:

```text
[17, 25, 33, 42]
```

## 10. 문제에서 이 알고리즘을 떠올리는 신호

* 정렬 알고리즘의 원리를 직접 구현하라는 문제입니다.
* 입력 크기가 작고 `O(n^2)`도 허용됩니다.
* 추가 메모리를 거의 쓰지 않고 정렬해야 합니다.
* 매 단계에서 최솟값 또는 최댓값을 찾아 앞쪽부터 확정하는 흐름이 자연스럽습니다.
* 교환 횟수를 비교적 적게 유지하고 싶습니다.
* 정렬 과정 자체를 설명하거나 출력해야 합니다.

## 11. 비슷한 알고리즘과 헷갈리는 부분

### 선택 정렬과 삽입 정렬

선택 정렬은 남은 구간에서 최솟값을 찾아 현재 위치와 바꿉니다.

삽입 정렬은 현재 값을 이미 정렬된 구간 안의 알맞은 위치에 끼워 넣습니다.

### 선택 정렬과 버블 정렬

버블 정렬은 인접한 두 값을 반복해서 비교하고 교환합니다.

선택 정렬은 한 라운드에서 최솟값 위치를 끝까지 찾은 뒤 한 번 교환합니다.

### 선택 정렬과 내장 정렬

선택 정렬은 학습용으로 이해하기 좋지만 큰 데이터에는 느립니다.

실전에서는 Python의 `sort()`나 `sorted()`를 사용하는 것이 일반적으로 더 빠르고 안전합니다.

### 안정 정렬과의 차이

선택 정렬은 같은 값을 가진 데이터의 상대 순서가 바뀔 수 있습니다.

예를 들어 같은 점수를 가진 학생들의 입력 순서를 유지해야 한다면 선택 정렬은 조심해야 합니다.

## 12. 자주 하는 실수

* 최솟값 자체와 최솟값의 인덱스를 헷갈립니다.
* 안쪽 반복문의 시작을 `target_index + 1`이 아니라 잘못된 위치로 둡니다.
* 매 비교마다 바로 교환해서 선택 정렬이 아닌 다른 흐름이 됩니다.
* 마지막 원소까지 바깥 반복을 돌려 불필요한 작업을 합니다.
* 이미 제자리에 있는 값도 무조건 교환해 불필요한 연산을 만듭니다.
* 내림차순 구현에서 비교 방향을 바꾸지 않습니다.
* 안정 정렬이 필요한 상황에서 선택 정렬을 사용합니다.
* 원본 리스트가 바뀌면 안 되는 상황에서 복사하지 않고 직접 정렬합니다.

## 13. 힌트 생성용 관점

### 1단계 힌트: 개념 힌트

이번 위치에 들어갈 값을 아직 정렬되지 않은 구간에서 찾아야 합니다. 오름차순이라면 남은 값 중 가장 작은 값을 선택하세요.

### 2단계 힌트: 접근 힌트

왼쪽부터 한 칸씩 확정해 보세요. 현재 인덱스를 기준으로 오른쪽 끝까지 훑으며 최솟값의 위치를 찾고, 현재 위치와 교환하면 됩니다.

### 3단계 힌트: 구현 힌트

바깥 반복문은 `0`부터 `len(arr) - 2`까지 돌면 충분합니다. 안쪽 반복문에서는 `min_index`를 갱신하고, 안쪽 반복문이 끝난 뒤 한 번만 swap하세요.

## 14. 언제 사용하면 좋은가

* 입력 조건: 데이터 개수가 작거나 학습 목적으로 정렬 과정을 직접 구현할 때 좋습니다.
* 문제 유형: 정렬 기본 구현, 최솟값 선택 반복, 제자리 정렬 연습에 적합합니다.
* 자주 등장하는 표현: "최솟값을 찾아 앞으로 보낸다", "선택 정렬로 구현하라", "정렬 과정을 출력하라"가 단서입니다.
* 적합한 자료구조: 배열이나 리스트에 적합합니다.
* 사용하면 안 되는 경우: 데이터가 많거나 안정 정렬이 필요하면 다른 정렬 또는 내장 정렬을 사용하는 편이 좋습니다.

## 15. 요약 정리

* 선택 정렬은 남은 구간에서 최솟값을 선택해 앞쪽에 배치합니다.
* 왼쪽부터 하나씩 정렬된 구간이 늘어납니다.
* 구현은 단순하지만 시간복잡도는 `O(n^2)`입니다.
* 추가 메모리는 거의 필요하지 않아 제자리 정렬로 볼 수 있습니다.
* 같은 값의 기존 순서가 바뀔 수 있어 불안정 정렬입니다.
* 매 라운드에서 최솟값을 찾고, 라운드가 끝난 뒤 한 번만 교환하는 것이 핵심입니다.
