## 1. 한 줄 요약

- 세그먼트 트리는 **구간(범위)에 대한 정보를 빠르게 구하고, 값이 변경되어도 효율적으로 반영할 수 있는 자료구조**이다.

---

## 2. 주요 활용처 및 문제 유형

다음 숫자 배열이 있다고 하자.

```
인덱스

0  1  2  3  4

값

5  8  3  6  2
```

---

질문이 계속 들어온다.

```
1번 ~ 3번 합은?

2번 ~ 4번 합은?

0번 ~ 4번 합은?
```

---

가장 단순한 방법은

매번 직접 더하는 것이다.

```
5 + 8 + 3 + 6 + 2
```

---

하지만 데이터가

```
100,000개
```

라면?

---

질문도

```
100,000번
```

들어온다면?

---

매번 직접 계산하면 너무 느리다.

---

게다가 중간에 값이 바뀔 수도 있다.

```
3번 값

6 → 10
```

---

이때

```
구간 합

구간 최댓값

구간 최솟값
```

등을 빠르게 처리하기 위해 사용하는 것이

```
세그먼트 트리
```

이다.

---

### 코딩 테스트에서 자주 나오는 문제

다음 문장이 보이면 세그먼트 트리를 의심해보자.

- 구간 합
- 구간 최댓값
- 구간 최솟값
- 값 변경(Update)
- N, Q가 매우 큼
- 여러 번의 구간 질의

특히

```
구간 조회 + 값 변경
```

이 함께 나오면 세그먼트 트리일 가능성이 높다.

매번 100명을 전부 더하면 비효율적이다.

## 5. 파이썬(Python) 구현 코드

### 세그먼트 트리 생성

```
arr= [5,8,3,6]

tree= [0]* (4*len(arr))

defbuild(node,start,end):

ifstart==end:
tree[node]=arr[start]
return

mid= (start+end)//2

build(node*2,start,mid)
build(node*2+1,mid+1,end)

tree[node]= (
tree[node*2]
+tree[node*2+1]
    )

build(1,0,len(arr)-1)
```

---

### 구간 합 조회

```
defquery(node,start,end,left,right):

# 범위 밖
ifright<startorend<left:
return0

# 완전히 포함
ifleft<=startandend<=right:
returntree[node]

mid= (start+end)//2

return (
query(node*2,start,mid,left,right)
+
query(node*2+1,mid+1,end,left,right)
    )
```

---

사용

```
print(query(1,0,3,1,2))
```

출력

```
11
```
