## 1. 한 줄 요약

- 프림 알고리즘은 **하나의 정점에서 시작하여 가장 저렴한 간선을 계속 선택하면서 최소 신장 트리(MST)를 만드는 알고리즘**이다.

---

## 2. 주요 활용처 및 문제 유형

어느 나라가 전국 도시에 전력망을 설치하려고 한다고 생각해보자.

```
서울
대전
부산
광주
```

모든 도시를 연결해야 한다.

하지만

```
비용은 최소
```

로 만들고 싶다.

---

예를 들어

```
서울 ── 3 ── 대전

서울 ── 10 ── 부산

대전 ── 2 ── 부산
```

이라면

```
서울 → 부산 (10)
```

보다

```
서울 → 대전 → 부산

3 + 2 = 5
```

가 훨씬 저렴하다.

---

이처럼

```
모든 정점을 연결

+

총 비용 최소
```

를 구하는 문제를

```
최소 신장 트리(MST)
```

문제라고 한다.

---

### 코딩 테스트에서 자주 나오는 문제

다음 문장이 보이면 MST를 의심해보자.

- 전력망 설치
- 도로 건설
- 통신망 구축
- 마을 연결
- 모든 노드 연결
- 최소 비용 연결

---

## 3. 핵심 아이디어

### 비유

무인도 여러 개를 다리로 연결한다고 생각해보자.

처음에는 한 섬만 가지고 있다.

```
[A]
```

---

이제 연결할 수 있는 다리 중

가장 싼 다리를 선택한다.

```
[A]──2──B
```

---

그 다음

현재 연결된 섬들에서

갈 수 있는 다리 중

가장 싼 것을 선택한다.

```
[A]──2──B──1──C
```

---

이 과정을 반복하면

결국 모든 섬이 연결된다.

---

즉 프림의 생각은

> "현재 연결된 영역을 조금씩 확장하자"
> 

이다.

---

### 크루스칼과의 차이

크루스칼은

```
그래프 전체에서

가장 싼 간선
```

을 찾는다.

---

프림은

```
현재 연결된 트리에서

밖으로 나가는

가장 싼 간선
```

을 찾는다.

---

## 4. 알고리즘 동작 과정 (Step-by-Step 시각화)

다음 그래프를 보자.

```
     4

A ------- B

| \       |

|  \      |

2   5     1

|    \    |

|     \   |

C ------- D

     3
```

간선

```
A-B : 4
A-C : 2
A-D : 5
B-D : 1
C-D : 3
```

---

### Step 1. 시작 정점 선택

A에서 시작

```
[A]
```

---

현재 선택 가능한 간선

```
A-B : 4
A-C : 2
A-D : 5
```

---

가장 싼 것

```
A-C : 2
```

선택

---

현재 상태

```
A ─ C
```

비용

```
2
```

---

### Step 2. 연결 영역 확장

현재 MST

```
A ─ C
```

---

선택 가능한 간선

```
A-B : 4
A-D : 5
C-D : 3
```

---

가장 싼 것

```
C-D : 3
```

선택

---

현재 상태

```
A ─ C ─ D
```

비용

```
2 + 3 = 5
```

---

### Step 3. 다시 확장

현재 MST

```
A ─ C ─ D
```

---

후보

```
A-B : 4
D-B : 1
```

---

가장 싼 것

```
D-B : 1
```

선택

---

현재 상태

```
A ─ C ─ D ─ B
```

비용

```
2 + 3 + 1 = 6
```

---

모든 정점이 연결되었다.

---

### Step 4. 종료

최종 MST

```
A ─ C
    │
    D ─ B
```

선택된 간선

```
A-C : 2
C-D : 3
D-B : 1
```

총 비용

```
6
```

## 5. 파이썬(Python) 구현 코드

```
importheapq

n=4

graph= [
    [],
    [(2,4), (3,2), (4,5)],
    [(1,4), (4,1)],
    [(1,2), (4,3)],
    [(1,5), (2,1), (3,3)]
]

visited= [False]* (n+1)

pq= []

# (비용, 정점)
heapq.heappush(pq, (0,1))

mst_cost=0

whilepq:

cost,now=heapq.heappop(pq)

# 이미 MST에 포함된 정점이면 무시
ifvisited[now]:
continue

visited[now]=True

mst_cost+=cost

fornext_node,next_costingraph[now]:

ifnotvisited[next_node]:
heapq.heappush(
pq,
                (next_cost,next_node)
            )

print(mst_cost)
```

출력

```
6
```

---

### 핵심 코드 설명

---


---

```
cost,now=heapq.heappop(pq)
```

현재 갈 수 있는 간선 중

가장 비용이 작은 것을 선택한다.

---

```
ifvisited[now]:
continue
```

이미 MST에 포함된 정점이면 무시한다.

---

```
mst_cost+=cost
```

선택된 간선 비용을 누적한다.

---

```

```

현재 정점에서 갈 수 있는 모든 간선을 확인한다.

---

```

pq,
    (next_cost,next_node)
)
```

후보 간선들을 우선순위 큐에 넣는다.

## 6. 핵심 요약 및 주의점

### 최소 신장 트리(MST)란?

```
모든 정점 연결

+

사이클 없음

+

비용 최소
```

인 트리이다.

---

### 프림의 핵심 아이디어

```
현재 연결된 영역

↓

가장 싼 간선 선택

↓

새 정점 추가

↓

반복
```

---

### 시각화

```
[A]

↓

[A]──C

↓

[A]──C──D

↓

[A]──C──D──B
```

---

### 시간 복잡도

우선순위 큐 사용 시

```
O(E log V)
```

- V = 정점 수
- E = 간선 수

---

### 공간 복잡도

```
O(V + E)
```

그래프와 우선순위 큐를 저장한다.

---

### 자주 하는 실수

### 1. 방문 체크 안 하기

```
ifvisited[now]:
continue
```

를 빼먹으면 같은 정점을 여러 번 선택할 수 있다.

---

### 2. 다익스트라와 혼동하기

프림도 우선순위 큐를 사용한다.

그래서 다익스트라와 매우 비슷하게 보인다.

하지만 목적이 완전히 다르다.

---

## 크루스칼과 차이점

| 항목 | 프림 | 크루스칼 |
| --- | --- | --- |
| 관점 | 정점 중심 | 간선 중심 |
| 시작 정점 | 필요 | 불필요 |
| 핵심 자료구조 | 우선순위 큐 | 유니온 파인드 |
| 선택 기준 | 현재 트리에서 가장 싼 간선 | 전체 간선 중 가장 싼 간선 |
| 동작 방식 | 트리를 확장 | 간선을 선택 |

---

### 그림으로 이해하기

### 프림

```
현재 트리

[A]

↓

확장

[A]──C

↓

확장

[A]──C──D
```

트리가 점점 커진다.

---

### 크루스칼

```
전체 간선 정렬

1
2
3
4
5
...
```

↓

```
싼 간선부터 선택

사이클이면 버림
```

---

### 언제 사용할까?

### 간선 목록만 주어진 경우

```
(비용, 정점1, 정점2)
```

↓

```
크루스칼
```

이 구현하기 쉽다.

---

### 인접 리스트 그래프

```
1 : (2,4), (3,2)
2 : ...
```

↓

```
프림
```

이 자연스럽다.

---

### 꼭 기억할 것

```
프림

=
현재 트리를
조금씩 확장하는 MST 알고리즘
```

```
1. 시작 정점 선택

2. 연결 가능한 간선 중 최저 비용 선택

3. 새로운 정점 추가

4. 모든 정점이 연결될 때까지 반복
```

한 문장으로 기억하면,

> **프림은 "현재 만들어진 네트워크에서 가장 저렴하게 새로운 정점을 추가해 나가는 알고리즘"이다.**
>
