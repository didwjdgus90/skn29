## 1. 한 줄 요약

- 위상 정렬은 **"반드시 먼저 해야 하는 일"의 순서를 지키면서 작업을 나열하는 알고리즘**이다.

---

## 2. 주요 활용처 및 문제 유형

대학교 수강 신청을 생각해보자.

예를 들어,

```
자료구조
   ↓
알고리즘
   ↓
고급 알고리즘
```

이라면

알고리즘을 듣기 전에 자료구조를 먼저 들어야 한다.

고급 알고리즘을 듣기 전에 알고리즘을 먼저 들어야 한다.

---

만약 순서를 무시하면?

```
고급 알고리즘
↓
알고리즘
↓
자료구조
```

이상한 순서가 된다.

---

위상 정렬은 이런 문제를 해결한다.

> "선행 조건을 모두 만족하는 순서를 구하라"
> 

---

### 현실 예시

### 건물 건설

```
기초 공사
   ↓
골조 공사
   ↓
내부 공사
   ↓
완공
```

---

### 게임 퀘스트

```
초보자 퀘스트
    ↓
중급 퀘스트
    ↓
고급 퀘스트
```

---

### 프로그램 빌드

```
A 라이브러리
    ↓
B 프로그램
    ↓
최종 실행파일
```

---

### 코딩 테스트에서 자주 나오는 문제

다음 문장이 보이면 위상 정렬을 의심해보자.

- 먼저 해야 하는 작업
- 선수 과목
- 선행 조건
- 의존 관계
- 순서를 정하라
- 가능한 작업 순서

---

## 3. 핵심 아이디어

위상 정렬의 핵심은 매우 단순하다.

> "지금 당장 할 수 있는 작업부터 처리한다"
> 

---

### 비유

회사 업무가 있다고 하자.

```
기획서 작성
   ↓
개발
   ↓
테스트
   ↓
배포
```

배포를 먼저 할 수는 없다.

개발도 기획서가 있어야 가능하다.

---

따라서

현재 조건이 모두 만족된 작업부터 꺼내서 처리한다.

```
기획서 작성
↓
개발
↓
테스트
↓
배포
```

---

### 중요한 특징

위상 정렬은

```
방향 그래프
```

에서만 사용한다.

---

예를 들어

```
A → B
```

는

```
A를 먼저 해야 함
```

을 의미한다.

---

또 하나 중요한 조건이 있다.

```
사이클(Cycle)이 없어야 한다.
```

---

예를 들어

```
A → B
↑   ↓
└── C
```

이면

```
A 먼저
B 먼저
C 먼저
```

가 서로 충돌한다.

즉 순서를 정할 수 없다.

---

## 4. 알고리즘 동작 과정 (Step-by-Step 시각화)

다음 그래프를 보자.

```
A
│ \
│  \
↓   ↓
B   C
 \ /
  ↓
  D
```

간선

```
A → B
A → C
B → D
C → D
```

---

### Step 1. 진입 차수(In-Degree) 계산

진입 차수란

```
나를 가리키는 화살표 개수
```

이다.

---

계산 결과

```
A : 0
B : 1
C : 1
D : 2
```

시각화

```
A(0)

↓      ↓

B(1)  C(1)

  \    /
   \  /

   D(2)
```

---

### Step 2. 진입 차수가 0인 정점 찾기

현재

```
A : 0
```

뿐이다.

따라서 A부터 시작한다.

---

큐 상태

```
Queue

[A]
```

---

### Step 3. A 꺼내기

```
Queue

[A]

↓

[]
```

결과

```
정렬 결과

A
```

---

A가 제거되면

```
A → B
A → C
```

간선도 함께 제거된다.

---

진입 차수 변화

```
B : 1 → 0
C : 1 → 0
D : 2
```

---

큐

```
[B][C]
```

---

### Step 4. B 꺼내기

```
Queue

[B][C]

↓

[C]
```

결과

```
A B
```

---

간선 제거

```
B → D
```

---

진입 차수 변화

```
D : 2 → 1
```

---

현재

```
C : 0
D : 1
```

---

큐

```
[C]
```

---

### Step 5. C 꺼내기

결과

```
A B C
```

---

간선 제거

```
C → D
```

---

진입 차수 변화

```
D : 1 → 0
```

---

큐

```
[D]
```

---

### Step 6. D 꺼내기

결과

```
A B C D
```

---

큐가 비었다.

```
[A, B, C, D]
```

위상 정렬 완료.

---

## 5. 파이썬(Python) 구현 코드

```
fromcollectionsimportdeque

# 정점 개수
n=4

# 그래프
graph= [
    [],
    [2,3],# 1 -> 2, 3
    [4],# 2 -> 4
    [4],# 3 -> 4
    []
]

# 진입 차수
indegree= [0]* (n+1)

# 진입 차수 계산
fornodeinrange(1,n+1):
fornext_nodeingraph[node]:
indegree[next_node]+=1

queue=deque()

# 진입 차수가 0인 정점 삽입
fornodeinrange(1,n+1):
ifindegree[node]==0:
queue.append(node)

result= []

whilequeue:
current=queue.popleft()

result.append(current)

# 현재 정점과 연결된 간선 제거
fornext_nodeingraph[current]:

indegree[next_node]-=1

# 새롭게 진입 차수가 0이 되면 큐에 삽입
ifindegree[next_node]==0:
queue.append(next_node)

print(result)
```

---

### 핵심 코드 설명

```
indegree[next_node]+=1
```

각 정점으로 들어오는 화살표 개수를 센다.

---

예시

```
1 → 2
3 → 2
```

이면

```
indegree[2] = 2
```

이다.

---

```
ifindegree[node]==0:
queue.append(node)
```

현재 당장 수행 가능한 작업을 큐에 넣는다.

---

```
current=queue.popleft()
```

가장 먼저 수행할 작업을 꺼낸다.

---

```
indegree[next_node]-=1
```

현재 작업이 끝났으므로

관련된 선행 조건 하나를 제거한다.

---

## 6. 핵심 요약 및 주의점

### 위상 정렬이 필요한 상황

```
A를 먼저 해야
B를 할 수 있다.
```

같은

```
선행 조건
```

이 존재할 때 사용한다.

---

### 핵심 아이디어

```
진입 차수 0

↓

지금 당장 가능

↓

처리

↓

새로운 진입 차수 0 발견

↓

반복
```

---

### 진입 차수란?

```
들어오는 화살표 개수
```

이다.

예시

```
A → D
B → D
C → D
```

이면

```
D의 진입 차수 = 3
```

이다.

---

### 사이클이 있으면?

```
A → B
↑   ↓
└── C
```

---

누가 먼저인지 결정할 수 없다.

따라서

```
위상 정렬 불가능
```

이다.

---

### 시간 복잡도

```
O(V + E)
```

- V = 정점 개수
- E = 간선 개수

그래프를 한 번씩만 확인하므로 매우 효율적이다.

---

### 자주 하는 실수

### 1. 방향 그래프가 아닌데 사용

위상 정렬은

```
방향 그래프
```

전용 알고리즘이다.

---

### 2. 진입 차수 계산 실수

```
indegree[next_node]+=1
```

방향을 반대로 계산하는 경우가 많다.

---

### 3. 사이클 여부 확인 안 하기

정상적인 위상 정렬이라면

```
정렬 결과 개수
=
전체 정점 개수
```

여야 한다.

만약

```
정렬 결과 개수 < 전체 정점 개수
```

라면 사이클이 존재한다.

---

### 꼭 기억할 것

```
위상 정렬

=
선행 조건이 있는 작업의 순서 정하기
```

```
1. 진입 차수 계산

2. 진입 차수 0을 큐에 넣기

3. 하나 꺼내기

4. 연결된 간선 제거

5. 새롭게 0이 된 정점 넣기

6. 반복
```

한 문장으로 기억하면,

> **"지금 당장 할 수 있는 일부터 처리하는 알고리즘"** 이 바로 위상 정렬이다.
>
