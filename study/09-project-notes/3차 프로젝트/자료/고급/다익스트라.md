# 본문

## 1. 한 줄 요약

다익스트라 알고리즘은 **음수 간선이 없는 가중치 그래프**에서, 하나의 시작 정점으로부터 다른 모든 정점까지의 **최단 거리**를 구하는 알고리즘이다.

쉽게 말하면, 여러 갈래 길 중에서 현재까지 가장 가까운 지점을 먼저 확정하면서 목적지까지의 최소 비용을 계산하는 방식이다.

---

## 2. 언제 사용하면 좋은가

다익스트라는 다음 조건에서 사용하기 좋다.

| 사용 조건 | 설명 |
|---|---|
| 간선마다 비용이 있음 | 단순히 몇 번 이동하는지가 아니라 이동 비용, 시간, 거리 등이 다름 |
| 시작점이 하나임 | 한 정점에서 다른 모든 정점까지의 최단 거리를 구함 |
| 모든 간선 가중치가 0 이상임 | 음수 간선이 있으면 다익스트라를 사용하면 안 됨 |
| 가장 가까운 정점을 먼저 확정할 수 있음 | 우선순위 큐를 사용하면 효율적으로 구현 가능 |

대표적인 문제 표현은 다음과 같다.

- A 지점에서 모든 지점까지의 최단 거리
- 시작 도시에서 각 도시까지 가는 최소 비용
- 특정 위치까지 이동하는 최소 시간
- 도로망, 네트워크, 배달, 경로 탐색 문제
- 가중치가 있는 그래프에서 최단 경로 찾기

---

## 3. 핵심 아이디어

다익스트라의 핵심은 다음 문장으로 정리할 수 있다.

> 현재까지 가장 비용이 작은 정점부터 확정한다.

처음에는 시작 정점의 거리를 0으로 둔다.

그리고 현재까지 갈 수 있는 정점 중 가장 가까운 정점을 선택한다.

그 정점을 거쳐서 다른 정점으로 가는 비용이 더 짧아지면 거리 값을 갱신한다.

이 과정을 반복하면 시작 정점으로부터 모든 정점까지의 최단 거리를 구할 수 있다.

---

## 4. 왜 우선순위 큐를 사용하는가

다익스트라는 매번 현재까지 발견된 정점 중에서 **가장 거리가 짧은 정점**을 골라야 한다.

일반 리스트를 사용하면 매번 최솟값을 찾기 위해 전체를 확인해야 하므로 비효율적이다.

우선순위 큐를 사용하면 가장 짧은 거리의 정점을 빠르게 꺼낼 수 있다.

```text
일반 리스트 사용:
매번 전체 탐색 → O(V^2)

우선순위 큐 사용:
가장 짧은 거리 꺼내기 → O(log V)
전체 시간복잡도 → O((V + E) log V)
```

따라서 코딩테스트에서는 대부분 **heapq / PriorityQueue**를 이용한 다익스트라 구현을 사용한다.

## 5. 알고리즘 동작 과정

예시 그래프를 보자.

```text
A --2-- B
|       |
5       1
|       |
C --2-- D
```

간선 정보:

```text
A -> B : 2
A -> C : 5
B -> D : 1
C -> D : 2
```

시작 정점은 A라고 하자.

---

### Step 1. 거리 배열 초기화

```text
A: 0
B: INF
C: INF
D: INF
```

시작 정점 A의 거리는 0이다.

나머지는 아직 도달 방법을 모르므로 무한대(INF)로 둔다.

---

### Step 2. A에서 갈 수 있는 정점 갱신

A에서 B까지 비용은 2이다.

A에서 C까지 비용은 5이다.

```text
A: 0
B: 2
C: 5
D: INF
```

우선순위 큐에는 다음 값이 들어간다.

```text
(2, B), (5, C)
```

---

### Step 3. 가장 가까운 B 선택

현재 가장 가까운 정점은 B이다.

B를 거쳐 D로 가면 비용은 다음과 같다.

```text
A -> B -> D = 2 + 1 = 3
```

기존 D의 값은 INF였으므로 3으로 갱신한다.

```text
A: 0
B: 2
C: 5
D: 3
```

---

### Step 4. 가장 가까운 D 선택

현재 큐에서 가장 가까운 정점은 D이다.

D에서 더 갱신할 수 있는 정점이 없다면 넘어간다.

---

### Step 5. C 선택

마지막으로 C를 확인한다.

C를 통해 D로 가는 비용은 다음과 같다.

```text
A -> C -> D = 5 + 2 = 7
```

이미 D의 최단 거리는 3이므로 갱신하지 않는다.

최종 결과:

```text
A: 0
B: 2
C: 5
D: 3
```

---

## 6. 구현 코드

### Python 구현

```python
import heapq
import sys

INF = int(1e18)

def dijkstra(start, graph, n):
    distance = [INF] * (n + 1)
    distance[start] = 0

    pq = []
    heapq.heappush(pq, (0, start))

    while pq:
        current_dist, current_node = heapq.heappop(pq)

        # 이미 더 짧은 거리로 처리된 적이 있으면 무시
        if distance[current_node] < current_dist:
            continue

        for next_node, cost in graph[current_node]:
            new_dist = current_dist + cost

            if new_dist < distance[next_node]:
                distance[next_node] = new_dist
                heapq.heappush(pq, (new_dist, next_node))

    return distance
```

---

## 7. 코드 설명

### 1) 거리 배열 초기화

```python
distance = [INF] * (n + 1)
distance[start] = 0
```

모든 정점까지의 거리를 무한대로 초기화한다.

시작 정점은 자기 자신까지의 거리가 0이므로 0으로 설정한다.

---

### 2) 우선순위 큐 초기화

```python
pq = []
heapq.heappush(pq, (0, start))
```

우선순위 큐에는 `(현재까지 거리, 정점)` 형태로 넣는다.

Python의 `heapq`는 첫 번째 원소를 기준으로 최소 힙을 구성하므로, 거리가 가장 짧은 정점이 먼저 나온다.

---

### 3) 이미 처리된 오래된 거리 무시

```python
if distance[current_node] < current_dist:
    continue
```

다익스트라에서는 같은 정점이 우선순위 큐에 여러 번 들어갈 수 있다.

이미 더 짧은 거리로 갱신된 적이 있다면, 오래된 정보는 무시한다.

이 조건이 없으면 불필요한 탐색이 많아진다.

---

### 4) 거리 갱신

```python
for next_node, cost in graph[current_node]:
    new_dist = current_dist + cost

    if new_dist < distance[next_node]:
        distance[next_node] = new_dist
        heapq.heappush(pq, (new_dist, next_node))
```

현재 정점을 거쳐 다음 정점으로 가는 비용이 기존 거리보다 작으면 갱신한다.

이 과정을 **완화(relaxation)**라고 한다.

---

## 8. 입력 예시

```python
n = 4
graph = [[] for _ in range(n + 1)]

edges = [
    (1, 2, 2),
    (1, 3, 5),
    (2, 4, 1),
    (3, 4, 2),
]

for a, b, cost in edges:
    graph[a].append((b, cost))
    graph[b].append((a, cost))  # 무방향 그래프일 경우

result = dijkstra(1, graph, n)

for i in range(1, n + 1):
    print(i, result[i])
```

출력:

```text
1 0
2 2
3 5
4 3
```

## 9. 시간복잡도와 공간복잡도

### 시간복잡도

우선순위 큐를 사용하는 다익스트라의 시간복잡도는 다음과 같다.

```text
O((V + E) log V)
```

여기서:

- V: 정점 수
- E: 간선 수

각 간선을 확인하면서 거리가 갱신될 수 있고, 우선순위 큐에 넣고 빼는 연산이 `log V`가 걸린다.

그래서 일반적으로 다음처럼 설명한다.

```text
O(E log V)
```

간선이 많은 그래프에서는 `E`가 더 지배적이기 때문이다.

---

### 공간복잡도

```text
O(V + E)
```

- 그래프 저장: O(V + E)
- 거리 배열: O(V)
- 우선순위 큐: 최대 O(E)

---

## 10. 사용하면 안 되는 경우

다익스트라는 강력하지만 항상 사용할 수 있는 것은 아니다.

### 1) 음수 간선이 있는 경우

```text
A -> B : 2
A -> C : 5
C -> B : -10
```

이런 경우에는 나중에 더 짧은 경로가 발견될 수 있다.

다익스트라는 한 번 가장 짧다고 판단한 정점을 확정하는 방식이므로, 음수 간선이 있으면 잘못된 결과가 나올 수 있다.

음수 간선이 있으면 **벨만포드 알고리즘**을 사용한다.

---

### 2) 모든 정점 쌍의 최단 거리가 필요한 경우

시작 정점이 하나가 아니라 모든 정점에서 모든 정점까지의 최단 거리가 필요하면 **플로이드 워셜 알고리즘**을 고려한다.

---

### 3) 간선 가중치가 모두 1인 경우

간선 비용이 전부 1이면 다익스트라보다 BFS가 더 간단하고 빠르다.

```text
모든 간선 비용 = 1
```

이면 BFS를 사용한다.

---

## 11. BFS, 벨만포드, 플로이드 워셜과 비교

| 알고리즘 | 사용 상황 | 시간복잡도 | 특징 |
|---|---|---|---|
| BFS | 모든 간선 가중치가 1 | O(V + E) | 가장 간단한 최단 거리 |
| 다익스트라 | 음수 없는 가중치 그래프 | O((V + E) log V) | 한 시작점 기준 최단 거리 |
| 벨만포드 | 음수 간선 가능 | O(VE) | 음수 사이클 감지 가능 |
| 플로이드 워셜 | 모든 정점 쌍 최단 거리 | O(V^3) | 구현은 간단하지만 느림 |

---

## 12. 자주 나오는 실수

### 실수 1. 음수 간선이 있는데 다익스트라 사용

다익스트라는 음수 간선이 있으면 안 된다.

음수 간선이 있으면 벨만포드를 고려한다.

---

### 실수 2. 우선순위 큐에서 꺼낸 값 검증 안 함

```python
if distance[current_node] < current_dist:
    continue
```

이 조건을 넣지 않으면 이미 오래된 거리 정보까지 처리해서 시간이 낭비된다.

---

### 실수 3. 무방향 그래프인데 한쪽 간선만 추가

무방향 그래프라면 양방향으로 넣어야 한다.

```python
graph[a].append((b, cost))
graph[b].append((a, cost))
```

방향 그래프라면 한쪽만 넣는다.

---

### 실수 4. INF 값을 너무 작게 설정

최단 거리의 최대값보다 INF가 작으면 오답이 발생한다.

```python
INF = int(1e18)
```

처럼 충분히 큰 값을 사용한다.

## 14. Text Flow Chart

```text
시작 정점 입력
    ↓
거리 배열 INF 초기화
    ↓
시작 정점 거리 = 0
    ↓
우선순위 큐에 (0, 시작 정점) 삽입
    ↓
큐가 빌 때까지 반복
    ↓
가장 거리가 짧은 정점 꺼내기
    ↓
이미 더 짧은 거리로 처리된 정점인가?
    ├─ YES → 무시
    └─ NO
        ↓
      인접 정점 확인
        ↓
      현재 정점을 거쳐 가는 비용이 더 짧은가?
        ├─ YES → 거리 갱신 후 큐에 삽입
        └─ NO → 넘어감
    ↓
최종 거리 배열 반환
```

## 15. 실전 예시 문제 유형

### 유형 1. 특정 시작점에서 모든 정점까지 최단 거리

대표 문제:

```text
시작점 K에서 모든 정점까지의 최단 거리를 출력하라.
```

풀이:

```text
다익스트라 기본형
```

---

### 유형 2. 특정 목적지까지 최소 비용

대표 문제:

```text
A에서 B까지 이동하는 최소 비용을 구하라.
```

풀이:

```text
다익스트라를 수행한 뒤 distance[B] 출력
```

---

### 유형 3. 여러 경유지를 포함한 최단 거리

대표 문제:

```text
1번에서 N번까지 이동하되 특정 정점을 반드시 지나야 한다.
```

풀이:

```text
다익스트라를 여러 번 수행한다.
```

예:

```text
1 -> v1 -> v2 -> N
1 -> v2 -> v1 -> N
```

두 경우 중 더 작은 값을 선택한다.

---

### 유형 4. 도달 불가능한 정점 처리

대표 문제:

```text
도달할 수 없는 정점은 INF를 출력하라.
```

풀이:

```python
if distance[i] == INF:
    print("INF")
else:
    print(distance[i])
```

## 16. 최종 정리

다익스트라는 다음 조건을 만족할 때 사용한다.

```text
가중치 그래프
시작점 하나
음수 간선 없음
최단 거리 / 최소 비용
```

핵심 구현 요소는 다음과 같다.

```text
거리 배열
우선순위 큐
오래된 거리 무시
간선 완화
```

다익스트라는 코딩테스트에서 최단 거리 문제의 기본이 되는 알고리즘이며, 우선순위 큐와 함께 자주 등장한다.
