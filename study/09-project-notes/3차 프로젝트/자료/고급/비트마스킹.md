## 1. 한 줄 요약

- 비트마스킹은 **0과 1로 이루어진 비트(Bit)를 이용하여 여러 상태를 매우 효율적으로 저장하고 관리하는 기법**이다.

---

## 2. 주요 활용처 및 문제 유형

여러 개의 스위치를 관리한다고 생각해보자.

```
전등 1 : ON
전등 2 : OFF
전등 3 : ON
전등 4 : ON
```

보통은 이렇게 저장할 수 있다.

```
[True,False,True,True]
```

---

그런데 컴퓨터는 사실

```
ON  = 1
OFF = 0
```

으로 생각한다.

따라서

```
1 0 1 1
```

처럼 저장할 수 있다.

---

이것을 하나의 숫자로 표현하면

```
1011
```

이 된다.

즉,

> 여러 개의 ON/OFF 상태를 하나의 정수로 관리하는 방법
> 

이 비트마스킹이다.

---

### 코딩 테스트에서 자주 나오는 문제

다음 키워드가 보이면 비트마스킹을 떠올려보자.

- 집합(Set)
- 부분집합
- 방문 여부
- 선택/미선택
- 모든 경우의 수
- N ≤ 20 정도

특히

```
각 원소를 선택하거나 선택하지 않는다
```

라는 느낌이 나면 비트마스킹 가능성이 높다.

---

## 3. 핵심 아이디어

### 비유

방에 스위치 4개가 있다고 생각해보자.

```
1번 스위치
2번 스위치
3번 스위치
4번 스위치
```

---

각 스위치는

```
켜짐
꺼짐
```

두 상태만 가진다.

---

따라서

```
1 = 켜짐
0 = 꺼짐
```

으로 표현 가능하다.

---

예를 들어

```
1번 ON
2번 OFF
3번 ON
4번 ON
```

이면

```
1 0 1 1
```

이다.

---

이 숫자 하나가

```
4개의 상태
```

를 모두 저장하고 있다.

---

### 왜 사용할까?

만약 원소가 20개라면

```
선택
미선택
```

상태가 존재한다.

---

경우의 수는

```
2 × 2 × 2 × ...
```

이다.

즉

```
2^20
```

가지 상태가 존재한다.

---

비트마스킹은 이런 상태를

```
정수 하나
```

로 표현할 수 있다.

---

## 4. 알고리즘 동작 과정 (Step-by-Step 시각화)

원소가 4개 있다고 하자.

```
0
1
2
3
```

---

### Step 1. 비트 위치 정하기

```
비트 위치

3 2 1 0
```

---

예를 들어

```
1010
```

이라면

```
3번 비트 = 1
2번 비트 = 0
1번 비트 = 1
0번 비트 = 0
```

이다.

---

### Step 2. 집합 표현하기

집합

```
{1, 3}
```

을 저장해보자.

---

원소 존재 여부

```
0 : 없음
1 : 있음
2 : 없음
3 : 있음
```

---

비트 표현

```
1 0 1 0
```

즉

```
1010(2)
```

이다.

---

십진수로는

```
10
```

이다.

---

### Step 3. 상태 확인하기

현재

```
1010
```

이다.

---

질문

```
원소 1 존재?
```

---

1번 비트 확인

```
1010

 ↑
```

값

```
1
```

---

결과

```
존재
```

---

### Step 4. 원소 추가하기

현재

```
1010
```

---

원소 2 추가

```
1010

↓

1110
```

---

집합

```
{1,2,3}
```

이 된다.

---

### Step 5. 원소 제거하기

현재

```
1110
```

---

원소 3 제거

```
1110

↓

0110
```

---

집합

```
{1,2}
```

이 된다.

## 5. 파이썬(Python) 구현 코드

### 원소 추가

```
mask=0

# 2번 원소 추가
mask|= (1<<2)

print(mask)
```

---

설명

```
1<<2
```

결과

```
0100
```

---

```
mask|=0100
```

이 되어

2번 원소가 추가된다.

---

### 원소 제거

```
mask&=~(1<<2)
```

---

설명

```
현재

0100
```

---

```
~(1<<2)
```

는

```
...1011
```

이므로

2번 비트만 제거된다.

---

### 원소 존재 확인

```
ifmask& (1<<2):
print("존재")
```

---

설명

```
mask

0100

AND

0100

=

0100
```

0이 아니므로 존재한다.

---

### 원소 토글(반전)

```
mask^= (1<<2)
```

---

설명

```
0 → 1

또는

1 → 0
```

으로 바뀐다.

---

### 전체 코드

```
mask=0

# 추가
mask|= (1<<1)

# 추가
mask|= (1<<3)

print(bin(mask))

# 존재 확인
ifmask& (1<<1):
print("1 존재")

# 제거
mask&=~(1<<1)

print(bin(mask))
```

## 6. 핵심 요약 및 주의점

### 비트 연산 기호

| --- | --- |

| `>>` | 오른쪽 시프트 |

```

```

### 시간 복잡도

원소 개수를 N이라 하면

```
상태 저장

O(1)
```

---

부분집합 전체 탐색

```
O(2^N)
```

---

그래서 보통

```
N ≤ 20
```

정도에서 많이 사용한다.
