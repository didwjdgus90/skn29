## 1. 한 줄 요약

- 크루스칼 알고리즘은 **모든 정점을 가장 적은 비용으로 연결하는 최소 신장 트리(MST)를 구하는 알고리즘**이다.

---

## 2. 주요 활용처 및 문제 유형

어느 통신 회사가 전국에 인터넷 케이블을 설치하려고 한다고 생각해보자.

도시들은 다음과 같이 연결할 수 있다.

```
서울 ── 3 ── 대전

서울 ── 5 ── 부산

대전 ── 2 ── 부산
```

숫자는 설치 비용이다.

---

회사의 목표는 간단하다.

```
모든 도시는 연결해야 함

+

설치 비용은 최소
```

---

예를 들어

```
서울 ── 5 ── 부산
```

보다

```
서울 ── 3 ── 대전 ── 2 ── 부산
```

이 비용이 같다.

하지만 그래프가 커지면 어떤 연결이 가장 저렴한지 직접 찾기 어렵다.

---

이때 사용하는 것이

```
최소 신장 트리(MST)
```

이고,

이를 구하는 대표 알고리즘이

```
크루스칼
```

이다.

---

### 코딩 테스트에서 자주 나오는 문제

다음 문장이 보이면 MST를 의심해보자.

- 모든 정점을 연결하라
- 최소 비용으로 연결
- 전력망 설치
- 도로 건설
- 네트워크 구축
- 마을 연결
- 통신망 연결

특히

> "모든 노드를 연결하면서 비용 최소"
> 

라는 문장이 나오면 크루스칼 가능성이 높다.

---

## 3. 핵심 아이디어

### 비유

섬 여러 개를 다리로 연결한다고 생각해보자.

```
A
B
C
D
```

각 섬 사이에 다리 건설 비용이 있다.

---

당연히 비싼 다리부터 만들 필요는 없다.

먼저

```
가장 싼 다리
```

부터 설치하면 된다.

---

예를 들어

```
A-B : 1
B-C : 2
A-C : 10
```

이라면

```
A-C : 10
```

을 먼저 선택할 이유가 없다.

---

크루스칼의 생각은 매우 단순하다.

> "가장 싼 간선부터 선택하자"
> 

---

하지만 주의할 점이 있다.

```
사이클(Cycle)
```

은 만들면 안 된다.

---

예를 들어

```
A ─ B
│   │
└── C
```

이미 연결된 곳에 또 연결하면

비용만 증가하고 얻는 것이 없다.

---

그래서

```
가장 싼 간선 선택

↓

사이클이면 버림

↓

아니면 채택
```

을 반복한다.

---

## 4. 알고리즘 동작 과정 (Step-by-Step 시각화)

다음 그래프를 보자.

```
     4

A ------- B

| \       |

|  \      |

2   5     1

|    \    |

|     \   |

C ------- D

     3
```

---

간선 목록

```
A-B : 4
A-C : 2
A-D : 5
B-D : 1
C-D : 3
```

---

### Step 1. 간선을 비용순 정렬

오름차순 정렬

```
B-D : 1

A-C : 2

C-D : 3

A-B : 4

A-D : 5
```

---

### Step 2. 가장 싼 간선 선택

선택

```
B-D : 1
```

현재 상태

```
B ─ D
```

비용

```
1
```

---

### Step 3. 다음 간선 선택

선택

```
A-C : 2
```

현재 상태

```
A ─ C

B ─ D
```

비용

```
1 + 2 = 3
```

---

### Step 4. 다음 간선 선택

선택

```
C-D : 3
```

현재 상태

```
A ─ C ─ D ─ B
```

비용

```
1 + 2 + 3 = 6
```

---

모든 정점이 연결되었다.

---

### Step 5. 다음 간선 확인

후보

```
A-B : 4
```

---

추가하면

```
A ─ C
|   |
|   |
B ─ D
```

사이클 발생

---

따라서

```
버림
```

---

### 최종 결과

선택된 간선

```
B-D : 1

A-C : 2

C-D : 3
```

---

최소 비용

```
6
```

---

## 5. 파이썬(Python) 구현 코드

```
# 유니온 파인드용 부모 배열
parent= [0,1,2,3,4]

deffind(x):
ifparent[x]!=x:
parent[x]=find(parent[x])

returnparent[x]

defunion(a,b):
root_a=find(a)
root_b=find(b)

ifroot_a!=root_b:
parent[root_b]=root_a

# (비용, 정점1, 정점2)
edges= [
    (4,1,2),
    (2,1,3),
    (5,1,4),
    (1,2,4),
    (3,3,4)
]

# 비용 기준 정렬
edges.sort()

mst_cost=0

forcost,a,binedges:

# 사이클이 아니면 채택
iffind(a)!=find(b):

union(a,b)

mst_cost+=cost

print(mst_cost)
```

출력

```
6
```

---

### 핵심 코드 설명

---

```
edges.sort()
```

간선을 비용 기준으로 정렬한다.

---

정렬 후

```
1

↓

2

↓

3

↓

4

↓

5
```

순서대로 검사한다.

---

```
find(a)!=find(b)
```

현재 서로 다른 그룹인지 확인한다.

---

예시

```
A ─ C

B ─ D
```

이면

```
A 그룹

B 그룹
```

이 다르다.

---

```
union(a,b)
```

간선을 채택하면서

두 그룹을 합친다.

---

### 왜 유니온 파인드를 사용할까?

현재

```
A ─ C ─ D
```

라고 하자.

---

여기에

```
A ─ D
```

를 추가하면

```
A → C → D → A
```

가 된다.

즉

```
사이클 발생
```

이다.

---

유니온 파인드는

```
이미 같은 그룹인가?
```

를 매우 빠르게 확인할 수 있다.

## 6. 핵심 요약 및 주의점

### 최소 신장 트리(MST)란?

```
모든 정점 연결

+

사이클 없음

+

비용 최소
```

인 트리이다.

---

### 크루스칼의 핵심 아이디어

```
가장 싼 간선부터 선택
```

---

알고리즘 흐름

```
1. 간선 정렬

2. 가장 싼 간선 선택

3. 사이클 검사

4. 가능하면 채택

5. 반복
```

---

### 시각화

```
가장 싼 간선

↓

선택

↓

사이클?

↓

YES → 버림

NO  → 채택
```

---

### 시간 복잡도

간선 정렬이 대부분의 시간을 차지한다.

```
O(E log E)
```

- E = 간선 개수

---

### 공간 복잡도

```
O(V)
```

- 유니온 파인드 부모 배열 저장

---

### 자주 하는 실수

### 1. 간선 정렬 안 함

```
edges.sort()
```

반드시 필요하다.

---

### 2. 사이클 검사 안 함

```
find(a)!=find(b)
```

확인 없이 추가하면 MST가 아니다.

---

### 3. MST와 최단 경로 혼동

크루스칼은

```
모든 정점을 연결하는 최소 비용
```

을 구한다.

---

하지만

```
A → B 최단 거리
```

를 구하는 알고리즘은 아니다.

---

## 프림(Prim) 알고리즘과 차이점

MST를 구하는 대표 알고리즘은 두 가지다.

```
크루스칼

프림
```

---

### 크루스칼

```
간선 중심
```

으로 생각한다.

```
가장 싼 간선부터 선택
```

---

### 프림

```
정점 중심
```

으로 생각한다.

```
현재 트리에서
가장 가까운 정점 추가
```

---

### 비교

| 항목 | 크루스칼 | 프림 |
| --- | --- | --- |
| 관점 | 간선 중심 | 정점 중심 |
| 핵심 자료구조 | 유니온 파인드 | 우선순위 큐 |
| 시작 정점 | 필요 없음 | 필요 |
| 핵심 전략 | 간선 정렬 후 선택 | 가까운 정점 확장 |

---

### 꼭 기억할 것

```

↓

↓

반복
```

한 문장으로 기억하면,

> **크루스칼은 "가장 싼 연결선부터 고르되, 원을 만들지 않으면서 모든 정점을 연결하는 알고리즘"이다.**
