## 문제 설명

매운 것을 좋아하는 Leo는 모든 음식의 스코빌 지수를 K 이상으로 만들고 싶습니다.
스코빌 지수가 가장 낮은 두 음식을 아래 공식으로 섞어 새로운 음식을 만듭니다.

```
섞은 음식의 스코빌 지수 = 가장 맵지 않은 음식 + (두 번째로 맵지 않은 음식 × 2)
```

모든 음식의 스코빌 지수가 K 이상이 될 때까지 반복합니다.
섞어야 하는 **최소 횟수**를 return하세요. 불가능하면 -1을 return합니다.

입출력 예시:

| scoville | K | return |
|---|---|---|
| [1, 2, 3, 9, 10, 12] | 7 | 2 |

풀이:
1. 1 + (2 × 2) = 5 → [5, 3, 9, 10, 12]
2. 3 + (5 × 2) = 13 → [13, 9, 10, 12]  ← 모두 7 이상, 종료

---

## 핵심 개념: 왜 힙(Heap)인가?

매번 "가장 작은 값 두 개"를 꺼내야 하는 문제입니다.

리스트에서 `min()`을 쓰면 매번 O(N)이 걸립니다.
반면 **Min Heap**을 쓰면 최솟값을 항상 O(log N)에 꺼낼 수 있습니다.

> 📦 힙은 "가장 작은(또는 큰) 값이 항상 맨 위에 있는 자료구조"입니다.
> 마치 우선순위가 높은 사람이 항상 줄 맨 앞에 있는 것처럼요.

### Python heapq 핵심 메서드

| 메서드 | 설명 | 시간복잡도 |
|---|---|---|
| `heapq.heapify(list)` | 리스트를 힙으로 변환 | O(N) |
| `heapq.heappush(heap, val)` | 값 삽입 | O(log N) |
| `heapq.heappop(heap)` | 최솟값 꺼내기 | O(log N) |
| `heap[0]` | 최솟값 확인 (꺼내지 않음) | O(1) |

Python의 `heapq`는 기본적으로 **Min Heap**입니다.

---

## 풀이 흐름

```
1. scoville 리스트를 Min Heap으로 변환
2. 힙의 최솟값(heap[0])이 K보다 작은 동안 반복:
   a. 가장 작은 값(first) pop
   b. 두 번째로 작은 값(second) pop
   c. first + second * 2 를 다시 push
   d. 횟수 +1
3. 힙에 원소가 1개만 남았는데도 K 미만이면 → -1 반환
```

---

## 코드

```python
import heapq

def solution(scoville, K):
    heapq.heapify(scoville)  # 리스트를 Min Heap으로 변환 O(N)
    cnt = 0

    while scoville[0] < K:       # 최솟값이 K보다 작으면 계속 섞기
        if len(scoville) < 2:    # 섞을 음식이 1개뿐이면 불가능
            return -1

        first = heapq.heappop(scoville)           # 가장 맵지 않은 음식
        second = heapq.heappop(scoville)          # 두 번째로 맵지 않은 음식
        heapq.heappush(scoville, first + second * 2)  # 섞어서 다시 삽입
        cnt += 1

    return cnt
```

### 코드 흐름 추적 (예제 기준)

```
초기 힙: [1, 2, 3, 9, 10, 12]  (heapify 후 Min Heap)

[1회차] heap[0]=1 < 7
  first=1, second=2
  push(1 + 2*2) = push(5)
  힙: [3, 5, 9, 10, 12]  cnt=1

[2회차] heap[0]=3 < 7
  first=3, second=5
  push(3 + 5*2) = push(13)
  힙: [9, 10, 12, 13]  cnt=2

[3회차] heap[0]=9 >= 7 → 종료
return 2  ✅
```

## 시간복잡도

| 연산 | 복잡도 |
|---|---|
| heapify | O(N) |
| 루프 1회 (pop 2번 + push 1번) | O(log N) |
| 전체 (최악의 경우 N번 반복) | O(N log N) |

단순 정렬 후 매번 min을 구하는 방식 O(N²) 대비 훨씬 효율적입니다.
