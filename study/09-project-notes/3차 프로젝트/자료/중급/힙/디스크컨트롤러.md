# 본문

## 문제 설명

하드디스크는 한 번에 하나의 작업만 수행할 수 있습니다.
각 작업은 `[요청 시점, 소요 시간]`으로 주어집니다.
모든 작업의 **요청부터 종료까지 걸린 시간의 평균을 최소화**하는 처리 순서를 찾으세요.

입출력 예시:

| jobs | return |
|---|---|
| [[0,3], [1,9], [2,6]] | 9 |

---

## 핵심 개념: SJF(Shortest Job First)

> "지금 처리할 수 있는 작업 중에서, 소요 시간이 가장 짧은 것부터 처리한다."

왜 짧은 것부터 해야 할까요?

긴 작업 하나를 먼저 하면, 그 뒤에 대기하는 모든 작업의 대기 시간이 같이 늘어납니다.
짧은 작업부터 처리하면, 여러 작업이 빨리 끝나서 **전체 평균 대기 시간이 줄어듭니다**.

> 📦 식당 비유: 손님이 몰릴 때 주문이 간단한 사람부터 처리하면
> 전체 손님의 평균 대기 시간이 줄어드는 것과 같습니다.

---

## 풀이 흐름

```
1. jobs를 요청 시점 기준으로 정렬
2. 현재 시간(time)이 지나면서 처리 가능한 작업을 Min Heap에 추가 (소요 시간 기준)
3. 힙에서 소요 시간이 가장 짧은 작업을 꺼내 처리
4. 큐가 비어있으면 다음 작업 시점으로 time을 점프
5. 모든 작업 완료 후 총 대기시간 / 작업 수 반환
```

핵심 포인트: **현재 시점까지 요청된 작업만 힙에 넣는다**

---

## 코드

```python
import heapq

def solution(jobs):
    jobs.sort()          # 요청 시점 기준 정렬
    heap = []            # (소요시간, 요청시점) - Min Heap
    time = 0             # 현재 시각
    total_wait = 0       # 누적 대기시간
    j = 0                # jobs 인덱스

    while j < len(jobs) or heap:

        # 현재 시각까지 요청된 작업을 모두 힙에 추가
        while j < len(jobs) and jobs[j][0] <= time:
            heapq.heappush(heap, (jobs[j][1], jobs[j][0]))  # (소요시간, 요청시점)
            j += 1

        if heap:
            duration, request = heapq.heappop(heap)  # 소요시간 가장 짧은 작업
            time += duration                          # 작업 완료 시각
            total_wait += time - request              # 대기시간 = 완료시각 - 요청시각
        else:
            # 처리할 작업이 없으면 다음 요청 시점으로 점프
            time = jobs[j][0]

    return total_wait // len(jobs)
```

### 코드 흐름 추적 (예제 기준)

```
jobs 정렬: [[0,3], [1,9], [2,6]]

[초기] time=0, heap=[]

time=0: jobs[0]=[0,3] 요청시점 0 <= 0 → heap에 push
  heap: [(3,0)]
  작업 처리: duration=3, request=0
  time = 0+3 = 3
  wait += 3-0 = 3    (총 대기: 3)

time=3: jobs[1]=[1,9] 요청시점 1 <= 3 → push
        jobs[2]=[2,6] 요청시점 2 <= 3 → push
  heap: [(6,2), (9,1)]  ← 소요시간 기준 Min Heap
  작업 처리: duration=6, request=2  ← 소요시간 짧은 것 먼저!
  time = 3+6 = 9
  wait += 9-2 = 7    (총 대기: 10)

time=9: jobs[3]=[1,9] 이미 heap에 있음
  작업 처리: duration=9, request=1
  time = 9+9 = 18
  wait += 18-1 = 17  (총 대기: 27)

return 27 // 3 = 9  ✅
```
