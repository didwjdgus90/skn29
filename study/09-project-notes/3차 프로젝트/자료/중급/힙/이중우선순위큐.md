# 본문

## 문제 설명

이중 우선순위 큐(Dual Priority Queue)는 아래 두 연산을 지원하는 자료구조입니다.

| 연산 | 의미 |
|---|---|
| `I n` | 정수 n을 큐에 삽입 |
| `D 1` | 최댓값 삭제 |
| `D -1` | 최솟값 삭제 |

모든 연산을 처리한 후 큐에 남은 **최댓값과 최솟값**을 출력합니다.
큐가 비어있으면 `EMPTY`를 출력합니다.

입출력 예시:

```
입력:
I 7
I 5
I -5
D -1    ← 최솟값(-5) 삭제
D 1     ← 최댓값(7) 삭제

출력: 5 5   (최대=5, 최소=5)
```

---

## 핵심 개념: 힙 두 개로 Min/Max 동시 관리

일반 힙은 최솟값 또는 최댓값 중 하나만 빠르게 꺼낼 수 있습니다.
이중 우선순위 큐는 **최솟값도, 최댓값도** 빠르게 꺼내야 합니다.

### 아이디어: Min Heap + Max Heap 동시 운용

> 📦 비유: 같은 목록을 두 명의 직원이 관리합니다.
> 한 명은 "가장 작은 것"을, 다른 한 명은 "가장 큰 것"을 담당합니다.
> 그런데 한쪽에서 삭제하면 다른 쪽에도 반영해야 합니다.
> → 이 "동기화 문제"가 핵심입니다.

### 동기화 문제 해결: isDeleted 배열

삽입할 때 각 원소에 고유한 key(인덱스)를 부여합니다.
삭제할 때 실제로 heap에서 즉시 지우지 않고, `isDeleted[key] = True`로 표시만 합니다.
heap에서 꺼낼 때 이미 삭제 표시된 원소는 그냥 버립니다.

```
삽입: minHeap과 maxHeap 둘 다에 (값, key) 형태로 push
삭제: isDeleted[key] = True 로 표시만
꺼낼 때: isDeleted[key]가 True면 그냥 버리고 다음 것 꺼내기
```

## 코드

```python
import sys
import heapq

def solve():
    input = sys.stdin.readline
    T = int(input())

    for _ in range(T):
        n = int(input())
        isDeleted = [False] * n   # 삭제 여부 추적
        minHeap = []              # 최솟값 추출용
        maxHeap = []              # 최댓값 추출용 (값에 -1 곱해서 저장)

        for i in range(n):
            cmd, val = input().split()
            val = int(val)

            if cmd == 'I':
                # 삽입: 두 힙 모두에 (값, key) 형태로 push
                heapq.heappush(minHeap, (val, i))
                heapq.heappush(maxHeap, (-val, i))   # 최대힙은 부호 반전

            else:  # 'D'
                if val == 1:    # 최댓값 삭제
                    # 이미 삭제된 원소는 버리면서 최상단 탐색
                    while maxHeap and isDeleted[maxHeap[0][1]]:
                        heapq.heappop(maxHeap)
                    if maxHeap:
                        _, key = heapq.heappop(maxHeap)
                        isDeleted[key] = True         # 삭제 표시

                else:           # 최솟값 삭제
                    while minHeap and isDeleted[minHeap[0][1]]:
                        heapq.heappop(minHeap)
                    if minHeap:
                        _, key = heapq.heappop(minHeap)
                        isDeleted[key] = True

        # 최종 정리: 삭제 표시된 원소 제거
        while maxHeap and isDeleted[maxHeap[0][1]]:
            heapq.heappop(maxHeap)
        while minHeap and isDeleted[minHeap[0][1]]:
            heapq.heappop(minHeap)

        if not minHeap:
            print("EMPTY")
        else:
            print(-maxHeap[0][0], minHeap[0][0])  # 최댓값, 최솟값

solve()
```

### 코드 흐름 추적 (예제 기준)

```
I 7  → minHeap:[(7,0)]  maxHeap:[(-7,0)]  isDeleted:[F,F,F,F,F]
I 5  → minHeap:[(5,1),(7,0)]  maxHeap:[(-7,0),(-5,1)]
I -5 → minHeap:[(-5,2),(7,0),(5,1)]  maxHeap:[(-7,0),(-5,1),(5,2)]

D -1 (최솟값 삭제)
  minHeap 최상단: (-5, 2) → isDeleted[2] = True
  minHeap:[( 5,1),(7,0)]

D 1 (최댓값 삭제)
  maxHeap 최상단: (-7, 0) → isDeleted[0] = True
  maxHeap:[(-5,1),(5,2)]
  → 그런데 (5,2)는 isDeleted[2]=True이므로 나중에 버려짐

최종 정리:
  maxHeap: (-5,1) 남음  ← isDeleted[1]=False, 유효
  minHeap: ( 5,1) 남음  ← isDeleted[1]=False, 유효

출력: -(-5) = 5, 5 → "5 5"  ✅
```

---

## 왜 isDeleted 배열이 필요한가?

Max Heap에서 7을 삭제했을 때, Min Heap 안의 7도 즉시 지우려면
Min Heap 전체를 뒤져야 해서 O(N)이 걸립니다.

isDeleted 배열을 쓰면 삭제 표시는 O(1), 
실제 제거는 어차피 꺼낼 때 자연스럽게 처리되어 전체 O(N log N)을 유지합니다.

---

## 시간복잡도

| 연산 | 복잡도 |
|---|---|
| 삽입 (두 힙에 push) | O(log N) |
| 삭제 (표시 + 정리) | O(log N) 평균 |
| 전체 (N개 연산) | O(N log N) |
