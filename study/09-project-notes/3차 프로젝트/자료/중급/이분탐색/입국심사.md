# 본문

## 문제 설명

n명이 입국심사를 기다립니다. 심사관마다 한 명을 심사하는 시간이 다릅니다.
모든 사람이 심사를 받는 데 걸리는 **시간의 최솟값**을 구하세요.

입출력 예시:

| n | times | return |
|---|---|---|
| 6 | [7, 10] | 28 |

풀이:
- 28분 동안: 7분 심사관 → 28//7 = 4명, 10분 심사관 → 28//10 = 2명 → 총 6명 ✅
- 27분 동안: 27//7 = 3명, 27//10 = 2명 → 총 5명 → 부족 ❌

---

## 왜 이분탐색인가?

n이 최대 10억 → O(N) 이하로 풀 수 없습니다.

**핵심 관찰:** "시간이 많을수록 처리 가능한 사람 수가 많아진다" → 단조 증가
→ 파라메트릭 서치 적용 가능!

```
최적화 문제: "모든 n명을 처리하는 최소 시간은?"
      ↓
결정 문제:  "mid분 동안 n명을 처리할 수 있는가?"
```

---

## 탐색 범위 설정

- `left = 1` : 최소 1분
- `right = max(times) * n` : 가장 느린 심사관 혼자 n명 처리하는 시간 (최악의 경우)

---

## 풀이 흐름

```
1. left=1, right=max(times)*n 으로 범위 설정
2. mid = (left+right)//2 계산
3. mid분 동안 처리 가능한 총 인원 = sum(mid // t for t in times)
4. 총 인원 >= n 이면:
   - mid분으로 충분 → answer=mid 저장, 더 짧은 시간 탐색 (right=mid-1)
5. 총 인원 < n 이면:
   - mid분이 부족 → 더 긴 시간 필요 (left=mid+1)
```

---

## 코드

```python
def solution(n, times):
    answer = 0
    left = 1
    right = max(times) * n   # 최악의 경우 (가장 느린 심사관 혼자 n명 처리)

    while left <= right:
        mid = (left + right) // 2

        # mid분 동안 전체 심사관이 처리할 수 있는 총 인원
        people = sum(mid // t for t in times)

        if people >= n:
            # mid분으로 n명 처리 가능 → 최솟값 후보 저장, 범위 줄이기
            answer = mid
            right = mid - 1
        else:
            # mid분으로 n명 처리 불가 → 시간 더 필요
            left = mid + 1

    return answer
```

### 코드 흐름 추적 (n=6, times=[7,10])

```
left=1, right=60

1회: mid=30, people=30//7+30//10=4+3=7 >= 6 → answer=30, right=29
2회: mid=15, people=15//7+15//10=2+1=3 < 6  → left=16
3회: mid=22, people=22//7+22//10=3+2=5 < 6  → left=23
4회: mid=26, people=26//7+26//10=3+2=5 < 6  → left=27
5회: mid=28, people=28//7+28//10=4+2=6 >= 6 → answer=28, right=27
6회: left>right → 종료

return 28  ✅
```

---

## 핵심 포인트

`people >= n`일 때 바로 return하지 않고 `answer=mid`로 저장 후 계속 탐색하는 이유:
- 딱 n명 처리했더라도 시간이 남을 수 있습니다.
- 예: mid=29일 때도 29//7+29//10 = 4+2 = 6명 처리 가능
- 28이 진짜 최솟값임을 확인하려면 더 탐색해야 합니다.

## 시간복잡도

| 연산 | 복잡도 |
|---|---|
| 이분탐색 (범위: max(times)*n) | O(log(max*n)) |
| 조건 확인 (times 순회) | O(T) |
| 전체 | O(T log(max*n)) |
