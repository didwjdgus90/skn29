# 본문

## 문제 설명

바위들이 강에 일렬로 놓여 있습니다.
바위를 n개 제거했을 때, **출발지~도착지 사이 간격의 최솟값이 최대**가 되도록 하세요.

입출력 예시:

| distance | rocks | n | return |
|---|---|---|---|
| 25 | [2, 14, 11, 21, 17] | 2 | 4 |

```
전체 위치: 0(출발) - 2 - 11 - 14 - 17 - 21 - 25(도착)
바위 2개 제거 시 간격 최솟값이 최대인 경우:
2, 14 제거 → 0 - 11 - 17 - 21 - 25 → 간격: 11, 6, 4, 4 → 최솟값=4  ✅
```

---

## 왜 이분탐색인가?

바위를 직접 조합해서 시도하면 조합의 수가 너무 많습니다.
distance가 최대 10억 → 범위가 매우 큼 → 파라메트릭 서치!

**핵심 관찰:** "간격의 최솟값을 X로 만들 수 있는가?" 로 바꿉니다.

```
최적화 문제: "n개 제거 후 간격 최솟값의 최댓값은?"
      ↓
결정 문제:  "간격의 최솟값이 mid 이상이 되도록 n개 이하의 바위를 제거할 수 있는가?"
```

---

## 결정 함수의 구현

"간격의 최솟값이 mid 이상"이 되려면, mid보다 작은 간격을 만드는 바위를 제거해야 합니다.

```
바위 정렬 후 앞에서부터 순회하며:
이전 바위와의 간격 < mid → 이 바위를 제거 (cnt++)
이전 바위와의 간격 >= mid → 통과, 이전 위치 갱신
```

제거한 개수 cnt <= n 이면 가능, cnt > n이면 불가능.

---

## 코드

```python
def solution(distance, rocks, n):
    rocks.sort()
    rocks = [0] + rocks + [distance]  # 출발점(0)과 도착점 추가

    def check(mid):
        """간격의 최솟값이 mid 이상이 되도록 n개 이하로 제거 가능한가?"""
        cnt = 0          # 제거한 바위 수
        prev = 0         # 이전으로 남긴 바위 위치
        for i in range(1, len(rocks)):
            if rocks[i] - prev < mid:   # 간격이 mid보다 작으면
                cnt += 1                # 현재 바위 제거
            else:
                prev = rocks[i]         # 간격이 충분하면 이 바위를 기준으로 갱신
        return cnt <= n

    left, right = 1, distance
    answer = 0

    while left <= right:
        mid = (left + right) // 2
        if check(mid):
            answer = mid        # 가능 → 더 큰 값도 가능한지 탐색
            left = mid + 1
        else:
            right = mid - 1     # 불가능 → 더 작은 값 탐색

    return answer
```

### 코드 흐름 추적 (예제 기준)

```
distance=25, rocks=[2,14,11,21,17], n=2
정렬 후: [0, 2, 11, 14, 17, 21, 25]
left=1, right=25

1회: mid=13, check(13)?
  prev=0
  rocks[1]=2:  2-0=2 < 13  → cnt=1 (제거)
  rocks[2]=11: 11-0=11 < 13 → cnt=2 (제거)
  rocks[3]=14: 14-0=14 >= 13 → prev=14
  rocks[4]=17: 17-14=3 < 13 → cnt=3 (제거)
  cnt=3 > n=2 → False
  → right=12

2회: mid=6, check(6)?
  2-0=2<6 → cnt=1, 11-0=11>=6 → prev=11
  14-11=3<6 → cnt=2, 17-11=6>=6 → prev=17
  21-17=4<6 → cnt=3 > 2 → False
  → right=5

3회: mid=3, check(3)?
  2-0=2<3 → cnt=1, 11-0=11>=3 → prev=11 ... cnt=1<=2 → True
  → answer=3, left=4

4회: mid=4, check(4)?
  2-0=2<4 → cnt=1, 11-0>=4 → prev=11
  14-11=3<4 → cnt=2, 17-11=6>=4 → prev=17
  21-17=4>=4 → prev=21, 25-21=4>=4 → ok
  cnt=2<=2 → True → answer=4, left=5

5회: left>right → 종료

return 4  ✅
```

## 핵심 포인트

check 함수에서 "이전 바위와의 간격 < mid인 바위를 제거"할 때
**도착지(distance)는 절대 제거할 수 없습니다.**
출발(0)과 도착(distance)을 rocks에 포함시켜 마지막 간격도 체크합니다.

|---|---|

| 전체 | O(R log distance) |
