## 이진 탐색이란?
이진 탐색은 정렬된 배열에서 원하는 값을 찾을 때 절반씩 범위를 줄여가며 탐색하는 알고리즘이다.

두꺼운 사전에서 단어를 찾는 것과 같다.
'apple'을 찾는다면 처음부터 한 장씩 넘기지 않고 책 중간을 펼쳐서 확인하고,
앞쪽인지 뒤쪽인지 판단해서 그쪽 절반만 다시 탐색한다.

주의: 반드시 정렬된 배열에서만 사용 가능하다.

## 순차 탐색 vs 이진 탐색
100만 개의 데이터에서 값을 찾는다면?

순차 탐색: 최대 1,000,000번 비교
이진 탐색: 최대 약 20번 비교 (log₂ 1,000,000 ≈ 20)

시간복잡도: O(log N)

## 단계별 설명
배열 [1, 3, 5, 7, 9, 11, 13, 15]에서 7을 찾는 과정:

left=0, right=7
1단계: mid=3, arr[3]=7 → 찾음! 인덱스 3 반환

배열 [1, 3, 5, 7, 9, 11, 13, 15]에서 11을 찾는 과정:

left=0, right=7
1단계: mid=3, arr[3]=7 < 11 → left=4
2단계: mid=5, arr[5]=11 == 11 → 찾음! 인덱스 5 반환

## 구현 코드 (Python)
left, right 포인터로 탐색 범위를 계속 절반씩 줄인다.
mid 값이 target보다 작으면 오른쪽 절반, 크면 왼쪽 절반만 탐색한다.

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid          # 찾음!
        elif arr[mid] < target:
            left = mid + 1      # 오른쪽 절반 탐색
        else:
            right = mid - 1     # 왼쪽 절반 탐색

    return -1  # 없음

arr = [1, 3, 5, 7, 9, 11, 13]
queries = [7, 4, 13]

for q in queries:
    result = binary_search(arr, q)
    print('YES' if result != -1 else 'NO')
```

## Parametric Search (응용)
조건을 만족하는 최솟값/최댓값을 구할 때 이진 탐색을 응용한다.
핵심: 단조 함수에서 조건 만족/불만족의 경계를 이진 탐색으로 찾는다.

```python
# 떡 자르기: 절단기 높이 H의 최댓값 구하기
def can_get(tteok, H, M):
    return sum(max(0, t - H) for t in tteok) >= M

def parametric_search(tteok, M):
    left, right = 0, max(tteok)
    result = 0
    while left <= right:
        mid = (left + right) // 2
        if can_get(tteok, mid, M):
            result = mid
            left = mid + 1
        else:
            right = mid - 1
    return result

print(parametric_search([19,15,10,17], 20))  # 출력: 15
```
