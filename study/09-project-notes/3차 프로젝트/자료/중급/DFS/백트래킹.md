# 본문

## 백트래킹이란?

조건을 만족하는 한 계속 탐색해 나가다가, 조건에 부합하지 않는 순간
탐색을 **취소하고 이전 단계로 돌아와** 다시 탐색을 이어나가는 알고리즘입니다.

> 📦 비유: 미로 탈출
> 한 방향으로 쭉 걸어가다 막히면 왔던 길을 되돌아가서 다른 길을 선택합니다.
> 백트래킹은 이처럼 "막히면 돌아가는" 전략입니다.

---

## DFS vs 백트래킹

| | DFS | 백트래킹 |
|---|---|---|
| 탐색 범위 | 모든 경로 탐색 | 조건 불만족 시 즉시 중단 |
| 가지치기 | 없음 | 있음 (pruning) |
| 효율 | 경우의 수 N! 그대로 | 불필요한 경로 조기 제거 |
| 구현 | 재귀/스택 | 재귀 + 조건 검사 |

**백트래킹은 DFS 기반이지만, 가지치기를 통해 탐색 범위를 줄입니다.**
가지치기를 얼마나 잘 하느냐에 따라 효율이 크게 달라집니다.

---

## 핵심 개념: 유망성 (Promising)

어떤 상태가 **해가 될 가능성이 있으면 유망하다(promising)** 고 합니다.

```
유망하다 → 계속 탐색
유망하지 않다 → 이전 단계로 돌아가기 (backtrack)
             → 해당 노드 이후 탐색 전부 생략 = 가지치기(pruning)
```

---

## 기본 구조 (의사 코드)

```python
def backtracking(상태, 현재깊이):
    if 목표 상태에 도달:
        정답 처리
        return

    for 가능한 모든 선택지:
        if 조건을 만족하는가 (유망성 검사):
            상태 변경          # 선택 적용
            backtracking(새 상태, 현재깊이 + 1)
            상태 원복          # 선택 취소 → 다음 선택지 시도
```

핵심은 **선택 → 재귀 → 원복** 의 3단계입니다.
원복(undo)을 빠뜨리면 이전 상태가 오염되어 잘못된 결과가 나옵니다.

## 예제: N-Queen 문제 (Python)

N×N 체스판에 N개의 퀸을 서로 공격하지 않도록 배치하는 경우의 수를 구하세요.
퀸은 같은 행, 열, 대각선 방향으로 공격합니다.

**관찰:** 행마다 퀸을 1개씩 놓으면 행 충돌은 자동으로 방지됩니다.
→ 각 행에서 어느 열에 놓을지만 결정하면 됩니다.

### 유망성 검사 조건

- 같은 열에 이미 퀸이 있으면 → 불가
- 대각선에 이미 퀸이 있으면 → 불가 (|행 차이| == |열 차이|)

```python
def n_queen(n):
    queen = [0] * n   # queen[i] = i번째 행에서 퀸이 놓인 열 번호
    answer = 0

    def is_valid(row):
        """현재 row에 퀸을 놓을 수 있는지 검사"""
        for prev_row in range(row):
            # 같은 열 충돌
            if queen[prev_row] == queen[row]:
                return False
            # 대각선 충돌: |행 차이| == |열 차이|
            if abs(prev_row - row) == abs(queen[prev_row] - queen[row]):
                return False
        return True

    def backtrack(row):
        nonlocal answer
        if row == n:          # 모든 행에 퀸 배치 완료
            answer += 1
            return

        for col in range(n):
            queen[row] = col          # 현재 행 col열에 퀸 배치 (상태 변경)
            if is_valid(row):         # 유망성 검사
                backtrack(row + 1)    # 다음 행으로 진행 (재귀)
            queen[row] = 0            # 원복 (다음 col 시도를 위해)

    backtrack(0)
    return answer

print(n_queen(4))   # 2
print(n_queen(8))   # 92
```

### 탐색 과정 (N=4 일부)

```
row=0: col=0 시도 → queen=[0,0,0,0]
  row=1: col=0 → 같은 열 충돌 ❌
  row=1: col=1 → 대각선 충돌 ❌
  row=1: col=2 → 유망 ✅ → queen=[0,2,0,0]
    row=2: col=0 → 대각선 충돌 ❌
    row=2: col=1 → 열/대각선 충돌 ❌
    row=2: col=2 → 열 충돌 ❌
    row=2: col=3 → 대각선 충돌 ❌
    → 모두 불가 → 백트래킹
  row=1: col=3 → 유망 ✅ → ...
...
```

## 백트래킹 적용 패턴

백트래킹이 잘 맞는 문제 유형입니다.

| 유형 | 예시 |
|---|---|
| 순열/조합 생성 | N개 중 M개 고르기 |
| 제약 충족 | N-Queen, 스도쿠 |
| 부분집합 탐색 | 합이 특정 값인 부분집합 |
| 경로 탐색 | 미로, 체스 이동 |

---

## 시간복잡도

가지치기 없는 경우 최악 O(N!) 이지만,
가지치기 효율에 따라 실제 탐색 수는 크게 줄어듭니다.
